第 1 章Chapter 1

三个警报，配对失效Three alarms, and pairing fails

译码器的任务在任何码上都一样：看到症状，选一个修复，使残留不是逻辑算符。变的是症状长什么样。这一章先把「静态症状」写成一行矩阵乘法，再数清 gross 码里一个错误点亮哪三条检查，最后说明为什么表面码的配对结构在这里消失了——以及在 toric_L3 这个最小实例上它为什么还在。 A decoder's job is the same on every code: see the syndrome, choose a repair, and make sure the residual is not a logical operator. What changes is what the syndrome looks like. This chapter first writes the “static syndrome” as one line of matrix multiplication, then counts exactly which three checks one error lights in the gross code, and finally explains why the surface code's pairing structure vanishes here, and why it survives on the smallest instance, toric_L3.

1.1静态症状：一行矩阵乘法The static syndrome: one line of matrix multiplication

先约定测量是完美的（这叫「静态」；测量也会错的情形留到第 4 章）。Atlas 的 syndrome-circuits-and-decoding.md 第 1 节只用一句话：「an X-type data error eX produces the Z-check syndrome HZeX; a Z-type error eZ produces HXeZ」。人话：把「哪些比特上有 X 错误」写成一列 0/1，用 Z 检查矩阵去乘它（模 2），结果那一列 0/1 就是哪些 Z 检查亮了。《从高考数学到 Toric Code》5.4 节用「链的端点」说过这件事；矩阵版本对任何 CSS 码都成立，gross 也不例外。

Assume for now that measurements are perfect (this is the “static” setting; measurements that can err wait until Chapter 4). Section 1 of the Atlas file syndrome-circuits-and-decoding.md needs one sentence: “an X-type data error eX produces the Z-check syndrome HZeX; a Z-type error eZ produces HXeZ”. Plainly: write “which qubits carry an X error” as a column of 0/1, multiply it by the Z check matrix (mod 2), and the resulting column of 0/1 says which Z checks light up. Section 5.4 of “From Exam Maths to the Toric Code” said this with “endpoints of a chain”; the matrix version holds for every CSS code, gross included.

For Z errors and X checks, swap the letters.

第二行是整个译码问题的判决书。《译码器 · 高中数学版》1.1 节说译码是「在类之间二选一」：残留要么是检查的乘积（无事发生），要么含一条横跨的串（逻辑错误）。BB 码多了一个数字上的差别：表面码 k = 1，一个症状下只有 2 类；gross 码 k = 12，同一个症状下合法修复分成 212 = 4096 类（每类对应 12 个逻辑比特各翻不翻的一种组合），译码器要在 4096 类里押中真实错误所在的那一类。Atlas 的原文接着提醒：「A correction needs the same syndrome and may differ from the actual error by a stabilizer」——修复不必等于真实错误，差一个稳定子就算成功。gross 的 X 稳定子群由 HX 的 66 个独立行生成，共 266 ≈ 7.4 × 1019 个元素：也就是说，每一类里有 266 个彼此等价的修复。这个巨大的数字叫退化degeneracy：许多不同的物理错误（互差一个稳定子）对应同一个逻辑效果。BB 码的退化度极高：gross 每一类含 266 个等价修复。它让「最可能的单个错误」与「最可能的类」分道扬镳。，第 2 章会看到它怎样为难置信传播。

The second line is the verdict of the whole decoding problem. Section 1.1 of “Decoders · High-School Edition” says decoding is “choosing one of two classes”: the residual is either a product of checks (nothing happened) or contains a spanning string (a logical error). BB codes add a numerical difference: the surface code has k = 1, so one syndrome has only 2 classes; gross has k = 12, so under one syndrome the valid repairs split into 212 = 4096 classes (one per combination of “flipped or not” across the 12 logical qubits), and the decoder must bet on the class the true error belongs to out of 4096. The Atlas text then reminds us: “A correction needs the same syndrome and may differ from the actual error by a stabilizer”; the repair need not equal the true error, and differing by a stabilizer still counts as success. The X stabilizer group of gross is generated by the 66 independent rows of HX and has 266 ≈ 7.4 × 1019 elements: every class contains 266 mutually equivalent repairs. This enormous number is called degeneracyMany different physical errors (differing by a stabilizer) have the same logical effect. BB codes are highly degenerate: each gross class contains 266 equivalent repairs. It makes “the most likely single error” and “the most likely class” part ways., and Chapter 2 shows how it troubles belief propagation.

1.2一个错误点亮哪三条检查Which three checks one error lights

参数与实例导读 2.2 节数过：gross 每个数据比特被 |A| = 3 条 X 检查和 |B| = 3 条 Z 检查碰到（写成 3 + 3，而不是「度 6」，因为两种检查在电路里的角色不同）。矩阵语言里：HZ 的每一列恰有 3 个 1。所以 eX 只有一个 1 时，s = HZeX 就是 HZ 的那一列，恰有 3 个 1：一个 X 错误点亮三条 Z 检查。具体是哪三条？按参数导读 1.3 节的编号（格子 (i, j) 编号 i·6 + j，左层 0–71，右层 72–143），对数据比特 1（左层格子 (0,1)）本篇自己算了一遍：Z 检查在格子 (i, j) 的左层三条腿由 Bᵀ 给出，落在 (i, j−3)、(i−1, j)、(i−2, j)；要让其中一条落在 (0,1)，检查得在 (0,4)、(1,1) 或 (2,1)，编号 4、7、13。同理，比特 1 上的 Z 错误点亮 X 检查 0、5、55（X 检查 0 的六条腿 [1, 2, 18, 75, 78, 84] 里确实有 1，可与参数导读转录的 reproduce.py 断言对照）。

Section 2.2 of the parameters guide counted it: every gross data qubit sits in |A| = 3 X checks and |B| = 3 Z checks (written 3 + 3 rather than “degree 6”, because the two kinds play different roles in the circuit). In matrix language: every column of HZ has exactly 3 ones. So when eX has a single 1, s = HZeX is that one column of HZ, with exactly 3 ones: one X error lights three Z checks. Which three? Using the numbering of section 1.3 of the parameters guide (site (i, j) is number i·6 + j, left layer 0–71, right layer 72–143), this guide worked it out for data qubit 1 (left-layer site (0,1)): the three left-layer legs of the Z check at site (i, j) come from Bᵀ and land on (i, j−3), (i−1, j), (i−2, j); for one of them to land on (0,1) the check must sit at (0,4), (1,1) or (2,1), numbers 4, 7, 13. Likewise a Z error on qubit 1 lights X checks 0, 5, 55 (the six legs of X check 0, [1, 2, 18, 75, 78, 84], do include 1; compare the reproduce.py assertion transcribed in the parameters guide).

1.3为什么「配对」没有意义了Why “pairing” no longer means anything

《译码器 · 高中数学版》2.1 节的症状图syndrome graph：顶点是警报，边是「一条错误链」；匹配译码在这张图上找总重量最小的完美配对。它成立的前提是每个基本错误恰好连接两个警报。是这样造出来的：每个可能的单比特错误恰好点亮两个警报，于是把它画成连接两个警报的一条边；一批错误就是一批边，症状就是这些边的端点；译码 = 把亮着的端点两两配对（2.2 节的最小重量完美匹配）。这个翻译依赖一个字：两。gross 码里单比特错误点亮三个警报，画出来不是一条边，而是一条连接三个顶点的超边hyperedge：连接三个或更多顶点的「边」。含超边的图叫超图；最小重量完美匹配是为普通图定义的，对超图没有多项式时间的对应算法。。「完美匹配」要求每个警报恰好属于一对；三个一组的结构下，「一对」这个词本身就用不上。BB 教程6.3 节那句「配对失去了意义」，展开就是这一段。

The syndrome graphVertices are alarms, edges are “one error chain”; the matching decoder finds the minimum-weight perfect pairing on this graph. It presupposes that every elementary error connects exactly two alarms. of section 2.1 of “Decoders · High-School Edition” is built like this: every possible single-qubit error lights exactly two alarms, so draw it as an edge joining those two; a set of errors is a set of edges, the syndrome is their endpoints, and decoding = pair up the lit endpoints (the minimum-weight perfect matching of section 2.2). This translation hinges on one word: two. In gross a single-qubit error lights three alarms; drawn out it is not an edge but a hyperedgeAn “edge” joining three or more vertices. A graph with hyperedges is a hypergraph; minimum-weight perfect matching is defined for ordinary graphs and has no polynomial-time counterpart on hypergraphs. joining three vertices. A “perfect matching” requires every alarm to belong to exactly one pair; with alarms coming in triples, the word “pair” itself does not apply. The sentence “pairing loses its meaning” in BB guide section 6.3 unfolds into this paragraph.

两个反例让边界更清楚。第一，toric_L3（A = 1 + x，B = 1 + y，BB 教程 5.1 节）检查重量 2 + 2，每个比特只在 2 条 Z 检查里，一个错误恰好亮两条：它就是环面码，匹配照常可用——所以「BB 码不能用匹配」这句话的精确版本是「检查重量 3 + 3 的 BB 码不能直接用匹配」。第二，第 3 章的第三条记录 sahay2026matching 正是把 gross 这类码通过对称性归约成「环面柱面」，让匹配重新可用；它没有推翻本节，它绕过了本节。先到实验台上看两种情形的警报数：预设 toric_L3，按「新错误」几次，读数里「亮起的 Z 检查」大约是错误重量的两倍；下一章把预设切到 [[72,12,6]]（与 gross 同一对多项式，6 × 6 环面），它接近三倍。

Two counter-examples sharpen the boundary. First, toric_L3 (A = 1 + x, B = 1 + y, BB guide section 5.1) has check weight 2 + 2, every qubit lies in only 2 Z checks, and one error lights exactly two: it is the toric code and matching works as usual, so the precise version of “BB codes cannot use matching” is “BB codes with check weight 3 + 3 cannot use matching directly”. Second, the third record of Chapter 3, sahay2026matching, is exactly a symmetry reduction of gross-like codes to “toric cylinders” that makes matching usable again; it does not overturn this section, it goes around it. Look at the alarm counts in both situations on the bench: with preset toric_L3, press “New error” a few times and the readout's “Z-checks lit” is about twice the error weight; in the next chapter switch to [[72,12,6]] (the same polynomial pair as gross on a 6 × 6 torus) and it approaches three times.

关键想法Key idea

症状永远是 s = HZeX；变的是 HZ 每列有几个 1。表面码与环面码每列 2 个，错误是「边」，译码是配对；gross 每列 3 个（比特 1 上的错误亮 Z 检查 4、7、13），错误是三端点的超边，配对无从谈起。加上 k = 12 带来的 4096 个类和每类 266 个等价修复，BB 需要的是一种不依赖「两个端点」的译码器——那就是下一章在整张 Tanner 图上传消息的置信传播。

The syndrome is always s = HZeX; what changes is how many ones each column of HZ has. Surface and toric codes have 2 per column, errors are “edges”, decoding is pairing; gross has 3 per column (an error on qubit 1 lights Z checks 4, 7, 13), errors are three-ended hyperedges, and pairing is off the table. Add the 4096 classes that k = 12 brings and the 266 equivalent repairs per class, and BB needs a decoder that does not rely on “two endpoints”: the belief propagation of the next chapter, which passes messages over the whole Tanner graph.

第 2 章Chapter 2

置信传播与 OSD：传消息、卡住、解方程Belief propagation and OSD: pass messages, stall, solve equations

置信传播（BP）让每个比特和每条检查在 Tanner 图上反复交换「你有多可能出错」。在没有圈的图上它给出精确答案；gross 的 Tanner 图最短的圈只有 6 步长，加上每类 266 个等价修复的退化，BP 会摇摆、给出不自洽的硬判决，或押错类。有序统计译码（OSD）在它卡住时接手：按可靠度排序，在最可能出错的比特上解线性方程组，保证交出一个清零症状的修复。这一章把这三件事各讲一遍，然后在 [[72,12,6]] 上亲手跑。 Belief propagation (BP) lets every qubit and every check on the Tanner graph repeatedly exchange “how likely are you to be flipped”. On a graph without cycles it is exact; the gross Tanner graph has cycles as short as 6 steps, and with the degeneracy of 266 equivalent repairs per class BP may oscillate, hand back an inconsistent hard decision, or bet on the wrong class. Ordered-statistics decoding (OSD) takes over when it stalls: sort by reliability, solve a linear system on the most-likely-flipped qubits, and guarantee a repair that clears the syndrome. This chapter explains each of the three, then runs them by hand on [[72,12,6]].

2.1Tanner 图上的消息：对数似然比Messages on the Tanner graph: log-likelihood ratios

BB 教程 6.1 节画过 Tanner 图检查矩阵的图形版：一侧是比特（gross 144 个），一侧是检查（HZ 的 72 条），H 的每个 1 是一条边。gross 的 Tanner(HZ) 有 72 × 6 = 432 条边。：比特一侧、检查一侧，HZ 的每个 1 是一条边；gross 的 Tanner(HZ) 有 144 个比特点、72 个检查点、72 × 6 = 432 条边。BP 在这张图上做的事，《qLDPC 码 · 高中数学版》6.1 节叫「每个比特问邻居：我错了吗」。消息的单位是对数似然比log-likelihood ratio，LLR：L = ln[P(没错)/P(错了)]。正数 = 相信没错，负数 = 相信错了，绝对值越大越确信。一开始每个比特的 LLR 都是先验值 ln((1−p)/p)。（LLR）：Lj = ln[P(比特 j 没错)/P(比特 j 错了)]，正数表示「相信没错」，负数表示「相信错了」，绝对值是把握的大小。一开始谁都没有额外信息，每个比特的 LLR 都等于先验值 ln((1−p)/p)——正是《译码器 · 高中数学版》1.3 节那条边权重 w0；p = 0.06 时约 2.75。然后每一轮：每条检查看着自己 6 个邻居的 LLR 和自己亮不亮，告诉每个邻居「按其他 5 个的说法，你该是什么」；每个比特回话给某条检查时，把先验和另外两条检查送来的消息相加（不把这条检查自己的话再还给它）；只有最后判决时才把三条全加上。几轮后对每个比特做硬判决hard decision：把实数 LLR 变成 0/1 的一步：Lj < 0 判为「错了」（cj = 1），否则判为「没错」。BP 的输出修复 c 就是全部比特的硬判决。：LLR 为负的比特判为出错，得到修复 c。若 HZc = s，说 BP「收敛」。

Gross's Tanner(HZ) has 72 × 6 = 432 edges.: qubits on one side, checks on the other, one edge per 1 of HZ; gross's Tanner(HZ) has 144 qubit nodes, 72 check nodes and 72 × 6 = 432 edges. What BP does on this graph, section 6.1 of “qLDPC Codes · High-School Edition” calls “every bit asks its neighbours: am I wrong?”. The unit of a message is the log-likelihood ratioLLR: L = ln[P(clean)/P(flipped)]. Positive = believed clean, negative = believed flipped, larger magnitude = more confident. Initially every qubit's LLR is the prior ln((1−p)/p). (LLR): Lj = ln[P(qubit j clean)/P(qubit j flipped)], positive meaning “believed clean”, negative “believed flipped”, and the magnitude is the confidence. At the start nobody has extra information, so every qubit's LLR equals the prior ln((1−p)/p), which is exactly the edge weight w0 of section 1.3 of “Decoders · High-School Edition”; about 2.75 at p = 0.06. Then, each round: every check looks at the LLRs of its 6 neighbours and at whether it is lit, and tells each neighbour “given what the other 5 say, here is what you should be”; every qubit, when replying to a check, adds its prior to the messages from the other two checks (it never hands a check its own evidence back); only the final decision sums all three. 2.2树上精确，圈里自欺：gross 的最短圈长 6Exact on trees, self-deceiving on cycles: gross's shortest cycle has length 6

The Atlas text: “On a tree, those local messages are exact. BB Tanner graphs are not trees: short cycles feed correlated information back into itself”. Plainly: if the graph has no cycles, a message sent out never returns, the three messages a qubit receives come from three unrelated regions, and adding them is exactly the probabilist's correct “multiply independent evidence”. With cycles it differs: what qubit j said comes back to j after a few steps, j treats its own words as someone else's evidence, counts them twice, and grows more confident with every round. The shorter the cycle, the sooner it returns. This guide computed it for gross's Tanner(HZ): the shortest cycle has length 6 (3 qubits and 3 checks alternating), for example qubit 1 → Z check 4 → qubit 64 → Z check 70 → qubit 67 → Z check 7 → qubit 1. In other words, the message qubit 1 sends in round 1 is back in its own hands by round 3 as “check 7's opinion”. This is no peculiar defect of gross: toric_L3 and [[72,12,6]] also have shortest Tanner cycles of length 6, and any BB code generated by translations has such short cycles closing up because “two translation routes reach the same site”. The surface code's Tanner graph has short cycles too; it avoids BP not because it lacks cycles but because it has a pairing structure to use instead.

第二个敌人是 1.1 节的退化。Atlas 原文：「quantum degeneracy means many errors represent the same logical coset. BP may oscillate, converge to an inconsistent hard decision, or settle on the wrong coset」。三种失败要分开听。摇摆（oscillate）：LLR 的符号一轮正一轮负，永远不稳定。不自洽的硬判决：每个比特各自判了，但合起来的 c 不满足 HZc = s，症状没清零——这是 BP 特有的失败，匹配译码器永远不会交出一个不清零症状的答案。押错类（wrong coset）：症状清零了，但残留是逻辑算符。退化加重前两种：两个等价的修复 c 与 c ⊕（某条检查）对症状同样有效，BP 在两者之间拿不定主意，就把概率摊开，结果哪个比特都不够负。《译码器 · 高中数学版》3.2 节讲过退化如何让匹配输给最大似然；这里它更进一步，让「逐比特表态」这个动作本身失灵。《qLDPC 码 · 高中数学版》6.2 节把这两个敌人合称「短圈与退化」，本节只是把它们落到 gross 的具体数字上。

The second enemy is the degeneracy of section 1.1. The Atlas text: “quantum degeneracy means many errors represent the same logical coset. BP may oscillate, converge to an inconsistent hard decision, or settle on the wrong coset”. Hear the three failures separately. Oscillate: the sign of an LLR flips from round to round and never settles. Inconsistent hard decision: every qubit has decided, but the combined c does not satisfy HZc = s, the syndrome is not cleared; this failure is peculiar to BP, since a matching decoder never hands back an answer that leaves the syndrome lit. Wrong coset: the syndrome is cleared but the residual is a logical operator. Degeneracy aggravates the first two: two equivalent repairs c and c ⊕ (some check) are equally valid for the syndrome, BP cannot choose between them, spreads the probability across both, and no qubit ends up negative enough. Section 3.2 of “Decoders · High-School Edition” showed how degeneracy makes matching lose to maximum likelihood; here it goes further and breaks the very act of “deciding qubit by qubit”. Section 6.2 of “qLDPC Codes · High-School Edition” called these two enemies “short cycles and degeneracy”; this section only pins them to gross's actual numbers.

关键想法Key idea

BP 是「逐比特表态」：每个比特把先验与三条邻居消息相加，负则判错。它在树上精确；gross 的 Tanner 图有长 6 的圈，消息三轮就绕回自己，加上每类 266 个等价修复，BP 会摇摆、给出症状不清零的判决、或押错类。OSD 是「卡住就解方程」：按可靠度取 66 个比特为信息集，解 HZc = s，保证清零，不保证成功，且要付全局的、随数据变化的延迟。BP-OSD 是这两步的合称，Atlas 的两条主要记录都是它。

BP is “deciding qubit by qubit”: each qubit adds its prior to three neighbour messages and is declared flipped if negative. It is exact on trees; gross's Tanner graph has cycles of length 6, a message returns to its sender in three rounds, and with 266 equivalent repairs per class BP may oscillate, hand back a decision that leaves the syndrome lit, or bet on the wrong class. OSD is “when stuck, solve”: take 66 qubits as an information set by reliability, solve HZc = s, guaranteed to clear, not guaranteed to succeed, at the price of global, data-dependent latency. BP-OSD names the two steps together, and both main Atlas records are it.

电路码距：静态的 12 不是电路的 12Circuit distance: the static 12 is not the circuit's 12

前三章的症状都是「静态」的：测量完美，s = HZe。真实的一条六腿检查是一段电路：一个帮手比特、六个 CNOT、一次读出。帮手在电路中途出错，会沿后面的 CNOT 传到几个数据比特上，形成一种「相关」错误；读数本身也会错，于是要用探测器比较相邻两轮。这一章说清为什么 CNOT 的顺序有讲究、什么是探测器、Atlas 为什么把「静态码距、电路码距、译码器找到的失败重量」当作三个不同的量，以及 bivariate_bicycle 条目明确不导出哪些东西。 The syndromes of the first three chapters were “static”: perfect measurement, s = HZe. A real weight-six check is a circuit: one helper qubit, six CNOTs, one readout. A helper that fails midway spreads through the later CNOTs onto several data qubits, forming a “correlated” error; readings themselves can be wrong, so detectors compare adjacent rounds. This chapter explains why the CNOT order matters, what a detector is, why the Atlas treats “static distance, circuit distance, decoder-found failure weight” as three different quantities, and which things the bivariate_bicycle entry explicitly does not export.

Such a correlated ‘hook’ may align with a logical operator more efficiently than independent faults.」《Surface Code · 高中数学版》第 4 章打开过这个黑盒（四腿版），《译码器 · 高中数学版》5.4 节给了这种错误一个名字：hook 错误hook error：帮手比特在第 t 个 CNOT 之后出错，错误经由第 t+1 到第 6 个 CNOT 传到对应的数据比特上，一个故障变成多个数据比特的相关错误。传到哪几个比特由 CNOT 顺序决定。。人话：一条 gross 的 Z 检查依次对它的 6 个数据比特做 CNOT；若帮手比特在第 2 个 CNOT 之后翻了，后面 4 个 CNOT 会把这一翻「复印」到 4 个数据比特上——一个故障、四个错误。在 gross 里这四个错误乘上那条检查本身就变成另外两腿上的错误——一个钩子故障其实只值重量 2，所以三个钩子加起来不超过 6，单靠它们凑不出重量 12 的逻辑算符；危险在于它们和别的故障叠在一起时，可以比同样多个独立的单比特故障更省地对齐到某条逻辑算符上：这就是「align with a logical operator more efficiently than independent faults」。CNOT 顺序决定复印到哪四个比特，所以顺序决定这件坏事会不会发生。

The Atlas text: “Measuring one stabilizer with an ancilla requires preparation, a sequence of entangling gates, measurement, and reset. The order of those entangling gates matters. Such a correlated ‘hook’ may align with a logical operator more efficiently than independent faults.” Chapter 4 of “Surface Code · High-School Edition” opened this box (the weight-four version), and section 5.4 of “Decoders · High-School Edition” named the error: the hook errorThe helper qubit fails after the t-th CNOT and the error travels through CNOTs t+1 to 6 onto the corresponding data qubits, turning one fault into a correlated error on several data qubits. Which qubits depends on the CNOT order.. Plainly: a gross Z check performs CNOTs with its 6 data qubits in turn; if the helper flips after the 2nd CNOT, the remaining 4 CNOTs “photocopy” that flip onto 4 data qubits: one fault, four errors. In gross, multiplying those four errors by the check itself turns them into errors on the other two legs, so one hook fault is really worth weight 2; three hooks add up to at most 6 and cannot by themselves make a weight-12 logical. The danger is that, combined with other faults, they can line up along a logical operator more cheaply than the same number of independent single-qubit faults: that is “align with a logical operator more efficiently than independent faults”. The CNOT order decides which four qubits receive the copy, so the order decides whether this bad thing can happen.

深度 7 由此有了准确的地位。Atlas：「bravyi2024bicycle gives a seven-CNOT-layer extraction for its two-layer connectivity. 4.2从读数到探测器From readings to detectors

Atlas 原文：「With noisy repeated extraction, one does not decode raw syndrome bits in isolation. Detector events compare measurements across time so that a measurement fault produces a recognizable spacetime pattern. The boundary rounds, initialization, final data measurement, and which products of measurement results are deterministic all enter the detector definition.」《译码器 · 高中数学版》5.1 节给了公式：探测器 D(i, t) = s(i, t) ⊕ s(i, t−1)，同一条检查相邻两轮读数不同才亮。人话：读错一次只影响一轮，下一轮读数变回去，于是探测器在时间方向上亮成一对；真实的数据错误让读数从那一轮起持续翻转，探测器只在发生那一轮亮。对 gross，一轮有 144 条检查、多轮就是 144 × 轮数个探测器，再加上开头（初始化后哪些乘积确定为 +1）和结尾（最后直接测数据比特）的特殊规则。译码器面对的是这张时空探测器图，不是第 1 章那 72 位的 s。Atlas 的操作合同因此要求写明「the exact extraction schedule and detector construction」——两者缺一，同一个电路就可能定义出两个不同的实验（第 3 章限定项 ③）。

The Atlas text: “With noisy repeated extraction, one does not decode raw syndrome bits in isolation. Detector events compare measurements across time so that a measurement fault produces a recognizable spacetime pattern. The boundary rounds, initialization, final data measurement, and which products of measurement results are deterministic all enter the detector definition.” Section 5.1 of “Decoders · High-School Edition” gave the formula: detector D(i, t) = s(i, t) ⊕ s(i, t−1), lit only when the same check's readings differ between adjacent rounds. Plainly: a single misread affects one round and the reading returns next round, so the detector lights as a pair along the time direction; a real data error flips the reading persistently from that round on, so the detector lights only in the round it happened. For gross, one round has 144 checks, so several rounds give 144 × (rounds) detectors, plus special rules at the start (which products are known to be +1 after initialization) and at the end (the data qubits are measured directly). The decoder faces this spacetime detector graph, not the 72-bit s of Chapter 1. The Atlas operational contract therefore demands “the exact extraction schedule and detector construction”: without either, one circuit can define two different experiments (qualifier ③ of Chapter 3).

有序统计译码（OSD）/ 信息集 / 阶数ordered-statistics decoding (OSD) / information set / order按可靠度取 66 个比特解方程保证清零；阶数 = 允许在信息集外翻转的比特数。Solve on 66 qubits chosen by reliability to guarantee clearing; order = qubits outside the set allowed to flip.
码容量 / 现象学 / 电路级code-capacity / phenomenological / circuit-level只有数据错误、测量完美 / 再加读数翻转 q / 电路每个位置独立出错；三个不同的实验。Data errors only with perfect measurement / plus readout flips q / every circuit location fails independently; three different experiments.
协议阈值 / 伪阈值protocol threshold / pseudo-threshold一族码在指定电路、探测器、归一化、译码器下曲线的交叉点（0.8%）/ 单块码逻辑错误率等于物理错误率的 p。The crossing of a family's curves under a specified circuit, detectors, normalization and decoder (0.8%) / the p where one block's logical error rate equals the physical one.
柱面归约 / 过度匹配cylinder reduction / over-matching用对称性把 BB 译码映射到环面柱面再匹配，证书是那次归约；补回丢失信息的改进步骤。Mapping BB decoding onto toric cylinders by symmetry before matching, certified by that reduction; the step recovering lost information.
hook 错误hook error帮手比特中途出错，沿后续 CNOT 复印到多个数据比特；CNOT 顺序决定落点。A helper fails midway and is copied by later CNOTs onto several data qubits; the CNOT order decides where.
探测器detector同一检查相邻两轮读数的异或；边界轮、初始化、最终测量都进入其定义。The XOR of one check's adjacent readings; boundary rounds, initialization and the final measurement enter its definition.
