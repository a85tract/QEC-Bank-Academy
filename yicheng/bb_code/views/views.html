什么是表示阶梯：BB 条目的八条记录What a representation ladder is: the BB entry's eight records

一个纠错码不是一张图，而是一族互相翻译的描述。Atlas 给每个条目排一架五级梯子：越靠下越能直接交给机器执行，越靠上越接近数学与物理的洞见。这一章先把五级各问什么问题说清，再数一数 BB 条目在每一级放了几条记录、每条记录带什么标签。想看同一架梯子在表面码上的样子，见《Surface Code · 表示阶梯》第 1 章；本篇不重复那里的一般介绍，只讲 BB 特有的部分。 An error-correcting code is not one picture but a family of mutually translating descriptions. The Atlas gives every entry a five-rung ladder: the lower rungs can be handed straight to a machine, the upper ones sit closer to mathematical and physical insight. This chapter first says what question each rung asks, then counts how many records the BB entry places on each rung and which label each carries. For the same ladder on the surface code see “Surface Code · Representation Ladder”, Chapter 1; this page does not repeat that general introduction and covers only what is specific to BB.

关键想法Key idea

表示阶梯回答的不是「BB 码是什么」，而是「BB 码有哪几种可靠的说法，每种说法可靠到什么程度、能推出什么、不能推出什么」。接下来五章按级往上走：第 2 章 R1（机器算的矩阵），第 3 章 R2（算出来的链复形 + 一本译码词典），第 4 章 R3（诚实地空着），第 5 章 R4（Tanner 图与电路的分界），第 6 章 R5（四本代数词典）。

The ladder does not answer “what is a BB code” but “in how many reliable ways can it be stated, how reliable is each, what does each let you conclude, and what not”. 2.1从两张矩阵到一张：144 行 × 288 列From two matrices to one: 144 rows × 288 columns

直觉教程停在两张矩阵上：HX = [A | B] 与 HZ = [Bᵀ | Aᵀ]，各 72 行 144 列（72 = lm 是格子数，144 = 2lm = n 是数据比特数；l = 12、m = 6 是环面两个方向的格数）。Atlas 的机器多走一步，把它们并成一张。做法来自《从高考数学到 Toric Code》4.2 节的泡利串：一条作用在 n 个比特上的 Pauli 串，用长 2n 的 0/1 向量 (x | z) 记——前 n 位记哪些比特上有 X，后 n 位记哪些比特上有 Z（Y 算作两边都有）。这就是辛形式symplectic form：把 n 比特 Pauli 串写成 2n 位 0/1 向量 (x | z)。两条串对易 ⇔ x₁·z₂ + z₁·x₂ ≡ 0 (mod 2)，这个「交叉点积」叫辛内积。Atlas 基础页 Pauli operators as binary symplectic vectors 讲全了。。一条纯 X 的检查就是 (行 | 0)，一条纯 Z 的检查就是 (0 | 行)。把 72 条 X 检查和 72 条 Z 检查全部这样写并上下叠起来：

The intuition guide stopped at two matrices: HX = [A | B] and HZ = [Bᵀ | Aᵀ], each 72 rows by 144 columns (72 = lm is the number of sites, 144 = 2lm = n the number of data qubits; l = 12 and m = 6 are the site counts along the two torus directions). The Atlas machine goes one step further and merges them into one. The method is the Pauli-string notation of “From High-School Math to the Toric Code”, §4.2: a Pauli string on n qubits is written as a 0/1 vector (x | z) of length 2n — the first n bits say which qubits carry X, the last n which carry Z (a Y counts on both sides). This is the symplectic formWriting an n-qubit Pauli string as a 2n-bit 0/1 vector (x | z). Two strings commute ⇔ x₁·z₂ + z₁·x₂ ≡ 0 (mod 2); this “crossed dot product” is the symplectic inner product. The Atlas foundations page “Pauli operators as binary symplectic vectors” covers it in full.. A pure-X check is (row | 0), a pure-Z check is (0 | row). Write all 72 X checks and 72 Z checks this way and stack them:

说人话：机器不认识「X 检查」「Z 检查」这两个词，它只认识一张 144 × 288 的 0/1 表，每行 6 个 1（前 72 行的 1 都在左半边，后 72 行的都在右半边）。这张表是所有下游计算的唯一输入——秩、逻辑算符、码距、以后的译码模拟都从它出发，这就是原文说的「universal executable baseline」。为什么要费事合并？因为辛形式对任何稳定子码都一样，不只是 CSS 码：一个不分 X/Z 的码（比如带 Y 的检查）也写成同样格式的表，同一套程序照样能算。BB 码恰好是 CSS 码，所以它的表里左右两半永远不会在同一行同时有 1。

In plain words: the machine does not know the words “X check” and “Z check”; it knows one 144 × 288 table of 0s and 1s with six 1s per row (the first 72 rows have theirs in the left half, the last 72 in the right half). This table is the single input to every downstream computation — rank, logical operators, distance, later decoding simulations all start from it; that is the record's “universal executable baseline”. Why bother merging? Because the symplectic form is the same for every stabilizer code, not just CSS codes: a code that does not separate X from Z (say, with Y in its checks) is written in the same format and the same programs run unchanged. BB codes happen to be CSS, so in their table the two halves never both carry a 1 in the same row.

对易在辛形式里是一句话：两行 r₁ = (x₁ | z₁)、r₂ = (x₂ | z₂) 对易当且仅当 x₁·z₂ + z₁·x₂ 是偶数（每个点积数的是两条串在多少个比特上「一个 X 撞上一个 Z」——正是碰撞定理）。对 S 的行来说：两条 X 检查之间 z 全为零，自动对易；两条 Z 检查同理；一条 X 检查与一条 Z 检查之间只剩 x₁·z₂ = HX 的一行点乘 HZ 的一行，全部为偶就是 HXHZᵀ = 0——直觉教程3.2 节那一行证明 AB + BA = 0 在这里兑现。CheckMatrix.from_css 这个转换器在构造时就会核对这一条（checkmatrix.validate()），不对易的表根本不会被接受。

Commutation is one sentence in the symplectic form: two rows r₁ = (x₁ | z₁), r₂ = (x₂ | z₂) commute iff x₁·z₂ + z₁·x₂ is even (each dot product counts the qubits on which “an X meets a Z” — exactly the collision theorem). For the rows of S: between two X checks the z parts are zero, so they commute automatically; likewise two Z checks; between an X check and a Z check only x₁·z₂ remains, a row of HX dotted with a row of HZ, and all of these even is HXHZᵀ = 0 — where the intuition guide's §3.2 one-line proof AB + BA = 0 is cashed in. The converter CheckMatrix.from_css checks this at construction time (checkmatrix.validate()); a non-commuting table is never accepted.

4.1R3 会装什么：有顺序的测量与瞬时稳定子群What R3 would hold: ordered measurements and instantaneous stabilizer groups

R1、R2 描述的是一个静态对象：144 条检查同时成立，不分先后。但真实的机器一次只测一批检查，先测哪条、后测哪条有讲究，有些码甚至靠测量顺序来定义自己——比如 Floquet 码，每一轮测的是两体算符，稳定子群随时间轮换，任何单一时刻都写不出一张固定的 H。R3「动力学」这一级为这类描述准备：记录一份有序的测量时间表，以及每个时刻的瞬时稳定子群instantaneous stabilizer group, ISG：在测量序列的某一时刻，此刻已被确定为 +1 的全部检查（及其乘积）构成的群。静态稳定子码的 ISG 始终等于它的稳定子群；动态码的 ISG 随时间改变。Atlas 基础页 Measurement schedules & ISGs 讲全了。。

R1 and R2 describe a static object: 144 checks that hold simultaneously, in no order. A real machine measures checks a batch at a time, the order matters, and some codes even define themselves by their measurement order — Floquet codes, for instance, measure two-body operators each round, their stabilizer group rotates in time, and at no single moment can one write down a fixed H. Rung R3 “Dynamics” exists for such descriptions: an ordered measurement schedule together with the instantaneous stabilizer groupISG: at a given moment of the measurement sequence, the group formed by all checks (and their products) currently known to be +1. For a static stabilizer code the ISG always equals its stabilizer group; for dynamic codes it changes in time. The Atlas foundations page “Measurement schedules & ISGs” covers it in full. at each step.

对 BB 码这样的静态稳定子码，R3 的内容是平凡的：无论你以什么顺序测那 144 条检查，每一轮结束后被确定的稳定子群都是同一个——就是 R1 那张 144 × 288 的表张成的群，rank 132。顺序会影响的是电路层面的事情（一个辅助比特的错误会传播到哪几个数据比特），那属于 R4，不属于 R3。所以「R3 无记录」对 BB 条目不是漏写，而是「没有非平凡的东西可记」。Atlas 的规则是：一条 views 记录必须是一句有内容、有出处标签、能被单独核对的断言；「ISG 始终等于稳定子群」对静态码是定义的直接后果，不值得单列一条。

For a static stabilizer code such as a BB code the R3 content is trivial: whatever order you measure the 144 checks in, the stabilizer group fixed at the end of each round is the same one — the group spanned by the R1 table of 144 × 288, rank 132. What the order does affect is a matter of the circuit (to which data qubits an ancilla's error spreads), which belongs to R4, not R3. So “no R3 record” is not an omission for the BB entry but “nothing nontrivial to record”. The Atlas rule: a views record must be a substantive assertion with a provenance label that can be checked on its own; “the ISG always equals the stabilizer group” is an immediate consequence of the definition for a static code and does not earn a record.

The record's second sentence, “split into two planar degree-three coupling layers”, is its core and the reason it earns a record. The surface code's Tanner graph can be drawn on one plane without crossings: every qubit has 4 edges, all to neighbours. Gross's cannot — every qubit has 6 edges, some spanning three sites (the x³ and y³ terms), and any planar drawing crosses. Bravyi et al. show that the 864 edges can be divided into two groups, each of which alone is a crossing-free planar graph, with every node of degree at most 3 within each group. In plain words: build a two-layer chip, each layer ordinary planar wiring, each qubit needing only 3 couplers per layer; stack the layers and connect them with inter-layer couplers, and the degree-6 graph is realised. That is the exact meaning of the intuition guide's §1.2 “the minimal price of giving up locality” and §6.1 “one more layer”. 爬完梯子，回头看八条记录Top of the ladder: the eight records in review

从下往上复述一遍。R1：把 HX、HZ 叠成一张 144 × 288 的辛形式表，rank 132，k = 12，一条重量 12 的逻辑算符（上界）——derived，机器说了算。R2：同一对矩阵是链复形 R → R² → R 的两个边界映射，与全部 Z 检查对易的 X 串有 78 维、其中 66 维是 X 检查的乘积，78 − 66 = 12 就是「中间同调」——derived；另一条记录说对称性能把译码问题的一部分投到环面状圆柱上用匹配——curated，是译码词典不是相等价。R3：无记录，静态码没有非平凡的测量动力学，条目也没导出任何时间信息。R4：Tanner 图 288 个点、864 条边、每比特 3 + 3，文献说能分成两层度 3 的平面图——curated；辅助比特、顺序、方向、重置、探测器五件事一件没导出。R5：多项式（canonical，定义本身）、群代数（curated：对易因为群阿贝尔，BB ⊂ 阿贝尔 2BGA ⊂ 两块码）、商模（curated：dim R/(A,B) = 6 给 k = 12，但秩不是距离，渐近不好）、任意子 / Koszul（curated：拓扑受挫，堵住「六个环面码」）。

Replayed bottom to top. R1: stack HX, HZ into one 144 × 288 symplectic table, rank 132, k = 12, one logical of weight 12 (an upper bound) — derived, the machine's word. R2: the same matrices are the two boundary maps of the complex R → R² → R; X strings commuting with all Z checks span 78 dimensions, 66 of which are products of X checks, and 78 − 66 = 12 is the “middle homology” — derived; the other record says symmetries project part of the decoding problem onto toric-like cylinders where matching works — curated, a decoder dictionary, not a phase equivalence. R3: no record; a static code has no nontrivial measurement dynamics, and the entry exports no time information. R4: a Tanner graph of 288 nodes and 864 edges, 3 + 3 per qubit, splittable per the literature into two planar degree-3 layers — curated; ancillas, order, orientation, reset, detectors, none exported. R5: polynomial (canonical, the definition itself), group algebra (curated: commutation because the group is abelian, BB ⊂ abelian 2BGA ⊂ two-block codes), quotient module (curated: dim R/(A,B) = 6 gives k = 12, but rank is not distance and the asymptotics are bad), anyon / Koszul (curated: topological frustration, blocking “six toric codes”).

带走一个习惯：以后看到「BB 码就是 X」，先问三件事——哪一级，什么标签，它在哪里止步。同一个词「等价」，在 R1 是能重跑的计算，在 R2 的圆柱是译码器的借用，在 R5 的任意子是一篇论文的定理。三者都有价值，但证据等级不同，能推出的结论也不同。

Take one habit with you: when you next read “a BB code is just X”, ask three things — which rung, which label, where does it stop. The one word “equivalent” is a rerunnable computation at R1, a decoder's borrowing in R2's cylinders, and a paper's theorem in R5's anyons. All three have value, but their evidence grades differ, and so do the conclusions they license.
