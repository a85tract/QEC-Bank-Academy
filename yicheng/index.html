一套按码组织的互动教程：环面码、Surface Code、BB 码、qLDPC 码。每个码下面按 Atlas 条目的「侧面」分篇：直觉、译码器、逻辑操作、参数、证书、参考文献……每篇都是单个 HTML 文件，中英文一键切换，所有格点实验与蒙特卡洛在你的浏览器本地运行。教程之间凡提到别处的内容都直接链接到原处，新符号在首次出现处即有解释。 A set of interactive tutorials organised by code: the toric code, the surface code, BB codes, qLDPC codes. Under each code the guides follow the Atlas entry's facets: intuition, decoders, logical operations, parameters, certificates, references… Each guide is a single HTML file, switchable between Chinese and English, with every lattice experiment and Monte-Carlo running locally in your browser. Wherever a guide refers to material elsewhere it links straight to the spot, and every new symbol is explained where it first appears.

关于这套教程About these guides

文件按 <码>/<侧面>/<侧面>.html 存放，高中数学版在文件名后加 -hs；只有一种版本时不加后缀。所有教程共用一套设计系统与交互框架，数字与引用沿用 QEC Atlas 的出处标签（verified、bounded、claimed、demonstrated、proposed），Atlas 站点本身在仓库的 exports/site/ 目录下，可从各篇直接跳转。

Files live at <code>/<facet>/<facet>.html, with -hs appended for the high-school edition when both exist. All guides share one design system and interaction framework, and numbers and citations keep the QEC Atlas provenance labels (verified, bounded, claimed, demonstrated, proposed); the Atlas site itself sits in the repository's exports/site/ folder and is linked from every guide.
