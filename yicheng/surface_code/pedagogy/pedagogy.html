第 1 章Chapter 1

HGP(repL, repL) 就是未旋转的平面贴片HGP(repL, repL) is the unrotated planar patch

直觉教程用剪刀造出表面码；Atlas 的构造器用一条乘法。本章证明两者是同一个对象：从一条 (L−1)×L 的经典矩阵出发，乘出两块量子比特、两张检查矩阵，验证它们对易、只连邻居，并算出 k=1。 The intuition guide built the surface code with scissors; the Atlas constructor builds it with one multiplication. This chapter proves they are the same object: starting from one (L−1)×L classical matrix, multiply out two qubit blocks and two check matrices, verify they commute and touch only neighbours, and compute k=1.

1.1经典因子：一条开链的奇偶矩阵The classical factor: the parity matrix of an open chain

令 H = rep_parity(L)长度 L 的重复码的奇偶检查矩阵：L−1 行、L 列，第 i 行只在第 i、i+1 列为 1，即「相邻两位相等」的检查。，一张 (L−1)×L 的 0/1 矩阵，每行是「相邻两位相等吗」：

Let H = rep_parity(L)The parity-check matrix of the length-L repetition code: L−1 rows, L columns, row i has 1s only in columns i and i+1, i.e. the check “are two neighbouring bits equal?”., an (L−1)×L binary matrix whose rows each ask “are two neighbouring bits equal?”:

H = rep_parity(L) = 1 1 0 0 … 0 1 1 0 … … … 0 1 1 ((L−1) 行rows × L 列columns)

H = 重复码的校验矩阵（每行一条「相邻两位相等」的检查）；L = 家族变量 = 重复码的长度；行数 L−1 = 检查数，列数 L = 经典比特数。H = the repetition code's parity-check matrix (each row one “two neighbours equal” check); L = the family variable = the repetition code's length; L−1 rows = checks, L columns = classical bits.

三个事实。行独立：第 0 列只在第 0 行出现，所以任何「加起来为零」的行组合必须不含第 0 行；去掉它后第 1 列只剩第 1 行，同理……逐列推进，每个系数都被迫为零。于是 rank秩：矩阵里线性独立的行数（= 独立的列数）。这里在模 2 意义下计算。(H) = L−1。核是一维的：ker核（kernel）：使 H·v = 0 的全部向量 v 组成的空间。dim ker H = 列数 − rank(H)。(H) 只有两个元素：零向量与全 1 向量（每对相邻位都相等，只能全 0 或全 1）；全 1 向量是它唯一的基向量，dim ker H = L − (L−1) = 1。转置的核是零维的：Hᵀ 有 L 行、L−1 列且列独立，所以 dim ker Hᵀ = (L−1) − (L−1) = 0。

Three facts. The rows are independent: column 0 appears only in row 0, so any combination of rows summing to zero cannot contain row 0; remove it and column 1 survives only in row 1, and so on, column by column, every coefficient is forced to zero. Hence rankThe number of linearly independent rows (= independent columns) of a matrix, computed here mod 2.(H) = L−1. The kernel is one-dimensional: kerThe kernel: the space of all vectors v with H·v = 0. dim ker H = number of columns − rank(H).(H) has exactly two elements, the zero vector and the all-ones vector (every neighbouring pair equal forces all bits equal, so all 0 or all 1); the all-ones vector is its single basis vector, and dim ker H = L − (L−1) = 1. The transpose kernel is zero-dimensional: Hᵀ has L rows, L−1 independent columns, so dim ker Hᵀ = (L−1) − (L−1) = 0.

rank(H) = L−1　·　dim ker(H) = 1　·　dim ker(Hᵀ) = 0　(最后一条 = 「链是开的」的代数签名the last one = the algebraic signature of an open chain)

rank = 独立行数；ker = 核，即 H·v = 0 的解空间；dim = 维数；ᵀ = 转置；H、L 同上。rank = number of independent rows; ker = kernel, the solution space of H·v = 0; dim = dimension; ᵀ = transpose; H, L as above.

最后那个 0 值得记住。若把链首尾相接成 L 条边的圈，就要多加一行「第 L−1 位与第 0 位相等」——但这一行是前面各行之和，依赖。普通核仍是一维，转置核却变成一维。这一个数字的差别，正是平面与环面的差别（1.4 节）。

Remember that final 0. Close the chain into an L-edge cycle and you add one row, “bit L−1 equals bit 0” — but that row is the sum of all the others: dependent. The ordinary kernel stays one-dimensional while the transpose kernel becomes one-dimensional. That single digit is the whole difference between plane and torus (§1.4).

1.2量子乘积：两块比特、两张矩阵、一次抵消The quantum product: two qubit blocks, two matrices, one cancellation

超图乘积Hypergraph product (HGP)：Tillich–Zémor 的构造，把两条经典检查矩阵 H₁、H₂ 组合成一对对易的量子 CSS 检查矩阵。这里两条都取 H。（HGP，tillich2009quantum）拿两份 H，把量子比特放进两块：比特×比特块，L×L = L² 个；检查×检查块，(L−1)×(L−1) = (L−1)² 个。合计 n = L² + (L−1)² = 2L²−2L+1，正是直觉教程账本里的 d² + (d−1)²。两张检查矩阵各有 L(L−1) 行，用⊗（张量积：A⊗B 把 B 整份复制进 A 的每个 1 所在位置）写成：

The hypergraph productHGP: the Tillich–Zémor construction combining two classical check matrices H₁, H₂ into a commuting pair of quantum CSS check matrices. Here both are H. (HGP, tillich2009quantum) takes two copies of H and places qubits in two blocks: the bit×bit block, L×L = L² qubits; the check×check block, (L−1)×(L−1) = (L−1)² qubits. In total n = L² + (L−1)² = 2L²−2L+1, exactly the d² + (d−1)² of the intuition guide's ledger. The two check matrices, each with L(L−1) rows, are written with ⊗ (the tensor product: A⊗B copies all of B into the position of each 1 in A):

HX = [ H ⊗ IL　|　IL−1 ⊗ Hᵀ ]　·　HZ = [ IL ⊗ H　|　Hᵀ ⊗ IL−1 ]

HX = X 检查矩阵（每行一条 X 检查，每列一个量子比特）；HZ = Z 检查矩阵；H = 重复码校验矩阵；Im = m×m 单位矩阵；⊗ = 张量积；ᵀ = 转置；竖线左边作用于比特×比特块，右边作用于检查×检查块。HX = the X check matrix (one row per X-check, one column per qubit); HZ = the Z check matrix; H = the repetition parity matrix; Im = the m×m identity; ⊗ = tensor product; ᵀ = transpose; left of the bar acts on the bit×bit block, right of it on the check×check block.

CSS 码要求每条 X 检查与每条 Z 检查对易，即重叠格数为偶数；写成矩阵就是 HXHZᵀ = 0（模 2）。两块各贡献一项：

A CSS code needs every X-check to commute with every Z-check, i.e. an even number of overlapping cells; in matrix form, HXHZᵀ = 0 (mod 2). Each block contributes one term:

(H⊗I)(I⊗H)ᵀ = H⊗Hᵀ　·　(I⊗Hᵀ)(Hᵀ⊗I)ᵀ = H⊗Hᵀ　⇒　HXHZᵀ = 2·(H⊗Hᵀ) = 0 (mod 2)

H、I、⊗、ᵀ 同上；HXHZᵀ 的第 (i,j) 个元素 = X 检查 i 与 Z 检查 j 重叠的格数；「= 0 (mod 2)」= 每对检查的重叠都是偶数，即全部对易。H, I, ⊗, ᵀ as above; entry (i,j) of HXHZᵀ = the number of cells where X-check i and Z-check j overlap; “= 0 (mod 2)” = every overlap is even, i.e. all pairs commute.

1.3为什么每条检查只连邻居Why every check touches only neighbours

矩阵没有几何；几何来自构造器给每个下标分配的坐标。比特×比特块的比特 (a,b) 放在 (2b, 2a)；检查×检查块的比特 (a,b) 放在 (2b+1, 2a+1)；X 检查 (a,b) 放在 (2b, 2a+1)；Z 检查 (a,b) 放在 (2b+1, 2a)。这样每条检查行里的每个 1 都连到曼哈顿距离两点在格点上的距离 |Δx| + |Δy|，只沿横竖方向走。恰为 1 的位置。内部检查有四个邻居；到了左右或上下边缘，一个邻居不存在，检查降为三腿。reproduce.py 对每个发布尺寸的每一行都核对了「距离集合 = {1}」，不只对画出来的 L=3。

A matrix has no geometry; the geometry comes from the coordinates the constructor assigns to each index. A bit×bit qubit (a,b) sits at (2b, 2a); a check×check qubit (a,b) at (2b+1, 2a+1); an X-check (a,b) at (2b, 2a+1); a Z-check (a,b) at (2b+1, 2a). Then every 1 in a check row joins a site at Manhattan distanceThe distance |Δx| + |Δy| between two lattice points, walking only horizontally and vertically. exactly one. Interior checks have four neighbours; at a left/right or top/bottom edge one neighbour is missing and the check drops to three legs. reproduce.py checks “distance set = {1}” for every row of every shipped size, not only the drawn L=3.

方向约定Orientation convention

在 Atlas 的坐标里，三腿 Z 检查在上下两边（y=0 与 y=4），三腿 X 检查在左右两边（x=0 与 x=4）。按直觉教程对边界的定义，Z 检查缺腿的边是毛边界、X 检查缺腿的边是光边界，所以这里毛边界在上下、光边界在左右——与直觉教程的图恰好转了 90°。读坐标时请以「哪种检查缺腿」为准，不要以「左右/上下」为准。

In the Atlas coordinates the three-leg Z-checks lie on the top and bottom edges (y=0 and y=4) and the three-leg X-checks on the left and right (x=0 and x=4). By the intuition guide's definition of the boundaries, the edge where Z-checks lose a leg is rough and where X-checks lose a leg is smooth, so here rough is top/bottom and smooth is left/right — rotated 90° relative to the intuition guide's pictures. Read coordinates by “which check is truncated”, not by “left/right versus top/bottom”.

1.4为什么 k = 1Why k = 1

每张量子检查矩阵有 L(L−1) 行。它们独立吗？HGP 有一条秩恒等式：rank(HX) = rank(H)·L + (L−1)·rank(H) − rank(H)²。代入 rank(H) = L−1：

Each quantum check matrix has L(L−1) rows. Are they independent? The HGP has a rank identity: rank(HX) = rank(H)·L + (L−1)·rank(H) − rank(H)². Substituting rank(H) = L−1:

rank(HX) = (L−1)L + (L−1)(L−1) − (L−1)² = L(L−1)　·　rank(HZ) = L(L−1)　⇒　k = [L² + (L−1)²] − 2L(L−1) = 1

HX, HZ = 两张量子检查矩阵；rank = 独立行数 = 独立检查数；L = 家族变量；L² + (L−1)² = n = 物理比特数；k = 逻辑比特数 = n − 独立检查总数。HX, HZ = the two quantum check matrices; rank = independent rows = independent checks; L = the family variable; L² + (L−1)² = n = physical qubits; k = logical qubits = n − total independent checks.

码距恰好是 L：一条串、L 条切口、一次枚举The distance is exactly L: one string, L cuts, one enumeration

「最短横跨串走 L 条边」是一张图，不是一个证明：它只说明码距不超过 L。真正的定理有两半。本章先给上界，再用 L 条互不相交的等价代表元证下界，最后看机器对 L=3、4 枚举、对 L=5 只敢说 bounded。 “The shortest spanning string uses L edges” is a picture, not a proof: it only shows the distance is at most L. The real theorem has two halves. This chapter gives the upper bound first, then proves the lower bound with L pairwise-disjoint equivalent representatives, and finally watches the machine enumerate L=3, 4 and say only “bounded” at L=5.

定理Theorem

对 L ≥ 2 的 HGP(repL, repL)，每个非平凡的逻辑 Pauli 算符的重量weight，记 wt(P)：算符 P 非平凡作用（X、Y 或 Z）的量子比特个数。至少为 L，且存在重量为 L 的 X 逻辑与 Z 逻辑。即 d = L。

For HGP(repL, repL) with L ≥ 2, every nontrivial logical Pauli has weightwt(P): the number of qubits on which the operator P acts nontrivially (X, Y or Z). at least L, and weight-L X and Z logicals exist. That is, d = L.

2.1上界：一行 X 与一列 ZUpper bound: one X row and one Z column

给比特×比特块编号 (a,b)，0 ≤ a,b < L。固定 a，在全部 (a,b) 上放 X，得一条横穿的「X 行」（图 1.1 里就是同一条 y=2a 水平线上的实心点）。每条 Z 检查位于 (2b'+1, 2a')，只有 a'=a 时才碰到这一行，而且恰碰两个比特 (a,b') 与 (a,b'+1)——0 或 2 次，永远对易。固定 b，在全部 (a,b) 上放 Z，得一条竖穿的「Z 列」，同理与每条 X 检查相遇 0 或 2 次。

Index the bit×bit block by (a,b), 0 ≤ a,b < L. Fix a and put X on every (a,b): a horizontal “X row” (in Fig. 1.1, the filled dots on one line y=2a). A Z-check at (2b'+1, 2a') meets this row only when a'=a, and then in exactly two qubits (a,b') and (a,b'+1) — zero or two times, always commuting. Fix b and put Z on every (a,b): a vertical “Z column”, likewise meeting every X-check zero or two times.

一行与一列恰好相交一次（在 (a,b)），所以按碰撞规则两者反对易。与某个通过全部检查的算符反对易的东西，不可能是稳定子（稳定子与一切通过检查的算符对易）；反过来亦然。所以两条串都不是稳定子，都是逻辑算符，重量都是 L。于是 d ≤ L。

A row and a column intersect exactly once (at (a,b)), so by the collision rule they anticommute. Anything anticommuting with an operator that passes every check cannot be a stabilizer (stabilizers commute with everything that passes the checks), and vice versa. So neither string is a stabilizer; both are logicals of weight L. Hence d ≤ L.

XL = X-行-row {(a,b): b = 0…L−1}　·　ZL = Z-列-column {(a,b): a = 0…L−1}　·　|行∩列row∩column| = 1 ⇒ 反对易anticommute　·　wt = L ⇒ d ≤ L

XL / ZL = 逻辑 X / 逻辑 Z；(a,b) = 比特×比特块的行、列下标；|·| = 集合的元素个数；wt = 重量（非平凡作用的比特数）；d = 码距；L = 家族变量。XL / ZL = logical X / logical Z; (a,b) = row and column index in the bit×bit block; |·| = number of elements of a set; wt = weight (qubits acted on nontrivially); d = distance; L = the family variable.

2.2L 条互不相交的等价代表元L pairwise-disjoint equivalent representatives

共有 L 条 X 行（a = 0…L−1）与 L 条 Z 列。它们代表同一个逻辑算符吗？看相邻两行 a 与 a+1 之间的那条「带」：X 检查 (a, b') 位于 (2b', 2a+1)，b' = 0…L−1，各连着上下两个比特×比特比特 (a,b')、(a+1,b') 和左右两个检查×检查比特。把带里全部 L 条 X 检查乘起来：每个检查×检查比特 (a,b'') 被左右两条检查各碰一次，成对抵消；剩下的恰好是整条第 a 行加整条第 a+1 行。所以「行 a」×「行 a+1」= 稳定子，两行等价。逐带推进，全部 L 条 X 行都在同一个逻辑类里。对 Z 列，用 Z 检查组成的竖直带做同样的事。

There are L X-rows (a = 0…L−1) and L Z-columns. Do they represent the same logical? Look at the “strip” between adjacent rows a and a+1: the X-checks (a, b') at (2b', 2a+1), b' = 0…L−1, each join the two bit×bit qubits (a,b'), (a+1,b') above and below and the check×check qubits to their left and right. Multiply all L X-checks in the strip: every check×check qubit (a,b'') is touched once by the check on its left and once by the one on its right, cancelling in pairs; what remains is exactly row a plus row a+1. So “row a” × “row a+1” = a stabilizer, and the two rows are equivalent. Strip by strip, all L X-rows lie in one logical class. For Z-columns, do the same with vertical strips of Z-checks.

∏b' X-check(a,b') = X-行-row(a) · X-行-row(a+1)　⇒　全部 L 行等价all L rows equivalent　·　同一族内支撑两两不交supports within a family pairwise disjoint

∏ = 连乘；X-check(a,b') = 位于 (2b', 2a+1) 的 X 检查；X-行(a) = 第 a 行全部比特×比特比特上的 X；L = 行数。∏ = product; X-check(a,b') = the X-check at (2b', 2a+1); X-row(a) = X on every bit×bit qubit of row a; L = number of rows.

同时，同一族内各条代表元的支撑两两不相交：行 a 与行 a' 没有公共比特。这两点合起来（等价 + 不交）就是下界的全部弹药。

At the same time, the representatives within one family have pairwise disjoint supports: row a and row a' share no qubit. These two facts together (equivalent + disjoint) are all the ammunition the lower bound needs.

2.3下界：每条切口都得碰到Lower bound: every cut must be met

因为 k = 1，每个非平凡逻辑类都能写成 XLaZLb，其中指数 a、b 各取 0 或 1（「用不用这个生成元」的开关位，与 2.1 节的坐标下标 (a,b) 无关），且 (a,b) ≠ (0,0)：三种取法给出 XL、ZL、YL = XLZL。设 P 是任意一个非平凡逻辑算符。它至少与 XL、ZL 之一反对易（若两者都对易，它就与全部逻辑算符对易，只能是稳定子，平凡）。

Since k = 1, every nontrivial logical class is XLaZLb, where the exponents a, b are bits, each 0 or 1 (an on/off switch for that generator, unrelated to the coordinate indices (a,b) of §2.1), with (a,b) ≠ (0,0): the three choices give XL, ZL, YL = XLZL. Let P be any nontrivial logical. It anticommutes with at least one of XL, ZL (commuting with both would mean commuting with every logical, hence a stabilizer, hence trivial).

设 P 与 Z 类反对易。关键一步：与类反对易 = 与类中每个代表元反对易，因为给一个代表元乘上稳定子，不会改变它与逻辑算符的对易性（稳定子与 P 对易）。于是 P 与全部 L 条 Z 列都反对易。要与一条纯 Z 的列反对易，P 必须在这条列上某处有 X 或 Y 支撑。L 条列互不相交，所以 P 至少在 L 个不同的比特上非平凡：wt(P) ≥ L。若 P 与 X 类反对易，换成 L 条不相交的 X 行，同理。

Suppose P anticommutes with the Z class. The key step: anticommuting with a class = anticommuting with every representative of it, because multiplying a representative by a stabilizer cannot change its commutator with a logical (stabilizers commute with P). So P anticommutes with all L Z-columns. To anticommute with a pure-Z column, P must have X or Y support somewhere on that column. The L columns are disjoint, so P is nontrivial on at least L distinct qubits: wt(P) ≥ L. If instead P anticommutes with the X class, use the L disjoint X-rows, and the same argument runs.

每个非平凡逻辑 P 与 XL 或 ZL 反对易every nontrivial logical P anticommutes with XL or ZL　⇒　与 L 条不交代表元都反对易anticommutes with L disjoint representatives　⇒　wt(P) ≥ L　·　合上界with the upper bound: d = L ∎

P = 任意非平凡逻辑算符；XL, ZL = 逻辑 X、Z；wt(P) = P 的重量；d = 码距；L = 家族变量；∎ = 证毕。P = any nontrivial logical operator; XL, ZL = logical X, Z; wt(P) = the weight of P; d = distance; L = the family variable; ∎ = end of proof.

这个论证的「学名」：有限贴片版的收缩系论证The argument's formal name: a finite-patch systolic argument

L 条不相交的代表元构成 L 道彼此独立的「切口」，任何与该类共轭的算符都必须穿过每一道。在拓扑码的语言里，这是「同调类的最短代表元长度」（收缩系，systole）的有限版本：不用画图、不靠小尺寸枚举，只用等价性与不相交性两个可机器核对的事实。reproduce.py 恰好断言了这两个事实（对 L=3,4,5）。

The L disjoint representatives form L independent “cuts”, and any operator conjugate to the class must cross every one. In the language of topological codes this is the finite version of “the shortest representative of a homology class” (the systole): no drawing, no small-size enumeration, only two machine-checkable facts, equivalence and disjointness. reproduce.py asserts precisely those two facts (for L=3,4,5).

Write the support of an X error as a 0/1 vector eX (length n, a 1 on each faulty qubit). 4.4为什么要 d 轮，而且不是简单表决Why d rounds, and why not a bare majority vote

如果唯一可能的故障是「每轮独立地翻转一次推断出的缝合奇偶」，那么重复测量再表决，就是一条时间方向的一维重复码，d 轮给出时间方向的码距 d。这个玩具约化不是完整的容错论证。真实的提取电路还有数据错误、辅助比特传播、以及跨越合并起点或终点的故障；它们在空间与时间上造出相关的探测事件，还可能改变「正在追踪的是联合逻辑观测量的哪个代表元」。所以合并期间的症状必须作为一段时空历史整体译码：跑 d 轮提供时间方向的码距，而把缝合探测器与体内探测器合起来推断逻辑奇偶的，是译码器，不是裸表决。格点手术教程在一次读错就够了与真相：不是表决，是时空译码两节里把这件事讲透了。

If the only possible fault were an independent flip of the inferred seam parity in each round, repeating the measurement and voting would be a one-dimensional repetition code in time, and d rounds would supply timelike distance d. That toy reduction is not the full fault-tolerance argument. Real extraction circuits also contain data faults, ancilla propagation, and faults crossing the start or end of the merge; they create correlated detection events in space and time, and can change which representative of the joint logical observable is being tracked. The merge syndrome must therefore be decoded as one spacetime history: running d rounds supplies timelike distance, and it is the decoder, not a bare majority rule, that combines seam and bulk detectors to infer the logical parity. The lattice-surgery guide covers this thoroughly in one misread is enough and the truth: not a vote but spacetime decoding.

绝不跨行比较Never compare across rows

5.2为什么 10.9% 与 10.3% 不同Why 10.9% and 10.3% differ

固定一个症状，某个逻辑类的概率是该类中全部错误链的概率之和。在随机键 Ising 模型的映射里，这个和是一个配分函数；最优译码在 Nishimori 线上比较各类的自由能。最小链译码器只比较能量（最短链的长度），丢掉了近乎退化的众多路径贡献的熵。所以这 0.6 个百分点的差距是同一个完美症状模型内部「译码器 / 统计力学」的区别，不是同一个数字的实验误差。这正是 3.3 节路径退化的数字后果，译码器教程在退化一节算过一个可以数出来的例子。

Fix a syndrome; the probability of a logical class is the sum over all error chains in that class. In the random-bond Ising mapping this sum is a partition function, and optimal decoding compares free energies on the Nishimori line. A minimum-chain decoder compares only energies (the length of the shortest chain) and discards the entropy contributed by the many nearly degenerate paths. So the 0.6-percentage-point gap is a decoder/statistical-mechanics distinction inside one perfect-syndrome model, not experimental uncertainty on one number. It is the numerical consequence of §3.3's path degeneracy; the decoders guide works a countable example in its degeneracy section.

5.3为什么 2.9% 不是门阈值Why 2.9% is not a gate threshold

加入带噪的症状比特，就多了一个时间方向，配对问题变成三维的匹配 / 规范问题（译码器教程第 5 章）。但现象学模型里的「每轮数据错误率」与「每轮测量比特翻转率」没有指定任何物理位置：没有制备、CNOT、空闲、泄漏、复位、读出。这个阈值对译码器物理很有价值，却不能与一个电路位置阈值直接比较。

Adding noisy syndrome bits creates a time direction and turns matching into a three-dimensional matching/gauge problem (Chapter 5 of the decoders guide). But the phenomenological “data error per round” and “measurement-bit flip per round” specify no physical locations: no preparation, CNOT, idle, leakage, reset or readout. The threshold is valuable for decoder physics yet cannot be compared directly with a circuit-location threshold.

5.4为什么 0.57% 的换算用八步Why the 0.57% conversion uses eight steps

Fowler 等人的模拟把 p 定义为每步的故障率，并明确使用每周期八步；文中「约 4% 每周期」是那个模型的换算。另一种六层电路也可以是合法的表面码调度，但不能把 Fowler 的八步换算直接贴到它身上——必须重建噪声账。归一化（每位置、每步、每轮、每周期、每单位时间）是账本的必填字段。

Fowler et al.'s simulation defines p per step and explicitly uses eight steps per cycle; the quoted “roughly four percent per cycle” is the conversion for that model. A different six-layer circuit may also be a valid surface-code schedule, but Fowler's eight-step conversion cannot be attached to it without rebuilding the noise accounting. Normalization (per location, step, round, cycle, or unit time) is a required field of the ledger.

关键想法Key idea

阈值不是检查矩阵的性质，是「码 + 噪声模型 + 症状模型 + 译码器 + 归一化」五元组的性质。Atlas 因此不给表面码一个阈值，而给一本账；页面上凡出现两个阈值数字，都必须说明它们来自不同的行。

A threshold is not a property of a check matrix; it is a property of the five-tuple “code + noise model + syndrome model + decoder + normalization”. The Atlas therefore gives the surface code not one threshold but one ledger, and wherever two threshold numbers appear on a page they must be declared as coming from different rows.

Q1 · 哪一个秩的事实把这个平面码与环面码区分开？Q1 · What single rank fact distinguishes this planar code from the toric code?

开链的重复码矩阵是 (L−1)×L 且行满秩，所以它的转置码维数为零。闭合成圈会多出一条行关系，让转置维数变成一。在 HGP 公式里，这把 1·1 + 0·0 = 1 变成 1·1 + 1·1 = 2（1.4 节）。

The open-chain repetition matrix is (L−1)×L with full row rank, so its transpose code has dimension zero. Closing the chain creates one row relation, making the transpose dimension one. In the HGP formula this turns 1·1 + 0·0 = 1 into 1·1 + 1·1 = 2 (§1.4).

Q2 · 为什么 d = L 是一个证明，而不是一张长度 L 的串的图？Q2 · Why is d = L a proof rather than a picture of one length-L string?

一行与一列只证上界。下界用每个逻辑类的 L 条不相交代表元：任何与该类反对易的算符必须碰到每一条代表元，因而至少占 L 个比特。代表元的等价性与不交性由 reproduce.py 核对（2.2–2.3 节）。

A length-L row and column prove only the upper bound. The lower bound uses L disjoint representatives of each logical class: anything anticommuting with the class must touch every representative, hence at least L qubits. Representative equivalence and disjointness are checked by reproduce.py (§2.2–§2.3).

Q3 · 为什么 XZZX 在纯退相位噪声下能达到 50%，而 CSS 表面码不能？Q3 · Why does XZZX reach 50% under pure dephasing while the CSS surface code does not?

纯 Z 错误在两种描述里都只激活一种症状。XZZX 额外带来对角线上的奇偶守恒，把二维问题拆成互相独立的重复码；CSS 没有这种一维分解，保持约 10.9% 的最优码容量阈值（账本第一行）。XZZX 不在本教程范围内，见「关系」侧面与 bonilla2021xzzx。

Pure Z errors activate only one syndrome type in either description. XZZX adds a diagonal parity conservation law that splits the two-dimensional problem into independent repetition codes; CSS lacks that one-dimensional decomposition and retains its roughly 10.9% optimal code-capacity threshold (ledger row one). XZZX is outside this tutorial's scope; see the Relations facet and bonilla2021xzzx.

Q4 · 可以把 10.9%、2.9%、0.57% 当作同一个阈值的三个估计来比较吗？Q4 · May one compare 10.9%, 2.9% and 0.57% as three estimates of the same threshold?

不可以。它们分别指完美症状的码容量噪声、逐轮重复的现象学数据 / 测量噪声、一个特定的调度电路级模型。基本故障位置与译码器都不同（5.1 节的账本）。

No. They refer respectively to perfect-syndrome code-capacity noise, repeated phenomenological data/measurement noise, and a particular scheduled circuit-level model. Their elementary fault locations and decoders differ (the ledger of §5.1).

Q5 · 为什么 d 轮手术不只是「时间上的多数表决」？Q5 · Why are d surgery rounds not simply “majority vote in time”?

若只有缝合读数的独立翻转，重复采样确实约化为一条重复码。真实的症状电路还含数据故障与传播故障，造出相关的时空探测事件；逻辑奇偶要由时空译码器与这些事件一并推断（4.4 节）。

If only independent seam-outcome flips occurred, repeated parity samples would reduce to a repetition code. Real syndrome circuits also contain data and propagated faults, which create correlated spacetime detection events; the logical parity is inferred jointly with those events by a spacetime decoder (§4.4).

Q6 · 算上辅助比特，未旋转贴片一共用多少比特？Q6 · How many qubits does the unrotated patch consume when ancillas are counted?

数据比特 2d²−2d+1，独立检查比它少一条，每条检查配一个专用辅助比特，总数 4d²−4d+1。旋转版是 d² 个数据加 d²−1 个辅助，共 2d²−1。reproduce.py 对 d=3 与 d=12 断言了这两条公式：d=3 时未旋转 13/25、旋转 9/17；d=12 时未旋转 265/529、旋转 144/287（数据 / 总数）。

2d²−2d+1 data qubits and one fewer independent checks, so one dedicated ancilla per check gives 4d²−4d+1 in total. The rotated totals are d² data plus d²−1 ancillas, or 2d²−1. reproduce.py asserts both formulas at d=3 and d=12: unrotated 13/25 and rotated 9/17 at d=3; unrotated 265/529 and rotated 144/287 at d=12 (data / total).

Q7 · 对每个比特做物理 H，就已经是逻辑 H 了吗？Q7 · Is physical H on every qubit already a logical H?

不是。它把码换成了它的对偶。逻辑门是横向 H 加上 90° 的几何重标记；要恢复固定的平面版图需要码形变。S 门只有在镜像对偶的折叠版图可用时才是常数深度。这些操作对应 Atlas 本条目「逻辑操作」侧面里的「H / S · fold-transversal」记录（出处 J. E. Moussa「Transversal Clifford gates on folded surface codes」，2016，moussa2016transversal；代价：常数深度门加一次折叠或等价的比特置换），Atlas 对它标 claimed。

No. It exchanges the code with its dual. The logical gate is transversal H plus the 90-degree geometry relabelling; restoring a fixed planar footprint requires code deformation. An S gate is constant depth only once the mirror-dual folded layout is available. These operations correspond to the “H / S · fold-transversal” record in this entry's Atlas Logical operations facet (source: J. E. Moussa, “Transversal Clifford gates on folded surface codes”, 2016, moussa2016transversal; cost: constant-depth gates plus a fold or an equivalent qubit permutation), which the Atlas labels claimed.

Q8 · 究竟是什么禁止了逻辑 T？Q8 · What precisely forbids logical T?

在码距不断增长的二维拓扑 Pauli 稳定子码上，任何有界深度、有界作用范围的电路只能诱导 Clifford 层级第二层的操作；T 在第三层。注入与码切换之所以可行，是因为它们添加了资源，或者离开了这条定理的某个假设。见格点手术教程「一条天花板：Bravyi–König」。

A bounded-depth, bounded-range circuit on a growing-distance two-dimensional topological Pauli stabilizer code induces a level-two Clifford-hierarchy operation; T is level three. Injection and code switching work because they add a resource or leave an assumption of that theorem. See the lattice-surgery guide's “a ceiling: Bravyi–König”.

XLaZLb上标 a、b，读「X 逻辑的 a 次方乘 Z 逻辑的 b 次方」Superscripts a, b, read “X-logical to the a times Z-logical to the b”a、b 各取 0 或 1，是「用不用这个生成元」的开关位；(1,0)、(0,1)、(1,1) 分别给出 XL、ZL、YL = XLZL，(0,0) 是恒等。与 2.1 节的坐标下标 (a,b) 无关。a, b are bits, each 0 or 1, on/off switches for the generators; (1,0), (0,1), (1,1) give XL, ZL, YL = XLZL, and (0,0) is the identity. Unrelated to the coordinate indices (a,b) of §2.1.
ZLA　XLC上标大写字母，读「贴片 A 的逻辑 Z」Capital superscript, read “the logical Z of patch A”上标标记算符所在的贴片：A、B = 4.2 节合并的两块贴片；C、A、T = CNOT 里的控制、辅助、目标贴片。The superscript names the patch an operator lives on: A, B = the two patches merged in §4.2; C, A, T = the control, ancilla and target patches of the CNOT.
∏大写希腊字母 π，读「派」Capital Greek π, read “pie”连乘记号。∏b' X-check(a,b') = 一条带里全部 X 检查的乘积；∏ 缝合检查 = ZL⊗ZL。The product sign. ∏b' X-check(a,b') = the product of all X-checks in a strip; ∏ seam checks = ZL⊗ZL.
⊕圆圈加，读「异或」Circled plus, read “X-OR”合并两组比特、成对相消（模 2 加法）。E⊕C = 错误加修复。Merge two sets of qubits with pairwise cancellation (addition mod 2). E⊕C = error plus repair.
⌈　⌉直角括号，读「向上取整」Square-cornered brackets, read “ceiling”⌈d/2⌉ = d 的一半，不足则进一：凑出一次逻辑失败至少需要的故障数。⌈d/2⌉ = half of d, rounded up: the minimum number of faults for one logical failure.
Λ大写希腊字母 lambda，读「拉姆达」Capital Greek lambda, read “LAM-da”压制因子：d 加 2 时逻辑错误率缩小的倍数，由整套器件与译码器拟合。Willow 报告 2.14 ± 0.02。不是阈值，不等于 pth/p。The suppression factor: how much the logical error rate shrinks per d→d+2, fitted from the whole device-and-decoder stack. Willow reports 2.14 ± 0.02. Not a threshold; not pth/p.
≤　≥　≠　≈　±读「小于等于 / 大于等于 / 不等于 / 约等于 / 正负」Read “at most / at least / not equal / approximately / plus-minus”d ≤ L 与 d ≥ L 合起来是 d = L；0.1031 ± 0.0001 表示报告值与其不确定度。d ≤ L and d ≥ L together give d = L; 0.1031 ± 0.0001 is a reported value with its uncertainty.
⇒　⇔　∈　∎读「推出 / 当且仅当 / 属于 / 证毕」Read “implies / if and only if / belongs to / Q.E.D.”逻辑记号：A ⇒ B 由 A 得 B；A ⇔ B 互为充要；x ∈ S 表示 x 是集合 S 的成员；∎ 标记证明结束。Logic marks: A ⇒ B derives B from A; A ⇔ B are equivalent; x ∈ S says x is a member of the set S; ∎ marks the end of a proof.
|+⟩读「加态」（plus ket）Read “plus ket”(|0⟩+|1⟩)/√2，X 值确定为 +1 的单比特状态；缝合比特的初态。(|0⟩+|1⟩)/√2, the single-qubit state with X value fixed at +1; the seam qubits' initial state.
