补件工坊：矩阵、复数、二项分布The parts shop: matrices, ℂ, binomial

1.1矩阵：给「对向量的操作」记账Matrices: bookkeeping for operations on vectors

你熟悉平面向量 v = (x, y)。现在我们需要描述对向量的操作——把一个向量变成另一个向量的规则。最有用的一类操作是「线性」的：新坐标是旧坐标的固定组合。这样的操作只需 4 个数就能完全记录，把它们排成 2×2 的方阵，称为矩阵，并规定它作用在（竖着写的）向量上的方式：

You know plane vectors v = (x, y). We now need to describe operations on vectors — rules turning one vector into another. The most useful ones are “linear”: each new coordinate is a fixed mix of the old ones. Four numbers record such a rule completely; arrange them in a 2×2 array, call it a matrix, and define how it acts on a (column-written) vector:

M = m₁₁m₁₂m₂₁m₂₂,　v = xy　⇒　M·v = m₁₁x + m₁₂ym₂₁x + m₂₂y　(每一行「点乘」一次 veach row “dots” v once)

立刻认识两位主角。交换矩阵 S 与变号矩阵 D：

Meet the two protagonists at once: the swap matrix S and the re-sign matrix D:

S = 0110: xy ↦ yx　·　D = 100−1: xy ↦ x−y　(↦ 读「映到」：左边的向量被送到右边的向量↦ reads “maps to”: the left vector is sent to the right one)

连续做两个操作呢？「先 B 后 A」把 v 变成 A(B·v)。存在唯一的矩阵把这两步并成一步，记作 AB，叫矩阵乘法：AB 的第 i 行第 j 列元素 = A 的第 i 行与 B 的第 j 列对应相乘再相加（和上面「行点乘向量」同一动作，逐列做一遍）。「什么都不做」也有矩阵：单位矩阵 I（对角线 1，其余 0），满足 I·v = v，且 S² = D² = I（交换两次、变号两次都回到原样）。

Two operations in a row? “B then A” sends v to A(B·v). A unique matrix does both in one step; write it AB and call the recipe matrix multiplication: entry (i, j) of AB = row i of A dotted with column j of B (the same row-dot move as above, done column by column). “Do nothing” has a matrix too: the identity I (ones on the diagonal), with I·v = v and S² = D² = I (swapping twice or re-signing twice restores everything).

Now the most important exercise in this tutorial. Compute SD and DS by hand (feed D's columns to S's rows; then the reverse):

SD = 0−110　·　DS = 01−10　⇒　DS = −SD
关键想法Key idea

矩阵乘法在乎顺序。S 和 D 交换顺序后恰好差一个整体负号——这个看似无关痛痒的 −1，将成为整座量子纠错大厦的承重梁。（顺带记下两条平安无事的性质：结合律 A(BC)=(AB)C 恒成立；只是交换律没了。）

Matrix multiplication cares about order. Swapping S and D costs exactly one overall minus sign — and this innocuous-looking −1 will carry the weight of the entire edifice of quantum error correction. (For the record, associativity A(BC)=(AB)C always holds; only commutativity is lost.)

1.2复数一页通Complex numbers, one page

回炉三件事：z = a + bi（i² = −1）；模 |z| = √(a²+b²)；共轭 z̄ = a − bi，且 z·z̄ = |z|²。量子力学的「配比数字」（振幅）一般是复数，概率永远等于模的平方 |z|²——本教程的公式将一律写成 |·|² 以保持通用，但主线的所有例子里振幅都是实数（此时 |a|² 就是 a²），你不会在任何一步真的被复数拦住。

Three re-polished facts: z = a + bi (i² = −1); modulus |z| = √(a²+b²); conjugate z̄ = a − bi with z·z̄ = |z|². Quantum “blend numbers” (amplitudes) are complex in general, and probability is always the modulus squared |z|² — our formulas will be written with |·|² for full generality, though in every worked example of the main path the amplitudes are real (where |a|² is just a²), so no step will ever actually strand you in ℂ.

z = a+bi　·　|z|² = z·z̄ = a²+b²　·　|z₁z₂| = |z₁||z₂|
为什么大自然坚持用复数？Why does nature insist on ℂ?

因为量子演化既要「转动」状态又要严格保持长度（概率总和为 1），二维里能连续转动且保长度的数系恰好是复数的乘法。教程主线用到的两种操作（交换、变号）碰巧都是实矩阵，所以我们可以全程待在实数里；但完整的操作清单里还有第三位成员 Y——它的矩阵含 i（第 3 章见）——以及一切「旋转角度」类操作。丢掉复数，量子力学的门就只剩一半。

Because quantum evolution must “rotate” states while exactly preserving length (total probability 1), and the number system whose multiplication rotates-and-preserves in two dimensions is precisely ℂ. The two operations our main path needs (swap, re-sign) happen to be real matrices, so we may stay in ℝ throughout; but the full roster includes a third member Y — whose matrix contains i (Chapter 3) — and every “rotate by an angle” operation. Drop ℂ and half of quantum mechanics' doors close.

经典纠错热身Classical warm-up

量子纠错的每个动作都是经典动作的升级。先在普通比特的世界里，把「出错—检查—修复」全套流程与两条中心思想（冗余、只查奇偶不读内容）拿到手。 Every quantum move upgrades a classical one. First, in the world of ordinary bits, collect the full fail–check–repair routine and its two central ideas: redundancy, and parity-only checks that never read content.

2.2重复码与二项分布Repetition & the binomial

最老的对策：发 0 记作 000、发 1 记作 111（编码：1 个「逻辑比特」写进 3 个「物理比特」），接收后多数表决。至少 2 个比特同时翻转才会译错，用 1.3 的二项分布立刻写出失败概率：

The oldest countermeasure: send 0 as 000, 1 as 111 (encoding: one “logical bit” written into three “physical bits”), then decode by majority vote. It fails only when ≥2 bits flip, so §1.3's binomial delivers the failure probability at once:

pL = C(3,2)·p²(1−p) + C(3,3)·p³ = 3p² − 2p³

什么时候划算？解不等式 3p² − 2p³ < p：除以 p（p>0），得 2p² − 3p + 1 > 0，因式分解 (2p−1)(p−1) > 0，而 p < 1 使第二个因子为负，故需 2p−1 < 0，即 p < 1/2。结论：只要信道「好过抛硬币」，重复就有利可图，且 p 越小、pL ≈ 3p² 的压缩越悬殊——p = 1% 时失败率降到约 0.03%。这种「错误率从 p 降到 ~p² 量级」的交易是一切纠错码的心脏。模拟对照理论：

When does it pay? Solve 3p² − 2p³ < p: divide by p (p>0) to get 2p² − 3p + 1 > 0, factor as (2p−1)(p−1) > 0; since p < 1 makes the second factor negative, we need 2p − 1 < 0, i.e. p < 1/2. Whenever the channel beats a coin flip, repetition pays — and the smaller p, the more lopsided the pL ≈ 3p² compression: at p = 1% the failure rate drops to ≈0.03%. 2.3奇偶检查：只问「一样吗」，得到症状Parity checks: ask only “equal?”, obtain the syndrome

多数表决有个隐藏动作——它读出了全部三个比特。经典世界无所谓；但第 3 章会证明，量子信息一被读取就受损。所以现在改练一种永不读内容的检修法：只测两个奇偶量 s₁ = b₁⊕b₂、s₂ = b₂⊕b₃（⊕ 表示模 2 加法：相同得 0，不同得 1）。读数 (s₁, s₂) 称为症状，四种取值恰好区分「无错 / 翻了 b₁ / 翻了 b₂ / 翻了 b₃」，而对内容 000 还是 111 一无所知：

Majority voting hides a step — it reads all three bits. Harmless classically; but Chapter 3 will prove that reading damages quantum information. So we now train a repair method that never reads content: measure only the two parities s₁ = b₁⊕b₂, s₂ = b₂⊕b₃ (⊕ is addition mod 2: equal gives 0, different gives 1). The reading (s₁, s₂) is called the syndrome; its four values exactly separate “no error / b₁ flipped / b₂ / b₃”, while revealing nothing about whether 000 or 111 is stored:

(0,0) → 无错clear　·　(1,0) → b₁　·　(1,1) → b₂　·　(0,1) → b₃
关键想法Key idea

症状指认错误而不泄露内容——「知错而不知情」。量子世界只允许这一种体检；toric code 就是把这个想法放大成一整张网格。

The syndrome names the error without betraying the content — “know the fault, not the secret”. It is the only physical exam the quantum world permits; the toric code is this idea scaled to a whole grid.

第 3 章Chapter 3

量子比特：ℂ² 里的单位向量The qubit: a unit vector in ℂ²

量子力学对一个两状态系统的全部规定，用三条公设就能写完：状态是单位向量、操作是矩阵、测量按模方掷骰子并坍缩。这一章把三条全部立起来，并让第 1 章那对矩阵 S、D 亮出真名。 Quantum mechanics legislates a two-state system in three postulates: states are unit vectors, operations are matrices, measurement rolls dice by modulus-squared and collapses. This chapter erects all three — and lets Chapter 1's matrices S, D reveal their true names.

3.1公设一与公设三：状态与测量Postulates one & three: states and measurement

一个量子比特遵循量子力学的两状态系统（原子的两个能级、超导电路……）。英文 qubit。的两个「纯读数」记作 |0⟩ 与 |1⟩（读 ket 0 / ket 1——就是给基向量起的名字），并规定它们是二维空间的标准基：

|0⟩ = 10,　|1⟩ = 01　⇒　一般状态general state |ψ⟩ = a|0⟩ + b|1⟩ = ab,　a, b ∈ ℂ,　|a|² + |b|² = 1

先认三个记号：状态惯例命名为 ψ（希腊字母，读「普西」）；ℂ 是双线体大写 C，读「复数集」，ℂ² 即两个复数组成的向量全体；∈ 读「属于」。公设一（状态）：系统的状态是一个长度为 1 的向量（分量叫振幅状态向量的分量，一般为复数；测得对应结果的概率 = 振幅的模方。，可以为负、甚至为复数）。公设三（测量）：在 0/1 基上测量，得 0 的概率是 |a|²、得 1 的概率是 |b|²（模方规则，因此要求长度 1：|a|²+|b|²=1 就是概率归一）；测量后状态坍缩为所得的那个基向量，原振幅信息即刻消失。在实振幅的切片上亲手体会（拖动箭头就是在改 a、b）：

3.2公设二：操作是矩阵——泡利三人组登场Postulate two: operations are matrices — enter the Paulis

公设二（操作）：不做测量时，对系统的任何操作都是「线性保长度」的，即由矩阵实现。第 1 章的两位主角现在亮明身份——交换矩阵 S 与变号矩阵 D 正是量子比特最基本的两种「拨动」，行话记作 X 与 Z；连同含 i 的第三位成员，合称泡利矩阵：

Postulate two (operations): between measurements, any operation is “linear and length-preserving”, i.e. a matrix. Chapter 1's protagonists now show their badges — the swap matrix S and re-sign matrix D are precisely the qubit's two elementary nudges, written X and Z; together with a third member containing i they form the Pauli matrices:

X = 0110　·　Z = 100−1　·　Y = 0−ii0　(本教程主线只需 X 与 Zthe main path needs only X and Z)

4.1张量积：把两个系统写成一个The tensor product: two systems as one

For any nontrivial Pauli string S there is a string E anticommuting with it (put a Z where S has an X, or vice versa). E maps S's +1 eigenspace into the −1 eigenspace: if Sv = v then S(Ev) = −E(Sv) = −Ev. And E is invertible (E² = I), so the two subspaces have equal dimension — half each. k independent checks halve k times: 2ⁿ → 2ⁿ⁻ᵏ. (“Independent” means no check is a product of the others; such a check's reading is already determined and cuts nothing new.)

还差一个角色：逻辑算符——与全部检查对易（不触发警报）、又不能写成检查乘积（不是「白干」）的泡利串。它保持编码空间整体不动，却在其内部实施非平凡的改写：改写的正是逻辑比特。

One cast member remains: logical operators — Pauli strings commuting with every check (no alarms) yet not products of checks (not “doing nothing”). They preserve the code space as a whole while rewriting its interior nontrivially: what they rewrite is the logical qubit.

4.5第一个量子码，与它的判决书A first quantum code, and its verdict

Take n = 3 with checklist {Z₁Z₂, Z₂Z₃} (commuting: Z meets Z, no collisions). Demanding both “+1 surely” forces neighbouring label slots equal, leaving only |000⟩ and |111⟩ of the eight basis kets: code space = {α|000⟩ + β|111⟩}, dimension 2³⁻² = 2 — one logical qubit ✓. As logical operators (the overbar reads “bar” and marks the logical edition) take X̄ = X₁X₂X₃ (two collisions with each check: commutes ✓; swaps |000⟩↔|111⟩ — the logical flip) and Z̄ = Z₁ (zero collisions ✓; re-signs |111⟩). Error detection in one sentence: encoded states satisfy Sψ = ψ; after an error E the state is Eψ; if E anticommutes with S, then S(Eψ) = −E(Sψ) = −Eψ — check S reads −1 with certainty. Alarm = anticommute; invisibility = commute. X₂ collides once with each check → syndrome (−1, −1), uniquely naming qubit 2; one more X₂ heals it. But Z₂ has zero collisions with both checks — no alarm at all; and on the code space Z₂ acts identically to Z̄ (each re-signs |111⟩ only) — a silent logical error. Walk both fates on the bench:

ℝ双线体大写 R，读「实数集」Double-struck R, read “the real numbers”全体实数组成的集合。The set of all real numbers.
ℤ双线体大写 Z，读「整数集」Double-struck Z, read “the integers”全体整数。ℤ₂ 读「Z 二」：只剩 0 和 1 的「模 2 / 奇偶」算术——1+1=0 的世界。All whole numbers. ℤ₂ (“Z-two”) is arithmetic mod 2 — the 0/1 world where 1+1=0.
