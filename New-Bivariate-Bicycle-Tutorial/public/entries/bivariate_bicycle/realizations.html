Physical realizations

  • Kunlun long-range-coupled superconducting processor demonstrated

    A [[18,4,4]] BB block used 32 transmons to execute all nonlocal weight-six checks and repeated syndrome cycles. The reported logical error per logical qubit per cycle was (8.91 +/- 0.17)%; this establishes feasibility, not below-threshold scaling and not a gross-code run.

    References: wang2026lowoverhead

  • optimized Rydberg neutral-atom layout proposed

    Gate routing and Rydberg interactions were co-designed for BB connectivity. The result is a numerical architecture proposal rather than a laboratory logical-memory demonstration.

    References: poole2025rydberg

  • layered two-dimensional hardware proposed

    Motion or communication embeds long-range BB checks in a locally connected device, including schedules that measure some costly checks less often. The altered cadence and circuit noise must be decoded as part of the proposal.

    References: berthusen2025local

  • degree-five morphing-circuit layout proposed

    A related BB family lowers connectivity from degree six to five and uses six CNOT rounds by morphing the code during extraction. It changes the family and detector model; it is not a cheaper schedule for every BB block.

    References: shaw2025morphing

  • modular gross-code architecture proposed

    An instruction set, compiler, and end-to-end resource model organize distance-12 and distance-18 BB modules into a computer. This closes an architecture gap but remains a proposal, not a hardware realization.

    References: yoder2025tour
