family

Bivariate bicycle code

A CSS code family built by repeating a few parity-check moves on a grid whose opposite edges are identified. Each polynomial term says how far to move on that wrapped grid; the same moves become sparse matrix rows. A swapped, reversed copy supplies the partner checks, while a global rank defect can leave several logical qubits. The two matrix blocks are algebraic coordinate blocks, not by themselves a hardware layout.
