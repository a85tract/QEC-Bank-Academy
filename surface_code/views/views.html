These are not different codes; they are the same object translated into different languages. The Atlas arranges the translations on a five-rung ladder ordered by how executable they are, and beside every rung it records whether the translation was computed by the machine, copied from a canonical definition, or curated from a paper. This guide walks the surface code up that ladder.

第 1 章Chapter 1

什么是表示阶梯What a representation ladder is

一个纠错码不是一张图，而是一族互相翻译的描述。Atlas 给每个条目排一架五级梯子：越靠下越能直接交给机器执行，越靠上越接近物理与数学的洞见。这一章先讲清梯子的五级各问什么问题，以及为什么每一级都要单独标注来源。 An error-correcting code is not one picture but a family of mutually translating descriptions. The Atlas gives every entry a five-rung ladder: the lower rungs can be handed straight to a machine, the upper ones sit closer to physical and mathematical insight. This chapter explains what question each rung asks, and why every rung carries its own provenance label.

1.1五级，五个问题Five rungs, five questions

在直觉教程里，表面码是一幅画：比特住在边上，星形检查问四条边的 X 奇偶，面检查问四条边的 Z 奇偶（toric code 全图），剪开后出现两种边界。这幅画对人很友好，对程序却没有意义——程序需要的是能直接做运算的东西。反过来，一张 0/1 矩阵对程序很友好，却看不出「边界」「圈」「阈值」这些词。表示阶梯（representation ladder）就是把同一个码的各种描述，按「机器可执行」到「人类可洞见」排成五级：

In the intuition guide the surface code is a picture: qubits live on edges, star checks ask the X-parity of four edges, face checks ask the Z-parity of four edges (the toric code at a glance), and cutting the torus open produces two kinds of boundary. That picture is friendly to people and meaningless to a program, which needs something it can compute with. Conversely, a 0/1 matrix is friendly to a program but hides words like “boundary”, “loop” and “threshold”. A representation ladder arranges all descriptions of one code on five rungs, from machine-executable to human-insightful:

1.2每一级都写明来源：derived / canonical / curatedEvery rung carries a provenance: derived / canonical / curated

2.1从检查到行向量From checks to row vectors

给全部 n 个数据比特编号（n = 物理比特数，就是记账里的那个 n）。一条 X 型检查（星）就是一行长 n 的 0/1 串：它碰到的比特写 1，其余写 0。把所有 X 检查的行叠起来，得到矩阵 HXX 检查矩阵：每行一条 X 型检查，每列一个数据比特，(i, j) 位为 1 表示第 i 条检查作用在第 j 个比特上。；Z 检查（面）同样叠成 HZZ 检查矩阵：每行一条 Z 型检查，每列一个数据比特。。这一对矩阵就是表面码的 CSS 形式Calderbank–Shor–Steane：每条检查要么全是 X、要么全是 Z，于是码由一对二元矩阵 (H_X, H_Z) 完整给出。。直觉教程里的碰撞规则「X 撞 Z 的格数为奇数才报警」，翻译成矩阵语言只有一句话：任意一行 X 与任意一行 Z 的重叠个数必须是偶数。

Number all n data qubits (n = the number of physical qubits, the same n as in the ledger). One X-type check (a star) becomes a 0/1 string of length n: a 1 on every qubit it touches, 0 elsewhere. This pair is the surface code in CSS formCalderbank–Shor–Steane: every check is all-X or all-Z, so the code is fully specified by a pair of binary matrices (H_X, H_Z).. The intuition guide's collision rule, “alarm only when X meets Z on an odd number of cells”, becomes a single matrix sentence: any X row and any Z row must overlap on an even number of qubits.

「辛形式」（symplectic form）是把两张矩阵拼成一张更大的表 [HX | 0 ; 0 | HZ]：每一行有 2n 位，前 n 位记 X 部分，后 n 位记 Z 部分。这样任何 Pauli 检查（哪怕不是纯 X 或纯 Z）都能写成一行，对易判据统一成一条公式：两行 (x | z) 与 (x′ | z′) 对易，当且仅当 x·z′ + z·x′ = 0（模 2），这叫辛内积，其中 x·z′ 是逐位相乘再相加。它不是把两行当普通向量做点积：单比特的 X = (1 | 0) 与 Z = (0 | 1)，普通点积是 1·0 + 0·1 = 0，辛内积却是 1·1 + 0·0 = 1，所以 X 与 Z 反对易。对纯 X 行与纯 Z 行，辛内积就退化成上面那条「重叠个数为偶数」。Atlas 的 R1 记录 symplectic-css-checks 说的就是这张叠起来的表——「所有对易、秩、逻辑、码距计算的通用可执行基线」。

The “symplectic form” glues the two matrices into one larger table [HX | 0 ; 0 | HZ]: each row has 2n bits, the first n recording the X part, the last n the Z part. Any Pauli check, even one that is not pure X or pure Z, then fits on a row, and the commutation test becomes one formula: rows (x | z) and (x′ | z′) commute exactly when x·z′ + z·x′ = 0 (mod 2), the symplectic product, where x·z′ multiplies position by position and adds. It is not the ordinary dot product of the two rows: for a single qubit, X = (1 | 0) and Z = (0 | 1) have ordinary dot product 1·0 + 0·1 = 0, yet symplectic product 1·1 + 0·0 = 1, so X and Z anticommute. For a pure-X row against a pure-Z row, the symplectic product reduces to the “even overlap” rule above. The Atlas R1 record symplectic-css-checks is exactly this stacked table — “the universal executable baseline used for commutation, rank, logical, and distance calculations”.

3.1超图积：两条开链相乘The hypergraph product: two open chains multiplied

从最小的经典码开始。长 L 的重复码把一位说 L 遍（L = 码字长度，也就是表面码版图的边长），它的检查矩阵 H 是 (L−1)×L 的「相邻两位相等」表（L−1 行、L 列）：

Start with the smallest classical code. The length-L repetition code says one bit L times (L = codeword length, which is also the side length of the surface-code layout); its check matrix H is the (L−1)×L table of “adjacent bits agree” (L−1 rows, L columns):

H = [ 1 1 0 ; 0 1 1 ] （L = 3）(L = 3)　·　rank(H) = L−1　·　dim ker(H) = 1　·　dim ker(Hᵀ) = 0　(L = 重复码长度 = 版图边长；rank = 秩，ker = 核，dim = 维数repetition length = layout side; rank, ker = kernel, dim = dimension)

三个数字里，ker核（kernel）：满足 H·v = 0 的所有向量 v 的集合。ker(H) 是重复码的码字（这里只有全 1 一个非零码字）；ker(Hᵀ) 是检查之间的线性关系。 的两个维数最要紧。dim ker(H) = 1：唯一的非零码字是全 1（核只有「0 0 0」和「1 1 1」两个元素）。dim ker(Hᵀ) = 0：检查之间没有线性关系——这是开链的代数签名。要是把链首尾接成一个圈（加一行「第 L 位与第 1 位相等」），新行是旧行之和，dim ker(Hᵀ) 就变成 1。请记住这个 0 与 1 的差别。

Of the three numbers, the two kerKernel: the set of all vectors v with H·v = 0. ker(H) holds the repetition codewords (here only the all-ones word besides zero); ker(Hᵀ) holds the linear relations among the checks. dimensions matter most. dim ker(H) = 1: the only nonzero codeword is all-ones (the kernel has just two elements, “0 0 0” and “1 1 1”). dim ker(Hᵀ) = 0: no linear relation among the checks — the algebraic signature of an open chain. Close the chain into a loop (add a row “bit L equals bit 1”) and the new row is the sum of the old ones, so dim ker(Hᵀ) becomes 1. Remember this 0-versus-1 difference.

超图积（hypergraph product, HGP）把两份 H 相乘。比特分成两块：比特×比特块有 L² 个（对应 3×3 方阵 q0–q8），检查×检查块有 (L−1)² 个（对应格心 q9–q12）。两张量子检查矩阵由 ⊗（张量积：把一个矩阵的每个元素换成它乘另一个矩阵）拼出：

The hypergraph product (HGP) multiplies two copies of H. Qubits split into two blocks: bit×bit with L² qubits (the 3×3 array q0–q8) and check×check with (L−1)² qubits (the cell centres q9–q12). The two quantum check matrices are assembled with ⊗ (the tensor product: replace each entry of one matrix by that entry times the other matrix):

HX = [ H ⊗ IL | IL−1 ⊗ Hᵀ ]　·　HZ = [ IL ⊗ H | Hᵀ ⊗ IL−1 ]　(Im = m×m 单位矩阵；L = 链长；H = 重复码检查矩阵the m×m identity; L = chain length; H = the repetition check matrix)

从公式到一条检查。HX 的行按 (i, j) 编号：i 是 H 的第 i 行（第 i 条经典检查，0…L−2），j 是第 j 个比特（0…L−1），行号 = i·L + j。左块 H ⊗ IL 在 (i, j) 行、比特×比特 qa·L+b 那一列的元素是 H[i][a]·[b = j]，所以这一行碰 b = j、a = i 或 i+1 的两个比特；右块 IL−1 ⊗ Hᵀ 在格心比特 qL²+c(L−1)+e 那一列的元素是 [c = i]·H[e][j]，所以碰 c = i、e = j−1 或 j（落在 0…L−2 里的那些）。例：L = 3 的 X1 是第 1 行，(i, j) = (0, 1)。左块给 a ∈ {0, 1}、b = 1，即 q1、q4；右块给 c = 0、e ∈ {0, 1}，即 q9、q10。合起来 X1 = {q1, q4, q9, q10}，正是 2.2 节表里 X1 那一行，也就是坐标图里 (x, y) = (2, 1) 那颗内部星。HZ 同理：行 (a′, i) 的行号 = a′(L−1) + i，左块 IL ⊗ H 碰 qa′L+b（b = i 或 i+1），右块 Hᵀ ⊗ IL−1 碰 qL²+c(L−1)+i（c = a′−1 或 a′）。例：Z3 是第 3 行，(a′, i) = (1, 1)，左块给 q4、q5，右块给 c ∈ {0, 1}，即 q10、q12，所以 Z3 = {q4, q5, q10, q12}，与表中一致。脚本对 L = 3 的全部 12 行核对过这两条下标规则与构造器的输出逐位相同。

From the formula to one check. Rows of HX are labelled (i, j): i is row i of H (classical check i, 0…L−2), j is bit j (0…L−1), and the row number is i·L + j. In the left block H ⊗ IL, the entry of row (i, j) in the column of the bit×bit qubit qa·L+b is H[i][a]·[b = j], so the row touches the two qubits with b = j and a = i or i+1; in the right block IL−1 ⊗ Hᵀ, the entry in the column of the face-centre qubit qL²+c(L−1)+e is [c = i]·H[e][j], so it touches c = i and e = j−1 or j (those within 0…L−2). Example: X1 of L = 3 is row 1, (i, j) = (0, 1). The left block gives a ∈ {0, 1}, b = 1, i.e. q1 and q4; the right block gives c = 0, e ∈ {0, 1}, i.e. q9 and q10. Together X1 = {q1, q4, q9, q10}, exactly row X1 of the §2.2 table, the interior star at (x, y) = (2, 1) of the coordinate map. R1、R2 描述的是一个静态对象：一组同时成立的检查。真实机器通常给每条检查配一个辅助比特，让大量检查并行地测；但一个数据比特同一时刻只能参加一个两比特门，所以碰同一个比特的检查必须排好先后，而这个顺序决定了一个故障会怎样扩散（4.3 节的钩子错误就是例子）。R3「动力学」记录的是有序的测量时间表，以及每个时刻的瞬时稳定子群instantaneous stabilizer group, ISG：在测量序列的某一时刻，此刻被确定为 +1 的全部检查的乘积群。对静态稳定子码它始终不变；对 Floquet 码等动态码它随时间轮换。。对表面码这种静态稳定子码，时间表并不改变稳定子群本身，所以 R3 对它不是必需的——但也不是无意义的：哪条检查先测、哪条后测，决定了一个错误会在哪几轮被看见（只报「变化」的探测器）。Atlas 目前对表面码没有 R3 记录。

R1 and R2 describe a static object: a set of checks that hold simultaneously. A real machine usually gives each check its own ancilla and measures many checks in parallel; but a data qubit can take part in only one two-qubit gate at a time, so checks that touch the same qubit must be ordered, and that order decides how a fault spreads (the hook errors of §4.3 are an example). R3 “Dynamics” records an ordered measurement schedule together with the instantaneous stabilizer groupISG: at a given moment in the measurement sequence, the group generated by all checks currently known to be +1. For a static stabilizer code it never changes; for dynamic codes such as Floquet codes it rotates in time. at every step. For a static stabilizer code like the surface code the schedule does not change the stabilizer group, so R3 is not required for it — but neither is it meaningless: which check is measured first and which later decides in which rounds an error becomes visible (detectors that report only “change”). The Atlas currently has no R3 record for the surface code.

The surface code stores k = 1 logical qubit, so it fixes no single state; what is wanted is the encoding map. Draw k extra reference legs and write the encoder as a state on n + k legs: it has the n − k checks plus 2k stabilizers obtained from the logical operators X̄ and Z̄, n + k in all, which is maximal; then bend the k reference legs down into inputs, giving the map from k logical qubits to n physical ones (Figure 5.2b).

这本词典的用处在格点手术。手术教程里，合并是在缝合线上连乘检查，分裂把两块贴片重新分开——但分裂并不撤销合并：合并测量了联合奇偶并把态投影到读数上，分裂只是停掉缝合检查、测掉缝合比特，已测得的奇偶留在纸上。两者都不是只作用在逻辑比特上的幺正门：线路图也能画它们，但要加上辅助比特、测量和按读数做的纠正。在 ZX 里它们各是一只蜘蛛表示的映射（de Beaudrap 与 Horsman 2020）：测 X̄₁X̄₂ 的粗糙合并是一只 2 进 1 出的 X 蜘蛛，读数为 −1 时先在一条输入上加一个 Z（图 5.3a）；粗糙分裂是一只 1 进 2 出的 X 蜘蛛（图 5.3b）；把 X 换成 Z 就是光滑的合并与分裂。蜘蛛融合是另一回事：它说两张图相等（相连的同色蜘蛛可以合成一只），是用来化简、证明两个协议做的是同一件事的等式，不是一步物理操作（图 5.3c）。Atlas 原话：「rough/smooth merge and split operations become spider maps, so lattice surgery is diagram rewriting rather than an opaque stabilizer schedule.」

This dictionary earns its keep in lattice surgery. In the surgery guide, a merge multiplies checks along the seam and a split restores two separate patches — but a split does not undo the merge: the merge measured the joint parity and projected the state onto the readout, while the split only stops the seam checks and measures out the seam qubits, so the measured parity stays on record. Neither is a unitary gate acting on the logical qubits alone: a circuit diagram can draw them too, but only with ancillas, measurements and outcome-dependent corrections. In ZX each is a map drawn as one spider (de Beaudrap and Horsman 2020): the rough merge measuring X̄₁X̄₂ is an X spider with 2 inputs and 1 output, with a Z first applied to one input when the outcome is −1 (Figure 5.3a); the rough split is an X spider with 1 input and 2 outputs (Figure 5.3b); swapping X for Z gives the smooth merge and split. Spider fusion is a different thing: it says two diagrams are equal (joined same-colour spiders can be combined into one), an equality used to simplify and to prove that two protocols do the same thing, not a physical step (Figure 5.3c). Atlas verbatim: “rough/smooth merge and split operations become spider maps, so lattice surgery is diagram rewriting rather than an opaque stabilizer schedule.”

5.4PEPS：基态是一张带虚拟 ℤ₂ 对称的张量网络PEPS: the ground space is a tensor network with a virtual ℤ₂ symmetry

第四本词典换到凝聚态物理的语言。PEPSprojected entangled pair states，投影纠缠对态：把二维格点上每个格点放一个小张量，相邻张量通过「虚拟腿」缩并，得到整个系统的量子态。是矩阵乘积态（MPS）的二维推广。 把一个二维量子态写成一张张量网络：每个格点一个小张量，相邻张量之间用虚拟腿相连并求和。表面码的编码空间（物理上叫基态空间）可以写成这样一张网络，而且局部张量有一个虚拟 ℤ₂ 对称virtual Z2 symmetry：在每条虚拟腿上同时作用一个 Z（两次作用回到原状，故名 ℤ₂ = {0,1} 群），局部张量保持不变。配合 G-单射性（见下一段），这条对称性是 toric code 拓扑序的张量网络表述。：在所有虚拟腿上同时作用一个 Z，张量不变。

The fourth dictionary switches to the language of condensed-matter physics. A PEPSProjected entangled pair state: place a small tensor on every site of a 2D lattice and contract neighbouring tensors through “virtual legs” to obtain the state of the whole system. The 2D generalisation of matrix product states (MPS). writes a 2D quantum state as a tensor network: one small tensor per site, neighbouring tensors joined and summed over through virtual legs. The surface code's code space (physically, its ground space) can be written as such a network, and the local tensor has a virtual ℤ₂ symmetryActing with a Z on every virtual leg at once (twice returns to the identity, hence the group ℤ₂ = {0,1}) leaves the local tensor unchanged. Together with G-injectivity (next paragraph), this symmetry is the tensor-network statement of the toric code's topological order.: apply Z to every virtual leg at once and the tensor is unchanged.

只有这条对称性还推不出什么：乘积态的张量也可以满足它。例如物理腿总是 |0⟩、四条虚拟腿只在「全 0」或「全 1」时取 1 的张量，四条腿同时作用 Z 时相位是 (−1)0 或 (−1)4，都等于 1，所以不变；可收缩出来的却是毫无纠缠的 |00…0⟩。Schuch、Cirac、Pérez-García 的定理还要求 G-单射性（这里 G = ℤ₂）：张量除了在虚拟腿上 ℤ₂ 不变，还要在对称允许的那部分虚拟空间上是单射的，即不同的虚拟边界状态给出不同的物理态，不会像上例那样被压成同一个。toric code 的张量满足更强的 ℤ₂-等距性：它可以取成把四条虚拟腿投影到偶宇称子空间（Z⊗Z⊗Z⊗Z = +1）的投影算符。在这些前提下、放在环面上（周期边界），论文证明直觉教程里三件分别论证的事都来自这条对称性：拓扑简并（ℤ₂ 时 4 个基态，即环面上 2 个逻辑比特），局部不可区分（任何局部测量都读不出逻辑信息——不偷看的检查之所以可能），以及任意子激发（链端点的警报就是 e、m 粒子；这一条用到等距性）。平面码的「1 个逻辑比特」还要额外规定边界上的张量，不在这篇论文的定理里。Atlas 的结论句：「The code's topological order is therefore a constraint on the local tensor, not merely a property asserted from its Hamiltonian.」——拓扑序不是从哈密顿量宣布出来的性质，而是写在一个小张量上的约束。

The symmetry alone implies nothing of the sort: a product-state tensor can satisfy it too. Take a tensor whose physical leg is always |0⟩ and whose four virtual legs give 1 only when they are all 0 or all 1: applying Z to all four legs gives the phase (−1)0 or (−1)4, both 1, so it is invariant; yet the contracted state is the unentangled |00…0⟩. The Schuch–Cirac–Pérez-García theorems also require G-injectivity (here G = ℤ₂): besides being ℤ₂-invariant on its virtual legs, the tensor must be injective on the part of the virtual space the symmetry allows, i.e. different virtual boundary states give different physical states instead of being squashed together as in the example. The toric-code tensor satisfies the stronger ℤ₂-isometry: it can be taken as the projector of the four virtual legs onto the even-parity subspace (Z⊗Z⊗Z⊗Z = +1). Under these assumptions, and on the torus (periodic boundaries), the paper proves that three things the intuition guide argued separately follow from the symmetry: topological degeneracy (4 ground states for ℤ₂, i.e. 2 logical qubits on the torus), local indistinguishability (no local measurement reads the logical information — the reason no-peek checks are possible), and anyonic excitations (alarms at chain endpoints are the e and m particles; this one uses the isometry). The planar code's “1 logical qubit” needs boundary tensors as well and is outside the paper's theorems. The Atlas's closing sentence: “The code's topological order is therefore a constraint on the local tensor, not merely a property asserted from its Hamiltonian.”

c　f读「c、f」Read “c, f”c = 链向量：C₁ 的元素，每条边一个 0/1 分量，1 表示该边上有 Z；∂₁c = 它的警报（端点）。f = 面向量：C₂ 的元素，每个面一个 0/1 分量；∂₂f = 所选面的边界，即若干 Z 检查的乘积（3.2 节）。c = chain vector: an element of C₁, one 0/1 entry per edge, 1 meaning a Z on that edge; ∂₁c = its alarms (endpoints). f = face vector: an element of C₂, one 0/1 entry per face; ∂₂f = the boundary of the chosen faces, i.e. a product of Z checks (§3.2).
Zh　P(h)　F = −T ln Zh读「类权重」「类概率」「自由能」Read “class weight”, “class probability”, “free energy”Zh = 同调类 h 里所有链的权重之和（每条链一个玻尔兹曼因子 e−E/T，E = 链长，T 由错误率定）；P(h) = Zh/Σh′Zh′ 是该类的概率；F 是 Zh 的对数换个符号再乘 T。匹配取 T → 0，只留和式里最大的一项——最短链（5.1 节）。Zh = the sum of the weights of all chains in homology class h (one Boltzmann factor e−E/T per chain, E = chain length, T set by the error rate); P(h) = Zh/Σh′Zh′ is the class probability; F is the logarithm of Zh, negated and multiplied by T. Matching takes T → 0 and keeps only the largest term — the shortest chain (§5.1).
ℤ₂双线 Z 下标 2，读「Z 二」Blackboard Z sub 2, read “Z-two”两元素群 {0, 1}（做两次回到原状）。PEPS 词典里的「虚拟 ℤ₂ 对称」：在所有虚拟腿上作用 Z，张量不变（5.4 节）。The two-element group {0, 1} (do it twice and you are back). In the PEPS dictionary, the “virtual ℤ₂ symmetry”: apply Z to every virtual leg and the tensor is unchanged (§5.4).
