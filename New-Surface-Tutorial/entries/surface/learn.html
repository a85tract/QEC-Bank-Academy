Begin with the phenomenon

A local alarm can reveal an error without revealing the qubit

Touch one data site and watch only the neighboring parity questions change.

A quantum memory cannot keep asking, “is this qubit 0 or 1?”—that would measure the information we are trying to protect. The surface code asks overlapping parity questions instead. A single X-type data error changes the answers to nearby Z-type questions; a Z-type error changes nearby X-type questions.

In the lab, choose Load one hidden X error, predict which question marks will light, then reveal the answer. The lit pattern is the syndrome. It identifies endpoints, not the complete error path.

Name what you can now see

The patch is two interleaved families of local questions

Inspect supports before introducing stars, plaquettes, boundaries, or HGP notation.

Data qubits occupy the black numbered sites. Each blue X check and red Z check is a row of the constructor’s binary check matrices. Select a check: its shaded support, Pauli operator, and row index are the same formal object seen in three ways.

Boundary checks touch fewer data sites because the open repetition chains have missing incidences. The words rough, smooth, star, plaquette, and hypergraph product now name visible relationships; they do not introduce extra geometry or hardware.

Infer, do not peek

Decoding means closing endpoints without choosing a logical path

Hide the sampled error, propose a recovery, and grade the residual class.

Many error chains have the same endpoints. A decoder may choose any recovery with the observed syndrome. Success therefore does not mean reproducing the hidden error. Add the proposed recovery to the error: the residual must have no syndrome and must be deformable into local stabilizers.

A different recovery can clear every alarm yet complete a boundary-to-boundary logical string. The lab reports that as a logical failure. This distinction is the reason a decoder is judged by residual logical class rather than exact path equality.

Add the measurement machinery

Checks become physical only after ancillas, order, and time are specified

Step through the validated L3 CNOT schedule and propagate a named hook fault.

A stabilizer row is a static operator. Hardware estimates it by preparing an ancilla, coupling that ancilla to every data qubit in the row, and measuring it. The four CNOT layers below are a validated schedule for the shipped L3 logical-X memory circuit; the coordinates are a circuit layout, not a new definition of the code.

Ordering matters. An ancilla fault after an early contact can propagate through later contacts and become a two-data-qubit hook. Step to the fault location, predict the remaining contacts, then inject the named fixture. Static code distance and circuit/spacetime fault distance are consequently different claims.

Protect while acting

The logical gate depends on what the hardware can couple

Choose a goal and connectivity; inspect the operation row whose assumptions actually fit.

The surface code does not come with one universal gate mechanism. Neighboring planar patches can measure a joint logical parity by lattice surgery. Aligned copies can use pairwise physical CNOTs. A logical T requires an injected non-stabilizer resource because bounded-depth local gates in two dimensions are Clifford.

Use the decision lab to separate the logical map from its physical realization. Each result is a claimed operation row with its own reference and cost statement; the selector is a curated teaching aid, not a hardware optimizer or a spacetime simulation.

Keep regimes attached

A threshold is meaningless without its experiment

Filter decoder records by observation model before comparing performance claims.

Perfect syndrome, repeated noisy syndrome, and scheduled circuit faults are different experiments. They expose different observations and count different elementary fault locations. A decoder name alone does not make their thresholds comparable.

Select a regime and inspect the exact populated Decoder record. Then answer the audit question. The Atlas stores literature provenance, but the page must still explain why a cross-regime ranking is invalid.

Use an unfamiliar patch, then audit the dossier

Four compact tasks test operational, formal, circuit, and epistemic command.

This final lab starts from the L4 patch rather than replaying the guided L3 path. Complete all four tasks: recover a hidden error without seeing it, identify a zero-syndrome logical failure, diagnose a named hook fault, and reject an invalid threshold comparison.

Completion means you can use the populated Surface Reference without a paper filling in a missing causal step. It does not certify every R5 dictionary as executable: ZX, fermionic, tensor-network, and statistical-mechanics views remain clearly curated explanations.
