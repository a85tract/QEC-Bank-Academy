QEC Atlas · Foundations · Open problems

Open problems (the Wanted board)

Machine-checkable distance lower-bound certificates open

Certificates for 'no logical below weight w' that a proof assistant can verify (feeds Lean L2); small-n exhaustion transcripts first, relaxation duals later.

Why: The formal-foundations layer needs LB certificates to state [[n,k,d]] theorems about instances.

Current proxy: Exact enumeration for small n only, unverified beyond.

General cell-complex library (boundaries, 3D+, geometry) partial

Extend the minimal ChainComplex (length-3, no geometry) to cell complexes with boundaries, higher dimensions, and coordinate embeddings.

Why: Needed for 3D codes (toric3d, color3d, gauge color) and for lattice embeddings beyond hand-coding; doubles as infrastructure for 3D self-correction research.

Current proxy: qeclib.chain (length-3, matrix-only) + hand-coded lattice dicts.

Code equivalence / canonical forms open

Decide when two entries are the same code up to local equivalence; canonical fingerprints beyond (n, k, d-bounds, weight histograms).

Why: Dedup as the zoo grows past hundreds of entries; unify quon/parton/majorana presentations of the same object.

Current proxy: Invariant fingerprint + curated identity edges.

Cohomology operations (cup products) on explicit complexes open

Compute cup products / cohomology operations on the chain complexes of product codes to certify native non-Clifford logicals (arXiv:2501.19375).

Why: Connects the homological representation directly to the LogicalOperation facet: the topology computes the gates.

Current proxy: Curated operations entries with refs.

Standard decoders for 3D color / gauge color / fracton codes open

Production-quality decoders (and benchmark harness rows) for code families where none is standard.

Why: decoders: none-known entries stay benchmark-blind; comparison tables honestly show the gap this item closes.

Current proxy: status: none-known recorded per card; curated literature curves allowed with refs.

Distance at n >~ 100 for qLDPC open

Compute or certify code distance for qLDPC instances beyond exhaustive range. Exactness NOT required: a relaxation-based certified LOWER bound (LP/SDP-style, symmetry-reduced, spectral/expansion) counts as a full solution — upper bounds are already cheap (any found logical certifies one); the lower bound is the open half.

Why: Unblocks 'verified' distance fields for every large entry (gross code and beyond); the Atlas comparison tables stay 'bounded/claimed' without it.

Current proxy: rand-lowweight-v1 upper bounds + literature claims with refs; exact enumeration only for small n.

Fermionic compiler / ZX-fermion translator open

Compilation in the unified Majorana/parton/quon representation (spec 3.2: one 'fermionic' type, dialects majorana-pairs|parton|quon). Plausibly the same computational content as ZX compilation. First deliverable: a formal ZX <-> fermionic dictionary.

Why: Makes the fermionic view machine-derived instead of fully curated; opens Majorana-native compilation for Floquet codes.

Current proxy: Curated per-entry fermionic notes only (refs arXiv:1703.02973, arXiv:1910.12065).

Floquet fault distance under a named schedule open

Detector design + fault-distance computation for dynamical codes (timelike vs spacelike kept separate); beyond-graphlike DEM search.

Why: Honeycomb and all Floquet entries show d = ? until this exists.

Current proxy: ISG structure verified (dynamic_k); d omitted or claimed(ref).

Lean QEC framework library (L1) partial

Formalize symplectic GF(2), Pauli/stabilizer/subsystem codes, Knill-Laflamme for Pauli errors, CSS/chain complexes in Lean 4 / Mathlib (spec section 11; outline = foundations/).

Why: Framework-first formalization makes every code an instance; L1+L2 alone is a publishable artifact.

Current proxy: Accepted exact-pinned Pauli-symplectic seam plus one sealed generic Lean Complete v1 checker and a governed all-instance replay for finite static stabilizer, CSS/chain, subsystem/gauge, and measurement-schedule structures. The accepted framework exposes structural, logical-witness, upper-bound, and bounded small-exact certificate classes. Every current shipped instance has a checked structural certificate; policy-eligible verified exact-distance instances also have bounded small-exact certificates. Knill-Laflamme, family theorems, decoder correctness, thresholds, hardware, dynamic logical transport, and broader certificate classes remain open.

Circuit-level decoding for nongeometric qLDPC families open

Build a replayable decoder and benchmark adapter for repeated syndrome extraction on sparse nongeometric qLDPC codes, including measurement, routing, leakage, and correlated circuit faults rather than only perfect syndrome bits.

Why: Quantum-expander and related HGP memories have code-capacity algorithms, but the Atlas cannot compare their operational memory performance until the extraction circuit, detector model, decoder, and noise normalization are one versioned executable contract.

Current proxy: Perfect-syndrome small-set flip, BP-OSD, and algebraic CSS baselines; none is a family-specific circuit-level threshold workflow.

Schedule equivalence via ZX rewriting open

Decide when two measurement schedules realize the same fault-tolerant object, using the ZX local-equivalence picture (arXiv:2303.08829) as target semantics.

Why: Canonicalizes dynamical entries; catches duplicate codes wearing different schedules.

Current proxy: None; curated identity claims only.

Scalable subsystem dressed-distance certification open

Extend exact-small and witnessed upper-bound dressed-distance replay to scalable certified lower bounds, named Pauli sectors, and equivalence-safe subsystem presentations.

Why: Finite C(S)/G enumeration now verifies small Bacon-Shor instances, but large subsystem families still need lower-bound certificates and proof that gauge-equivalent presentations preserve the claimed quantity.

Current proxy: The referee exactly enumerates complete small weight layers and validates seeded randomized upper witnesses modulo the full gauge group. Over-budget witnesses remain upper-only with not-certified optimality; no asymptotic or presentation-equivalence theorem is inferred.

Transversal-gate certification library partial

Given a code, enumerate/certify its transversal logical gates. Routes: triorthogonality checks (done, exact), automorphism-based logical Cliffords (Tanner-graph autos via nauty), brute force for small n.

Why: Turns the operations facet from claimed(ref) into verified for the gates that matter; feeds fair comparison of computation, not just memory.

Current proxy: triortho.transversal_t_candidate + literature claims.
