不在乎的比特，
与穿了衣服的码距 Don't-care qubits
and the dressed distance

Toric Code 教程里的检查清单有一条铁律：所有检查两两对易。有一类码故意违反它：允许一些「检查」互相打架，代价是编码空间里多出几个我们不在乎的比特——它们随便被翻，受保护的那个逻辑比特毫发无损。这类码叫子系统码，最小的例子只有 4 个比特，一张纸能算完。但它把「码距」这个词弄复杂了：一条逻辑算符可以乘上那些「不在乎」的操作换一件衣服，码距要在所有衣服里取最轻的那件。Atlas 的检验员对 4、9、15 个比特的 Bacon–Shor 码把这件事穷举做完，写下 verified；对 35 个比特的 5 × 7 却只能交出一件重量 12 的衣服，旁边写着 not-certified。这一篇讲这道开放问题是什么、Atlas 现在怎么凑合、为什么我们想要答案、一个合格的答案长什么样。 The check list of the toric-code guide obeys one iron rule: all checks commute pairwise. One class of codes breaks it on purpose: some “checks” are allowed to fight each other, at the price of a few extra qubits in the code space that we don't care about; flip them at will and the protected logical qubit is untouched. These are subsystem codes, and the smallest example has only 4 qubits, one sheet of paper's worth. But they complicate the word “distance”: a logical operator can be multiplied by those don't-care operations to change clothes, and the distance must take the lightest of all outfits. The Atlas referee finishes this exhaustively for the 4-, 9- and 15-qubit Bacon–Shor codes and writes verified; for the 35-qubit 5 × 7 it can only hand over one outfit of weight 12, marked not-certified. This guide explains what the open problem is, how the Atlas copes today, why we want the answer, and what a qualifying answer looks like.

Everything else (gauge generators, center, bare and dressed, modulo the gauge group, sectors, presentations) is built from a 4-qubit toy you can compute by hand before it gets a name. 速查回顾：五条随身事实Quick recap: five facts to carry

这一篇只依赖 Toric Code 教程里的五件事。每一条都给出原处的链接；记不清就点回去，读完再回来。 This guide relies on five things from the toric-code guide. Each comes with a link to where it was taught; if one is hazy, follow the link and come back.

#事实Fact原处Where it was taught
1一条泡利串在每个比特上放 I、X、Y 或 Z 之一；重量 = 放了非 I 的比特数。A Pauli string puts one of I, X, Y, Z on each qubit; its weight is the number of qubits carrying a non-I letter.4.2 节section 4.2
2碰撞定理：两条泡利串反对易，当且仅当「两条都非 I 且字母不同」的比特数是奇数；否则对易。XX 与 ZZ 若只共用一个比特就反对易，共用两个就对易。Collision theorem: two Pauli strings anticommute exactly when the number of qubits where both are non-I with different letters is odd; otherwise they commute. XX and ZZ anticommute if they share one qubit, commute if they share two.4.2 节section 4.2
3一个稳定子码是一份两两对易的检查清单；k = n − 独立检查数（前提是检查乘不出 −I；检查都是带 + 号的全 X 串或全 Z 串时自动成立，因为这样的串相乘不产生符号，本篇的 Bacon–Shor 码就是这样）。A stabilizer code is a list of pairwise commuting checks; k = n − (number of independent checks) (provided no product of checks equals −I; this holds automatically when every check is an all-X or all-Z string with a + sign, since multiplying such strings produces no sign, as in the Bacon–Shor codes of this guide).4.4 节section 4.4 · 5.3 节section 5.3
4逻辑算符 = 与所有检查对易、却不是检查乘积的泡利串；码距 d = 最轻逻辑算符的重量。环面码 d = L。A logical operator is a Pauli string commuting with every check yet not a product of checks; the distance d is the weight of the lightest one. The toric code has d = L.5.6 节section 5.6 · 5.8 节section 5.8
5一条逻辑算符乘上任何检查，仍是同一个逻辑算符（对码空间作用相同）；所以「最轻」要在所有这些乘积里找。A logical operator times any check is still the same logical operator (same action on the code space); so “lightest” must be sought among all such products.5.5 节section 5.5

In this guide Xi, Zi denote the string with a single X or Z on qubit i, and X0X2 the string with an X on qubits 0 and 2.

这个问题用人话说是什么：一份会打架的检查清单The problem in plain words: a check list that fights itself

先在 4 个比特上写下四条两两相邻的「检查」，发现其中两条反对易，按 Toric Code 教程的规则这份清单不合法。然后看它为什么还能保护一个比特：把打架的部分划成「不在乎」的区域。接着在 4 比特和 9 比特上亲手给逻辑算符换衣服，定义穿了衣服的码距，最后读 Wanted 板的原文。 First write four nearest-neighbour “checks” on 4 qubits and find that two of them anticommute, so by the toric-code guide's rules the list is illegal. Then see why it still protects one qubit: fence off the fighting part as a “don't-care” region. Next, change a logical operator's clothes by hand on 4 and 9 qubits, define the dressed distance, and finally read the Wanted board's wording.

用第 0 章的碰撞定理检查一下：X0X2 与 Z0Z1 只在 q0 这一个比特上「都非 I 且字母不同」，1 是奇数，反对易。按 Toric Code 教程 4.4 节的规则，这两条不能同时进一份检查清单——测了一条，另一条的答案就被打乱。Atlas 直觉页说这不是缺陷：「That is not a defect: gauge generators are allowed to disturb an unprotected gauge subsystem.」这四条串不叫稳定子，叫规范生成元gauge generator：允许互相反对易的一组「检查」。它们生成的群叫规范群 G。它们的测量结果不必全部同时确定；只有它们当中互相对易的那部分（中心）才是真正的稳定子。；它们生成的整个乘积集合叫规范群 Ggauge group：把四条规范生成元任意相乘得到的所有泡利串（连同符号）。本篇比较泡利串时不计整体符号，只看哪些比特上放了什么字母（理由见 1.2 节）。。人话：我们故意写了一份会打架的清单。

Check with the collision theorem of Chapter 0: X0X2 and Z0Z1 are “both non-I with different letters” on exactly one qubit, q0; 1 is odd, so they anticommute. By the rules of toric-code section 4.4 these two cannot sit in one check list: measuring one scrambles the answer of the other. The Atlas intuition page says this is not a flaw: “That is not a defect: gauge generators are allowed to disturb an unprotected gauge subsystem.” The four strings are not called stabilizers but gauge generatorsA set of “checks” allowed to anticommute with one another. The group they generate is the gauge group G. Their measurement outcomes need not all be simultaneously definite; only the mutually commuting part (the center) consists of true stabilizers., and the set of all their products is the gauge group GAll Pauli strings (with signs) obtained by multiplying the four gauge generators in any combination. This guide compares Pauli strings without their overall sign and looks only at which letter sits on which qubit (the reason is in 1.2).. In plain words: we wrote a self-fighting list on purpose.

1.2中心：清单里互不打架的那部分，与一个不在乎的比特The center: the part of the list that does not fight, and one don't-care qubit

打架的清单里仍有和平的成员。把两条竖边相乘：X0X2 · X1X3 = X0X1X2X3，记作 SX。它与 Z0Z1 在 q0、q1 两个比特上碰撞，2 是偶数，对易；与 Z2Z3 同理。同样，两条横边相乘得 SZ = Z0Z1Z2Z3，它与每条竖边碰撞两次，对易。SX 与 SZ 碰撞四次，也对易。这两条与所有规范生成元都对易的乘积叫规范群的中心center：规范群里与规范群每个元素都对易的那些元素。它们是真正的稳定子，构成稳定子群 S。Atlas 原文：「The protected codespace is fixed only by the commuting center of the gauge group.」，记作 S；它们才是真正的稳定子：测它们，答案稳定，不被别的测量打乱。

A fighting list still has peaceful members. Multiply the two vertical edges: X0X2 · X1X3 = X0X1X2X3, call it SX. It collides with Z0Z1 on two qubits, q0 and q1; 2 is even, so they commute; likewise with Z2Z3. Similarly the two horizontal edges multiply to SZ = Z0Z1Z2Z3, which collides twice with every vertical edge and commutes. SX and SZ collide four times and commute too. These products commuting with every gauge generator form the centerThe elements of the gauge group that commute with every element of the gauge group. They are the true stabilizers and form the stabilizer group S. Atlas text: “The protected codespace is fixed only by the commuting center of the gauge group.” of the gauge group, written S; they are the true stabilizers: measure them and the answer is stable, unscrambled by other measurements.

关于符号要说清一件事。规范群若连符号一起算，里面有 −I：记 A = X0X2、B = Z0Z1，两者反对易，交换一次多一个负号（BA = −AB），所以 A·B·A·B = −A·A·B·B = −I（本篇的检验脚本用 16 × 16 矩阵乘过）。−I 与一切对易，按字面定义它落在中心里，可它不能当检查：没有状态满足 −|ψ⟩ = |ψ⟩。所以本篇约定：比较泡利串时不计整体相位（±1、±i），「中心」指不计相位后与 G 中每条串都对易的那些串；稳定子群 S 由中心里一组选好符号、彼此相容（乘不出 −I）的代表生成，这里取 +SX、+SZ。本篇所有的 rank 都是不计相位的秩，也就是只看每个比特上放了什么字母。

One point about signs. Counted with signs, the gauge group contains −I: write A = X0X2 and B = Z0Z1; they anticommute, so swapping them costs a minus sign (BA = −AB), and A·B·A·B = −A·A·B·B = −I (this guide's check script multiplied the 16 × 16 matrices). −I commutes with everything, so by the literal definition it lies in the center, yet it cannot serve as a check: no state satisfies −|ψ⟩ = |ψ⟩. So this guide's convention is to compare Pauli strings up to an overall phase (±1, ±i): the “center” means the strings that commute with every string of G once phases are dropped, and the stabilizer group S is generated by representatives from the center with chosen signs that are consistent (no product gives −I), here +SX and +SZ. Every rank on this page ignores phases: it looks only at which letter sits on which qubit.

现在记账。按 Toric Code 教程 5.3 节的算法，n − 独立稳定子数 = 4 − 2 = 2，编码空间里有 2 个比特的自由度。但其中只有 1 个受保护。为什么：另一个自由度正是被规范生成元「打乱」的那个——X0X2 和 Z0Z1 反对易，它们就像一个额外比特上的 X 和 Z：测一个，另一个原本确定的结果就变成随机。比如状态原本满足 Z0Z1 = +1，测一次 X0X2 之后再测 Z0Z1，得 +1 和 −1 的概率各一半。我们不在乎这个比特的状态，Atlas 叫它规范比特gauge qubit：编码空间里被规范生成元随意翻动、不承载受保护信息的自由度。数量 g = (rank G − rank S)/2。。子系统码的账本公式（Atlas foundations 页的一句话定义：「Trade logical qubits for gauge freedom; k = n − (rank G + rank S)/2」）：

Now the ledger. By the procedure of toric-code section 5.3, n − (independent stabilizers) = 4 − 2 = 2, so the code space has 2 qubits' worth of freedom. But only 1 is protected. Why: the other degree of freedom is precisely the one “scrambled” by the gauge generators; X0X2 and Z0Z1 anticommute like the X and Z of one extra qubit: measuring one turns the other's previously definite outcome random. For example, if the state had Z0Z1 = +1, then after one measurement of X0X2 a new measurement of Z0Z1 gives +1 or −1 with probability one half each. We don't care about this qubit's state; the Atlas calls it a gauge qubitA degree of freedom inside the code space that gauge generators flip at will and that carries no protected information. Their number is g = (rank G − rank S)/2.. The ledger formula for subsystem codes (the one-liner of the Atlas foundations page: “Trade logical qubits for gauge freedom; k = n − (rank G + rank S)/2”):

k = n − (rank G + rank S) / 2　　·　　g = (rank G − rank S) / 2

记号：rank G = 独立的规范生成元条数（这里 4：四条边彼此不能互相乘出），rank S = 独立的稳定子条数（这里 2：SX、SZ），k = 受保护的逻辑比特数，g = 规范（不在乎）比特数。代入：k = 4 − (4 + 2)/2 = 1，g = (4 − 2)/2 = 1。公式从哪里来：稳定子码的算法先给出 n − rank S 个自由度（这里 2 个）。再把四条生成元换一组写法：保留 A = X0X2 和 B = Z0Z1，把 X1X3 换成 A·X1X3 = SX，把 Z2Z3 换成 B·Z2Z3 = SZ（换掉的那条总能再乘回来，所以生成的群不变）：G = ⟨SX, SZ, A, B⟩。这组写法里，SX、SZ 与一切对易，A 与 B 彼此反对易、与 SX、SZ 都对易。G 的任一元素都能写成（SX、SZ 的某个乘积）· Aα · Bβ（α、β 取 0 或 1）；它与 B 对易当且仅当 α = 0，与 A 对易当且仅当 β = 0，所以中心恰好是 ⟨SX, SZ⟩，而规范自由度全部来自 A、B 这一对反对易的算符，它们就是那个规范比特的「X 和 Z」。于是 rank G = 4 = rank S + 2 × 1。一般的 G 也能整理成「中心 + g 对」，步骤在下面的补课里；所以 rank G = rank S + 2g，即 g = (rank G − rank S)/2。受保护的比特是扣掉规范比特剩下的：k = (n − rank S) − g，代入 g 化简就是 k = n − (rank G + rank S)/2。Atlas 推导页 gauge-center-and-qubits.md 的账本表第一行正是「2 × 2 | rank S 2 | rank G 4 | k 1 | g 1」。

Notation: rank G = number of independent gauge generators (here 4: no edge is a product of the others), rank S = number of independent stabilizers (here 2: SX, SZ), k = protected logical qubits, g = gauge (don't-care) qubits. Substituting: k = 4 − (4 + 2)/2 = 1, g = (4 − 2)/2 = 1. Where the formula comes from: the stabilizer-code count first gives n − rank S degrees of freedom (2 here). Now rewrite the four generators: keep A = X0X2 and B = Z0Z1, replace X1X3 by A·X1X3 = SX and Z2Z3 by B·Z2Z3 = SZ (the replaced string can always be multiplied back, so the generated group is unchanged): G = ⟨SX, SZ, A, B⟩. In this form SX and SZ commute with everything, while A and B anticommute with each other and commute with SX and SZ. Every element of G can be written as (some product of SX, SZ) · Aα · Bβ with α, β equal to 0 or 1; it commutes with B exactly when α = 0 and with A exactly when β = 0, so the center is exactly ⟨SX, SZ⟩, and all the gauge freedom comes from the one anticommuting pair A, B, the “X and Z” of the gauge qubit. Hence rank G = 4 = rank S + 2 × 1. A general G can be put in the same form, “center + g pairs”, by the steps in the catch-up fold below; so rank G = rank S + 2g, that is g = (rank G − rank S)/2. The protected qubits are what is left after removing the gauge qubits: k = (n − rank S) − g, and substituting g simplifies to k = n − (rank G + rank S)/2. The first row of the ledger table in the Atlas derivation page gauge-center-and-qubits.md reads exactly “2 × 2 | rank S 2 | rank G 4 | k 1 | g 1”.

补课 · 为什么中心以外的部分总是成对：一步配对，反复做Catch-up · Why the part outside the center always comes in pairs: one pairing step, repeated

手上有 G 的一组独立生成元（不计相位）。若它们两两对易，就全在中心里，g = 0。否则挑出一对反对易的 a、b，对其余每条生成元 h 做一次修正：

Start from a set of independent generators of G (phases ignored). If they all commute pairwise, they all lie in the center and g = 0. Otherwise pick one anticommuting pair a, b and correct every other generator h once:

h′ = h · a[h 与 b 反对易] · b[h 与 a 反对易]

记号：[…] 成立时取 1、不成立时取 0；a1 = 乘上 a，a0 = 不乘。

Notation: [...] is 1 when the statement holds and 0 otherwise; a1 = multiply by a, a0 = do not.

核对 h′ 与 a 对易：h 本身与 a 反对易的次数记为 [h 与 a 反对易]；若它是 1，乘进来的 b 与 a 反对易，又贡献一次；乘进来的 a 与 a 对易，不贡献。两次抵消，h′ 与 a 对易。h′ 与 b 同理。修正只是乘上 G 里的元素，生成的群不变，生成元也仍然独立。于是 G 分成两块：⟨a, b⟩ 和「修正后的其余生成元」，两块之间两两对易。对其余那块重复这一步，直到剩下的生成元两两对易。每做一次拿走一对，最后得到 g 对 (ai, bi) 和一组两两对易的 sj。G 的元素里，与 bi 对易的恰是不含 ai 的，与 ai 对易的恰是不含 bi 的，所以中心恰好由 sj 生成：rank G = rank S + 2g。这个步骤叫辛 Gram–Schmidtsymplectic Gram–Schmidt：把一组泡利串整理成「若干对反对易的算符 + 一组与一切对易的算符」的逐对修正步骤，名字来自线性代数里逐个正交化的 Gram–Schmidt 方法。。

Check that h′ commutes with a: h itself contributes [h anticommutes with a]; if that is 1, the b multiplied in anticommutes with a and contributes once more; the a multiplied in commutes with a and contributes nothing. The two cancel, so h′ commutes with a; likewise with b. A correction only multiplies by elements of G, so the generated group is unchanged and the generators stay independent. G thus splits into two blocks, ⟨a, b⟩ and “the other generators after correction”, which commute with each other. Repeat the step on the second block until the remaining generators commute pairwise. Each round removes one pair, leaving g pairs (ai, bi) and a set of pairwise commuting sj. An element of G commutes with bi exactly when it contains no ai, and with ai exactly when it contains no bi, so the center is generated by the sj: rank G = rank S + 2g. The procedure is called symplectic Gram–SchmidtThe pair-by-pair correction that brings a set of Pauli strings into the form “some anticommuting pairs + a set that commutes with everything”; the name comes from the Gram–Schmidt orthogonalisation of linear algebra..

在 2 × 2 上做一遍。取 a = X0X2、b = Z0Z1。X1X3 与 b 在 q1 碰撞一次（反对易），与 a 不碰撞，所以 h′ = X1X3 · a = SX；Z2Z3 与 a 在 q2 碰撞一次，与 b 不碰撞，所以 h′ = Z2Z3 · b = SZ。剩下的 SX、SZ 对易，停：g = 1、rank S = 2，就是正文里的写法。在 3 × 3 的 12 条生成元上照做，本篇的检验脚本得到 4 对，剩下的 4 条生成的正是 5.1 节的四条条带：g = 4、rank S = 4。

On the 2 × 2. Take a = X0X2 and b = Z0Z1. X1X3 collides once with b, at q1 (anticommutes), and not with a, so h′ = X1X3 · a = SX; Z2Z3 collides once with a, at q2, and not with b, so h′ = Z2Z3 · b = SZ. The remaining SX and SZ commute, so we stop: g = 1, rank S = 2, the form used in the main text. Doing the same on the 12 generators of the 3 × 3, this guide's check script finds 4 pairs, and the 4 generators left over generate exactly the four strips of 5.1: g = 4, rank S = 4.

子系统码 = 一份允许打架的检查清单 + 一个约定：清单里互相对易的部分（中心）是真正的稳定子，打架的部分只翻动我们不在乎的规范比特。受保护的比特数不是 n − rank S，而是 n − (rank G + rank S)/2。Atlas 直觉页把「Counting n − rank(S) protected qubits」列为第二号错误：3 × 3 的 Bacon–Shor 码有 1 个受保护比特和 4 个规范比特，不是 5 个受保护比特。

A subsystem code = a check list that may fight itself + one convention: the mutually commuting part of the list (the center) are the true stabilizers, and the fighting part only flips gauge qubits we don't care about. The number of protected qubits is not n − rank S but n − (rank G + rank S)/2. The Atlas intuition page lists “Counting n − rank(S) protected qubits” as failure mode number two: the 3 × 3 Bacon–Shor code has 1 protected qubit and 4 gauge qubits, not 5 protected qubits.

1.3裸的逻辑算符，与穿了衣服的逻辑算符Bare logical operators, and dressed ones

The protected qubit needs its own X̄ and Z̄. Take X̄ = X0X1 (the whole top row): it collides twice with Z0Z1, zero times with Z2Z3, and not at all with the two vertical edges (X against X is no collision), so it commutes with all four gauge generators; and it is not a product of them (in such products X's always come in vertical pairs). Take Z̄ = Z0Z2 (the whole left column): likewise it commutes with all four. X̄ and Z̄ collide once, at q0, and anticommute, exactly the relation a logical pair should have (section 5.6). 1.4穿了衣服的码距：在所有衣服里取最轻的，「商掉整个规范群」The dressed distance: the lightest of all outfits, “modulo the full gauge group”

于是「码距」要重新定义。Atlas 检验员的定义（设计文档 2026-08-10-subsystem-dressed-distance-v1.md 原文）：一条泡利串 p 是穿了衣服的逻辑见证，当且仅当「1. p commutes with every row of S; and 2. p is not in G.」穿了衣服的码距dressed distance：所有满足「与每条稳定子对易，且不在规范群 G 里」的泡利串中最轻者的重量。它是子系统码真正的码距。就是所有这种 p 里最轻的重量。两个条件对应两种「不算」：与某条稳定子反对易的串会触发警报，不算；属于 G 的串只翻不在乎的比特，无害，也不算。「modulo the full gauge group」（商掉整个规范群）说的是第二条：两条只差一个规范算符的串被看成同一件东西，而且这个规范算符可以是 G 里的任何元素，不只是中心。人话：码距 = 能骗过所有稳定子、又真的改写受保护比特的最轻操作；一件衣服算一次，锯齿和直行算同一条。

So “distance” must be redefined. The Atlas referee's definition (verbatim from the design document 2026-08-10-subsystem-dressed-distance-v1.md): a Pauli p is a dressed-logical witness exactly when “1. p commutes with every row of S; and 2. p is not in G.” The dressed distanceThe weight of the lightest Pauli string that commutes with every stabilizer and does not lie in the gauge group G. It is the true distance of a subsystem code. is the lightest weight among all such p. The two conditions match two ways of “not counting”: a string anticommuting with some stabilizer trips an alarm, so it does not count; a string inside G only flips don't-care qubits, harmless, so it does not count either. “modulo the full gauge group” refers to the second: two strings differing by a gauge operator are regarded as one and the same, and that gauge operator may be any element of G, not only the center. In plain words: the distance is the lightest operation that fools every stabilizer and really rewrites the protected qubit; each outfit counts once, zig-zag and straight row are the same one.

三件事。第一，不能相信任何大子系统码的 d：看到 bounded 12，你只知道 d 不超过 12；机器没有核对过任何下界，真值是 12、5 还是 4，记录本身不告诉你。第二，不能按噪声方向选码：3 × 5 的参数页只说 d = 3 verified；想知道「Z 方向的码距是 3、X 方向的是 5」（能保证纠正的分别只有 1 个和 2 个错），只能去读 claimed 的引文。第三，不能把一个证书搬到另一种写法上：如果你手里是同一对 (S, G) 的另一份生成元清单（重排过，或加了冗余的生成元），条目里 verified 的 d = 3 在形式上不属于你的清单，尽管你确信是同一个码。规范固定又远一步：把 3 × 3 的六条 ZZ 升级成稳定子就得到 Shor 码（规范固定后的 Bacon–Shor ↔ Shor），rank S 从 4 变成 8，(S, G) 已经不是同一对，「同一 (S, G)」的定理也管不到它（同一个码穿不同的衣服 · 3.3 节列过类似的「今天做不到」）。人话：小码的数字可信，大码的数字只有一半，方向的数字全靠引文，换个写法一切归零。

Three things. First, you cannot trust the d of any large subsystem code: seeing bounded 12 you know only that d is at most 12; no lower bound has been machine-checked, and the record alone does not tell you whether the truth is 12, 5 or 4. Second, you cannot choose a code by noise direction: the 3 × 5 parameters page only says d = 3 verified; to learn “the Z-direction distance is 3, the X-direction one 5” (guaranteeing correction of only 1 and 2 errors respectively) you must read the claimed citation. Third, you cannot carry a certificate to another notation: if you hold another generator list for the same (S, G) (reordered, or with redundant generators added), the entry's verified d = 3 formally does not belong to your list even though you are sure it is the same code. Gauge fixing goes one step further: promoting the six ZZ edges of the 3 × 3 to stabilizers gives the Shor code (gauge-fixed Bacon–Shor ↔ Shor), rank S goes from 4 to 8, (S, G) is no longer the same pair, and a same-(S, G) theorem does not reach it (The same code in different clothes · 3.3 lists a similar “cannot do today”). In plain words: small codes' numbers are trustworthy, large codes' numbers are half, directional numbers rest on citations, and a change of notation resets everything.

4.2纸上三句话就能证的下界，机器为什么不认A lower bound three sentences prove on paper: why the machine does not accept it

对 Bacon–Shor 码，下界是高中水平的。以 r × c 的矩形、X 扇区为例，Atlas 推导页的论证翻成人话是三句话：(1) 穿衣只会让每列里的 X 滑动、成对产生或成对湮灭（1.3 节），改不了每列 X 的个数的奇偶（1.3 节亲手验证过）。(2) 一条 X 型串要与相邻两列的 Z 型稳定子条带对易，就必须让相邻两列的奇偶相同，于是所有列的奇偶一样：全偶或全奇；全偶的串全是规范算符（无害）：同一列里的两个 X 等于它们之间那几条竖边之积，例如 X0X6 = (X0X3)(X3X6)，中间的 X3 乘了两次、消掉；一列里有偶数个 X，就把它们两两配对，每对换成竖边之积，每列都这样做，整条串就是竖边之积，属于 G。所以逻辑算符必须每列都是奇数个 X。(3) 每列至少一个 X，重量至少 c；一整行恰好做到 c。于是 dX = c，同理 dZ = r，d = min(r, c)。第 5 章让你在 3 × 3 上逐句核对。

For Bacon–Shor the lower bound is high-school level. For an r × c rectangle and the X sector, the Atlas derivation page's argument in plain words is three sentences: (1) dressing only slides, creates or annihilates X's in pairs within their columns (1.3) and cannot change the parity of the number of X's in each column (verified by hand in 1.3). (2) For an X-type string to commute with the Z-type stabilizer strip over two neighbouring columns, those two columns must have the same parity, so all columns share one parity: all even or all odd; all-even strings are gauge operators (harmless): two X's in the same column equal the product of the vertical edges between them, for example X0X6 = (X0X3)(X3X6), where the middle X3 appears twice and cancels; a column with an even number of X's can be split into pairs, each pair replaced by a product of vertical edges, and doing this in every column writes the whole string as a product of vertical edges, which lies in G. So a logical must have an odd number of X's in every column. (3) At least one X per column, weight at least c; a whole row achieves exactly c. Hence dX = c, likewise dZ = r, and d = min(r, c). Chapter 5 has you check it sentence by sentence on the 3 × 3.

那为什么 5 × 7 还写着 bounded 12？因为这三句话是针对这一族的：它用了「竖边只在列内滑动」「稳定子是相邻两列的条带」这些 Bacon–Shor 特有的几何。检验员是共享的，它对任何一份 (S, G) 清单只会做两件事——穷举一层层的串，或验一条具体的见证。它没有「读懂一段关于列奇偶的论证」的能力，而 Atlas 也不允许人工把纸上的结论填成 verified（码距篇 2.3 节：那叫 claimed）。证书篇 1.1 节的标准是「证书 = 数据 + 一台不信任任何人的检查器」：三句话是证明，不是证书。要让它成为证书，得把「每列奇偶」这类不变量写成检查器能逐条核对的数据——对 Bacon–Shor 也许做得到，但 statement 要的是对一般的子系统家族都能产出证书的方法，而一般的规范群没有行、列、条带这些现成的结构。人话：我们会证，但证明写在纸上；机器要的是它自己能核对的东西，而且要对任何一份清单都管用。

Then why does the 5 × 7 still say bounded 12? Because the three sentences are specific to this family: they use Bacon–Shor's own geometry, “vertical edges slide only within a column”, “stabilizers are strips over two neighbouring columns”. The referee is shared and does only two things with any (S, G) list: exhaust the strings layer by layer, or validate one concrete witness. It has no ability to “understand an argument about column parities”, and the Atlas does not allow a human to enter a paper conclusion as verified (distance guide 2.3: that is called claimed). The standard of certificate guide 1.1 is “a certificate = data + a checker that trusts nobody”: three sentences are a proof, not a certificate. To make them a certificate, invariants like “column parity” must be written as data a checker can verify item by item; perhaps feasible for Bacon–Shor, but the statement wants a method that produces certificates for general subsystem families, and a general gauge group has no ready-made rows, columns or strips. In plain words: we can prove it, but the proof lives on paper; the machine wants something it can check itself, and it must work for any list.

4.3为什么是 open-research，以及玩具尺度上的账Why open-research, and the arithmetic at toy scale

Wanted 板用两个词分难度：hard-engineering——知道怎么做，但要做很多（例如「从理想症状到真实电路」4.2 节）；open-research——没人知道怎么做。这道题是后者，且比码距篇的同名难题多一层：那里的候选是「与所有稳定子对易且不是稳定子乘积」的串，这里每个候选还要多做一次「在 G 里吗」的判定，而下界证明必须覆盖整个 G 的所有衣服——松弛法（码距篇 4.2 节：不逐点检查也能证最小值）要在商空间 C(S)/G 上设计，文献里没有现成的做法。2.2 节的表已经给出穷举的账：候选数按 C(n, w) · 3w 增长，35 个比特到重量 4 就是四百多万条，超过两百万的预算；再看码距篇 1.4 节的 2n 墙，n = 35 时全部泡利串有 435 ≈ 1.2 × 1021 条。检验员的预算门为什么设在两百万、为什么拒绝半途下界？设计文档：「This boundary makes small finite examples exact while preventing an accidental exponential referee run.」——防止一次验证意外跑上几天；而「半途的下界」若被接受，就会有人把预算调大一点、再大一点，把「跑到哪算到哪」当成证明。人话：穷举的墙和码距篇一样高，商掉规范群让每一步更贵，而绕过墙的松弛法还没人替子系统码发明出来。

The board grades difficulty with two words: hard-engineering, known how but much to do (for example “From ideal syndromes to real circuits” 4.2); open-research, nobody knows how. This problem is the latter, with one more layer than the namesake problem of the distance guide: there the candidates are strings “commuting with every stabilizer and not a product of stabilizers”, here every candidate additionally needs the test “is it in G?”, and a lower-bound proof must cover every outfit in the whole of G; relaxation methods (distance guide 4.2: proving a minimum without checking every point) would have to be designed on the quotient C(S)/G, and the literature has no ready recipe. The table of 2.2 already gives the exhaustion arithmetic: candidates grow as C(n, w) · 3w, and at 35 qubits weight 4 alone is over four million strings, past the two-million budget; recall the 2n wall of distance guide 1.4: for n = 35 all Pauli strings number 435 ≈ 1.2 × 1021. Why is the referee's gate at two million, and why does it refuse half-way lower bounds? The design document: “This boundary makes small finite examples exact while preventing an accidental exponential referee run”, so one verification cannot accidentally run for days; and if “half-way lower bounds” were accepted, someone would raise the budget a little, then a little more, and treat “as far as it ran” as a proof. In plain words: the exhaustion wall is as high as in the distance guide, quotienting by the gauge group makes every step dearer, and the relaxation method that would go around the wall has not yet been invented for subsystem codes.

尾声Epilogue

一份会打架的清单、一件衣服、一道两百万的门A self-fighting list, one outfit, a two-million gate

回放一遍。子系统码允许检查清单互相打架：互不打架的乘积（中心）是真正的稳定子，打架的部分只翻我们不在乎的规范比特，受保护的比特数 k = n − (rank G + rank S)/2。逻辑算符乘上任何规范算符仍是同一条，于是它有很多件衣服；穿了衣服的码距是「与所有稳定子对易、且不在 G 里」的最轻串的重量，商掉的是整个规范群。Atlas 的检验员对 [[4,1,2]]、[[9,1,3]]、[[15,1,3]] 一层层穷举到底（候选数 C(n, w) · 3w，预算两百万），写下 verified；分方向的 dX、dZ 仍是 claimed；对 5 × 7 穷举在第 4 层前拒绝，随机搜索交出一件重量 12 的衣服（seed 17，iters 32），写着 bounded 与 not-certified，尽管纸上三句话就能证 d = 5。我们想要答案，是因为大码的 d 只有一半可信、方向的数字全靠引文、换一种写法证书归零。合格的答案是可扩展的认证下界、命名的扇区、等价安全的表述三样；难度 open-research：纸上的证明用了机器没有的几何，而对一般的规范群，绕过穷举之墙的方法还没有人发明。

Replay. A subsystem code lets its check list fight itself: the mutually commuting products (the center) are the true stabilizers, the fighting part only flips gauge qubits we don't care about, and the protected count is k = n − (rank G + rank S)/2. A logical times any gauge operator is still the same logical, so it has many outfits; the dressed distance is the weight of the lightest string that “commutes with every stabilizer and is not in G”, modulo the whole gauge group. The Atlas referee exhausts [[4,1,2]], [[9,1,3]], [[15,1,3]] layer by layer to the end (C(n, w) · 3w candidates, budget two million) and writes verified; the directional dX, dZ remain claimed; on the 5 × 7 exhaustion refuses before layer 4 and the random search hands over an outfit of weight 12 (seed 17, iters 32), marked bounded and not-certified, although three sentences on paper prove d = 5. We want the answer because a large code's d is only half trustworthy, directional numbers rest on citations, and a change of notation resets the certificate. A qualifying answer is three things, scalable certified lower bounds, named sectors, equivalence-safe presentations; the difficulty is open-research: the paper proof uses geometry the machine does not have, and for a general gauge group the method that would go around the exhaustion wall has not been invented.
