# QEC-Bank-Academy

Interactive tutorials on quantum error-correcting codes, in Chinese and English.
They are the teaching companion to [QEC-Bank](https://github.com/a85tract/QEC-Bank).

**Read online:** https://a85tract.github.io/QEC-Bank-Academy/

Each page is a single HTML file. Every lattice experiment and Monte Carlo
simulation runs locally in your browser, and a button at the top switches
between Chinese and English.

## Two tracks

- **No prerequisites.** Assumes only arithmetic and derives every step on the
  spot.
- **High-school math.** Uses vectors, complex numbers, counting, probability,
  and logarithms, and teaches matrices on the spot. Files for this track end
  in `-hs`.

## Contents

| path | topic |
|---|---|
| `index.html` | series index |
| `toric_code/` | the toric code, starting from parity checks |
| `surface_code/` | the surface code, plus ten entry guides (parameters, decoders, logical operations, hardware experiments, certificates, relations, derivations, references, guided tour, representations) |
| `bb_code/` | bivariate bicycle (BB) codes, with the same set of entry guides |
| `qldpc/` | qLDPC codes and the BP-OSD decoder |
| `wanted/` | ten open problems from the QEC-Bank wanted board |

Entry guides read a code's QEC-Bank record item by item and link to its page on
the [QEC-Bank site](https://a85tract.github.io/QEC-Bank/). Read a code's
intuition guide before its entry guides.
