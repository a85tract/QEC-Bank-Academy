02 / QUBIT

一个量子比特，会沿两条独立方向出错。

普通比特只有 0 / 1 翻转。对量子比特，我们用两个基本错误分量记账；Y 就是两者同时出现（忽略不影响纠错判断的整体相位）。

BIT FLIP

X 错误

可把它想成“数值方向”的翻转。它会让与之反对易的 Z 型校验翻灯。

PHASE FLIP

Z 错误

相位方向的翻转，没有经典硬币的直接对应。它会让 X 型校验翻灯。

BOTH

Y = X + Z

这里的“+”是模 2 记账：同类错误两次抵消。Y 同时触发两套校验。

为什么不直接测量数据？

直接读取量子比特会破坏叠加中携带的信息。稳定子校验只询问一组量子比特的联合奇偶性；理想情况下，它揭示错误，却不揭示编码态中的逻辑 0 / 1。

必须分清：“测量校验”不是“测量逻辑信息”。前者应只暴露综合征。

“响应”仍取决于错误是否落在该校验的 6 个支撑位置中，以及交叠数是奇数还是偶数。

什么仍然是隐藏的？

你看见的是 18 个校验位，不是 18 个数据量子比特的量子态，更不是 4 个逻辑量子比特的内容。综合征只约束“错误属于哪个等价类”。

05 / DECODE

相同脚印，可能是无害等价，也可能是逻辑灾难。

这正是量子解码与“把灯熄掉”之间的差别：任何同综合征修正都会熄灯，但只有逻辑等价的修正才真正成功。

COMMUTATION

为什么一定不变？

X 校验与 Z 校验的支撑总以偶数次相交，因此对易。矩阵语言把所有情况压成一行：

HX(HZ)T = AB + BA = 0

A、B 都由 x、y 的循环平移组成，而 xy = yx；在模 2 中，同一项出现两次就抵消。

穷举最小重量解码器

浏览器枚举全部 218 个分量模式，为每个综合征保存最轻猜测；这是教学用精确解码器，不是论文的 BP-OSD。

07 / FORMAL

把你刚才点亮的每个对象，接回标准数学。

下面不是另一套知识：x、y、A、B、H、综合征、稳定子和逻辑算符，都是前面可见对象的紧凑名字。

  1. 周期平移
    x = Sℓ ⊗ Im，y = Iℓ ⊗ Sm。它们就是网格上的两种环回移动，且 xy = yx。
  2. 双变量配方
    A、B 各是 3 个 x 或 y 幂的模 2 和；所以每行 / 每列恰有 3 个 1。
  3. CSS 校验矩阵
    HX=[A | B]，HZ=[BT | AT]；每行对应一个权重 6 的稳定子生成元。
  4. 对易条件
    HX(HZ)T=AB+BA=0，保证所有 X / Z 稳定子能共同定义编码空间。
  5. 码参数
    n=2ℓm；k=n−rank(HX)−rank(HZ)；d 是与所有检查对易、却不在稳定子行空间中的最轻 Pauli 重量。
  6. 解码目标
    给定 s，找高概率 ê 使 Hê=s；成功条件不是 ê=e，而是 e+ê 属于相应稳定子行空间。

9 × 18 校验矩阵

深色格 = 1。第 9 列后是 L | R 的分界。

9 行中有 2 个线性依赖，所以每类独立稳定子只有 7 个：k = 18 − 7 − 7 = 4。

逻辑 X / Z 是什么？

它们与所有稳定子对易，因此没有综合征；但它们不属于稳定子群，因此会改变编码信息。本页实例的一条最轻逻辑支撑为 L00, L01, L21, R01，重量 4。

“拓扑”具体在哪里？

物理标签位于周期网格，校验由同一模板平移得到；这给出环面布局。但 BB 校验通常不满足二维几何局域：图可分成两个平面层，并不等于单层二维近邻。

CLAIM

“0.7% 阈值”

更准确：小型 BB 码在指定的独立电路级噪声、综合征电路、d 轮测量和 BP-OSD 解码设置下，报告接近 0.7% 的伪阈值。它不是任意硬件、任意解码器的材料常数。

CLAIM

“节省约 10 倍量子比特”

更准确：论文在 p=0.1% 的电路级模型中，以 12 个逻辑量子比特和目标逻辑错误率比较 `[[144,12,12]]` 与多个独立 surface-code patch，得到约 10× 的方案级估计。

BB 码是二维局域拓扑码吗？

不是通常意义的二维几何局域码。它有周期网格 / 环面标签和可平移校验，但部分边是长程的；Tanner 图 thickness = 2，可拆成两个边不重叠的平面子图。

码距 d=12 是否保证能纠正任意 6 个错误？

码距 12 保证唯一纠正任意不超过 ⌊(12−1)/2⌋=5 个数据 Pauli 错误（理想综合征、最优纠错语境）。在含门故障与测量错误的电路级模型中，还要看综合征电路的 circuit distance 与解码器。

论文已经在 144 个数据量子比特的芯片上演示了吗？

该 2024 Nature 工作给出构造、综合征电路、解码与数值模拟，并讨论超导硬件挑战；它不是一个 144 数据比特 BB 码的硬件实验报告。

综合征全 0 是否代表没有错误？

不。可能无错，也可能是稳定子（对逻辑信息无害），还可能是非平凡逻辑算符（逻辑失败）。这就是上一章“零综合征逻辑错”挑战的重点。
