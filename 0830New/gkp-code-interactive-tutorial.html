STATION 02

一个尖峰不可靠，就铺成周期梳子

GKP 不把逻辑 0 放在某一个位置，而把它重复在相隔固定距离的一整列位置上。逻辑 1 使用错开半个周期的另一列。

偶数格：逻辑 0奇数格：逻辑 1
动手 02 · 切换码字
|0̄⟩ ∝ Σₛ |q = 2s√π⟩

所有峰都落在“偶数格”。把整把梳子平移 √π，就得到逻辑 1。

可见物 ↔ 标准术语峰间完整周期 2√π 是稳定子平移；0 与 1 之间的半周期 √π 是逻辑 X̄。
为什么“同时在许多位置”不是偷偷复制量子态？

这些尖峰组成一个不可分割的量子叠加，不是许多可独立读取的副本。直接测 q 会得到其中一个峰，并破坏原来的叠加。纠错测量必须只问“偏离最近格线多少”，不能问“落在哪个偶/奇峰”。

STATION 03

综合征就是余数：量一量偏了多少

把位移除以格距 √π，只保留离最近整数格的余数。解码器反向移动这个余数；留下的整数格数决定有没有逻辑错误。

STATION 04

把无限平面折叠：四个沉默的逻辑锚点

稳定子每隔 2√π 重复一次。把相空间的对边粘起来，就得到一个环面；这不是“实空间的表面码”，而是 GKP 晶格的商空间结构。

同一个解码实验，换一种地图

余数相同，不代表作用相同

下面三个 q 位移测到完全相同的综合征 +0.20√π，但回推后落在不同逻辑类。

0.20√π → syndrome 0.20√π → Ī

它离 Ī 锚点最近；校正成功。

关键不可见性逻辑 X̄、Z̄ 与稳定子对易，所以它们不触发综合征。综合征告诉你“偏离格线多少”，不会告诉你跨过了奇数还是偶数个半周期。
这里的“拓扑”究竟是什么？

稳定子平移晶格是 Λ = 2√π·ℤ²。把相差一个稳定子平移的点视为同一点，得到 ℝ²/Λ；矩形的左右边、上下边分别粘合，所以它在拓扑上是环面。四个零综合征锚点 Ī、X̄、Z̄、Ȳ 位于同一个稳定子基本胞中。

别混淆：单模 GKP 不是把许多物理量子比特铺在二维实空间的拓扑码。它的“环面”来自相空间周期识别。

STATION 07

把直觉对接到标准数学，并学会审计论断

到这里，前面的每个可见对象都有一个标准名字。先固定约定，再谈稳定子、逻辑算符、距离、解码目标与阈值。

本教程的方形 qubit 约定

单位与码字

[q,p] = i, ħ = 1, L = √π
|0̄⟩ ∝ Σₛ |q=2sL⟩
|1̄⟩ ∝ Σₛ |q=(2s+1)L⟩

稳定子与逻辑 Pauli

Sq = exp(i2Lq) = Z̄²
Sp = exp(−i2Lp) = X̄²
Z̄ = exp(iLq)
X̄ = exp(−iLp)

为什么稳定子能一起测？

两次基本平移围成的相空间面积是 4π，因此交换相位是 exp(i4π)=1。

SqSp = SpSq

为什么 X̄ 与 Z̄ 像 Pauli？

半周期平移围成面积 π，交换时多出 exp(iπ)=−1。

Z̄X̄ = −X̄Z̄

综合征方程

位移 u、v 的稳定子相位分别给出模 L 的余数。

rq = wrapL(u)
rp = wrapL(v)

距离与解码目标

在欧氏位移度量下，最短非平凡逻辑位移长 L；最近格点唯一判决半径为 L/2。

ddisp = √π, R = √π/2
“等价误差”精确定义

相差一个稳定子的误差，对码空间作用完全相同。相差一个逻辑算符的误差给出相同综合征，却对编码信息作用不同。因此：同综合征并不等于可互换；解码的统计任务是在所有与综合征一致的逻辑陪集中，选后验概率最大的一个。

理想纠错、现象学噪声、电路级噪声、硬件行为
A

理想数据位移

完美码字、完美辅助与测量；只给数据施加位移。半格判决直接成立。

B

现象学测量噪声

数据位移之外，综合征读数也错。需重复轮次与时序解码。

C

电路级故障

辅助制备、SUM、测量、反馈都可出错，且错误会传播。

D

硬件行为

损耗、非线性、泄漏、控制脉冲与相关噪声，需要设备参数与校准证据。

模型 A 的“|Δ|<√π/2 可纠正”不是模型 C 或 D 的整机容错保证。每加一层现实因素，就要重新定义噪声、解码器和成功事件。

阈值审计器

“GKP 的阈值是多少？”这个问题少了条件

单模最近格点判决给的是几何半格，不是可扩展量子计算的单一阈值。以 toric–GKP 连接码为例，同一篇研究在不同假设下报告了不同数值：

报告值它属于哪个模型不能偷换成什么

6%仅 GKP 纠错测量完美、toric 测量有噪时的模型结果不是普适 squeezing 要求

术语速查

oscillator
振子；提供连续 q、p 自由度的物理载体。
grid state
网格态；在相空间呈周期结构的 GKP 码态。
stabilizer
稳定子；保持所有码态不变、且可测量其本征相位的位移算符。
syndrome
综合征；本教程中是位移对 √π 取模后的信息，不包含逻辑态本身。
logical Pauli
逻辑 Pauli；保持码空间但改变编码比特的半周期位移 X̄、Z̄。
decoder
解码器；根据综合征与噪声先验选择最可能逻辑陪集，并决定校正。

一手来源与适用范围

  • Gottesman, Kitaev & Preskill — Encoding a qubit in an oscillator (2001)原始定义；本页的方形码、稳定子、可纠正位移、有限 squeezing 与辅助态综合征测量均从此约定核验。
  • Matsuura, Yamasaki & Koashi — Equivalence of approximate GKP codes (2020)说明不同有限能量 GKP 近似形式及参数对应；提醒“峰宽”必须连同近似态定义一起报告。
  • Flühmann et al. — Encoding a qubit in a trapped-ion mechanical oscillator (2019)囚禁离子机械振子的 GKP 编码、逻辑门与层析实验；不是持续纠错阈值研究。
  • Campagne-Ibarcq et al. — Quantum error correction of a qubit encoded in grid states (2020)超导微波腔中的方形/六角 GKP 状态与反馈纠错实验；实验结论受装置误差模型与协议约束。
  • Vuillot et al. — Quantum error correction with the toric GKP code (2019)重复有噪 GKP 纠错、最大似然问题及 toric–GKP 阈值；本页阈值审计表的来源。
  • Grimsmo & Puri — Quantum Error Correction with the GKP Code (2021)权威 Perspective；补充超导实现、机会与挑战的系统背景。
