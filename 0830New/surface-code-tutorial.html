01 / 12

当前问题 · 为什么不能等最后再检查？

错误不会举手。我们只能设计问题，让它留下脚印。

普通计算机可以把答案复制很多份；量子信息不能被任意复制，直接测量又会改变它。表面码的核心策略不是“看见错误本身”，而是反复询问许多局部关系是否仍然成立。

物理层

真实器件会发生门错误、退相干、泄漏、测量错误和串扰。它们并不都等价于一个简单翻转。

编码层

把一个逻辑量子比特的状态分散到许多数据量子比特中。没有任何一个物理量子比特单独保存完整答案。

经典层

辅助量子比特给出检查结果；经典解码器读取它们的时空历史，更新“最可能需要补偿什么”。

先建立正确的目标

量子纠错通常不会证明“某个物理量子比特发生了某种错误”。它要保证的是：不同但等价的物理变化仍代表同一个逻辑状态，直到我们有足够证据选择一个安全的补偿类别。

02 / 12

保持不变 · 逻辑值；允许变化 · 它存在哪一份副本里

从三个 0 开始：关系比单个数字更可靠。

先暂时忘记“量子”。把一个普通比特 0 编成 000，把 1 编成 111。只要最多一位翻转，多数表决就能恢复原值；相邻两位的奇偶关系则告诉我们哪里不一致。

实验 01 · 三比特重复码

写入、制造错误、再只看关系

两个检查：
s₁ = b₀ ⊕ b₁
s₂ = b₁ ⊕ b₂

⊕ 读作“异或”：相同得 0，不同得 1。
你刚刚得到的结构：数据、局部检查、综合征、解码、逻辑值。表面码保留这五件事，但会同时保护两类量子错误。

能纠正多少？

三个位置之间的最短“逻辑翻转”要翻 3 位，所以码距 d = 3；它能保证纠正 ⌊(d−1)/2⌋ = 1 个未知翻转。

为什么还不够？

量子比特除了“0 与 1 对调”的 X 错误，还有“相位正负号对调”的 Z 错误。只沿一条线重复，不能同时保护两者。

03 / 12

新障碍 · 相位不会直接出现在一次 0/1 测量里

量子比特不是“同时是 0 和 1”的神秘硬币。

它是一个允许相加的状态：|ψ⟩ = α|0⟩ + β|1⟩。测量概率由振幅的平方给出，而振幅的正负号与复相位会决定下一步叠加时是增强还是抵消。

为什么不能复制任意未知量子态？
假设一个线性操作能同时做到 |0⟩→|0⟩|0⟩、|1⟩→|1⟩|1⟩。对 |+⟩=(|0⟩+|1⟩)/√2，线性性要求输出 (|00⟩+|11⟩)/√2；真正的两份副本却是 (|00⟩+|01⟩+|10⟩+|11⟩)/2，两者不同。这就是“不克隆”的最短证明。
04 / 12

可观测证据 · 把四个数据的奇偶性搬到一个辅助量子比特

不读数据，只读它们之间的约束。

辅助量子比特（ancilla）像一张可擦写便签。让每个数据量子比特依次对它执行受控操作，便签最后只记住整体奇偶性。测量并重置便签，数据中的逻辑叠加可以保留。

05 / 12

正式命名 · “正常关系”就是 +1 本征值

稳定子：一个不会泄露逻辑答案的合格问题。

稳定子 S 是一串 Pauli 算符的乘积。合法编码态 |ψ̄⟩ 满足 S|ψ̄⟩=+|ψ̄⟩。如果误差 E 与 S 反对易，那么 S(E|ψ̄⟩)=−E|ψ̄⟩，测量结果从 +1 翻到 −1。

正常：S|ψ̄⟩ = +|ψ̄⟩　　出错：SE = −ES ⇒ S(E|ψ̄⟩) = −E|ψ̄⟩

X 型稳定子

SX=X₁X₂X₃X₄。它对 Z 或 Y 误差敏感，因为 X 与 Z 在同一量子比特上反对易。

Z 型稳定子

SZ=Z₁Z₂Z₃Z₄。它对 X 或 Y 误差敏感。X 与 Z 的角色完全对偶。

单点规则

同类相遇或有一个 I：对易
X 与 Z、Z 与 Y、Y 与 X：反对易

×
多点规则

数一数“反对易相遇”有几次。偶数次整体对易，奇数次整体反对易。

为什么所有检查必须两两对易？

因为我们要能同时给它们指定确定的 +1 结果。表面码的 X 与 Z 检查要么不重叠，要么重叠在 2 个数据量子比特上；两次反对易的负号相乘回到 +1。

07 / 12

可见证据 · 错误链的端点

表面码不看链的内部，只看它在哪里结束。

一个 Z 错误会翻转与该数据位相邻的 X 检查；相邻 Z 错误共享的检查被翻两次，又回到 +1。因此一串错误通常只在端点留下 −1 综合征。链也可以终止在允许它消失的边界。

简并性：很多不同误差链会产生同一个综合征。它们相差一个稳定子时，对逻辑信息的作用完全等价。因此综合征从来不是“错误位置的完整照片”。
为什么闭合小环没有综合征？
环上每个相邻检查都与错误链相交偶数次，所以所有检查仍给出 +1。若这个环恰好是若干稳定子边界的乘积，它对编码空间等同于恒等操作；如果它穿过了不可收缩的拓扑路径或连接了相应边界，它可能成为逻辑算符。区别不在局部形状，而在全局同调类别。
08 / 12

决策任务 · 选择一个与真实误差同类的修正

解码不是猜中每一步，而是别选错拓扑类别。

解码器只得到综合征和噪声模型。它寻找一条很可能产生相同端点的修正链 C。只要真实误差 E 与 C 合起来是稳定子，逻辑信息就安全；若合起来跨越整块码面，就发生了逻辑故障。

提示会出现在这里。

最小权完美匹配（MWPM）

把检测事件视为图上的顶点，把候选错误链视为带权边，寻找总权重小的配对。边权通常接近 −log P(edge)，所以“最短”应理解为“最可能”，不一定是几何距离最短。

其他解码器

Union-Find、张量网络、信念传播、神经网络和相关噪声感知方法各有速度、精度、并行性与校准成本的取舍。解码器是容错系统的一部分，不是事后插件。

09 / 12

新增维度 · 检查结果自己也会错

单轮综合征只是快照；检测事件来自相邻轮次的变化。

若第 t 轮的检查值 m(t) 与上一轮不同，就记一个检测事件 d(t)=m(t)⊕m(t−1)。数据错误常在同一时间产生空间上相邻的事件；一次测量错误常在同一检查的相邻时间产生两个事件。

实验 07 · 时空解码图

比较三种故障留下的形状

检测事件：dᵢ(t)=mᵢ(t) ⊕ mᵢ(t−1)
解码对象：二维空间 × 一维时间
“重复 d 轮”背后的理由

码距不仅要抵抗数据链，也要抵抗时间方向上的测量故障链。一个距离 d 的存储实验通常运行至少与 d 同量级的综合征轮次来显露时空距离；具体电路、边界初始化和最终测量会加入额外检测器。

10 / 12

全局自由度 · 局部检查管不到的一条线

逻辑量子比特藏在“跨越整块面”的选择里。

稳定子固定了所有局部奇偶关系，但没有固定一条连接同类边界的 Pauli 字符串。竖直的 Z̄ 与水平的 X̄ 在一个数据位相交，所以反对易：X̄Z̄=−Z̄X̄。它们正好像一个普通量子比特的 X 与 Z。

逻辑字符串观察器

切换逻辑算符与等价路径

把路径沿一个稳定子边界推移，只是多乘了一个稳定子，所以逻辑作用不变。能连续缩成局部小环的闭合路径是平凡的；跨接相应边界的路径不平凡。
d = min wt(P)
P ∈ N(𝒮) \ 𝒮

逻辑 Pauli

通常不必真的把修正门打回芯片；经典控制器可维护一个 Pauli frame，在后续测量解释中吸收它。

逻辑 Clifford

可借助码变形、补丁旋转、边界交换或晶格手术实现；实现细节依架构而异。

非 Clifford

常见路线是注入并蒸馏 magic state，再用量子传态消耗它。表面码本身并不会免费给出通用门集。

晶格手术为什么能做两逻辑比特测量？
把两个补丁的相邻边界临时合并，开始测量跨边界的新稳定子；这些新结果的乘积给出联合逻辑算符（如 Z̄⊗Z̄ 或 X̄⊗X̄）的本征值。经过足够轮次后再分开补丁，就得到一个容错的联合奇偶测量。CNOT 可以由这类联合测量、辅助逻辑补丁和 Pauli frame 更新组合出来。

现实检验 · 增加量子比特何时才有帮助？

阈值不是一条材料常数，而是一整套方案的交叉点。

在给定噪声模型、综合征电路和解码器下，如果物理错误率低于阈值，提高码距会指数压低逻辑错误；高于阈值时，增加部件反而加入更多故障机会。

阈值依赖什么

门、复位、测量、空闲、泄漏和相关噪声；检查电路与调度；解码器及其延迟；边界与逻辑操作；评价指标。脱离这些假设谈“表面码阈值”是不完整的。

为什么仍受欢迎

检查是局部且低权重的，适配二维最近邻器件；研究成熟、解码方法多、容错逻辑路线清晰。代价是每个高质量逻辑量子比特通常需要大量物理资源。

阈值之下也不等于“已经可用”

可扩展计算还需要逻辑门、魔态工厂、实时解码、布线控制、长期校准和极低的稀有相关事件。2023 年实验展示了 d=5 略优于 d=3；2024/2025 年发表的 Willow 结果进一步报告 d=3→5→7 的低于阈值缩放。它们是关键里程碑，但不是通用容错计算机已经完成。

毕业标准 · 能推导、能解码、能审计假设

把直觉压缩成专家可检查的形式。

如果你能独立解释下面每个公式如何对应前面的可见对象，并在毕业挑战中达到 8/10，你已具备阅读表面码论文与模拟器文档的核心语言。真正的专家还会为每个数字追问噪声模型、边界、轮次和解码器。

1 · 稳定子码

𝒮 是 n 比特 Pauli 群的阿贝尔子群，−I∉𝒮。码空间是所有 S∈𝒮 的共同 +1 本征空间。若有 r 个独立生成元，则 k=n−r。

𝒞={|ψ⟩:S|ψ⟩=|ψ⟩,∀S∈𝒮}

2 · CSS 对易条件

X 与 Z 生成元分别由二进制矩阵 HX、HZ 给出。每对行的重叠必须为偶数。

HXHZT=0 (mod 2)

3 · 综合征方程

把 X、Z 错误位置写成二进制向量 eX、eZ。Z 检查检测 X 错，X 检查检测 Z 错。

sZ=HZeXT
sX=HXeZT

4 · 逻辑算符与距离

正规化子 N(𝒮) 中不属于 𝒮 的 Pauli 保持码空间却改变逻辑信息。最小权重就是距离。

d=minP∈N(𝒮)\𝒮 wt(P)

5 · 解码

给定综合征 s，选择后验概率大的等价类，而不只是单条误差。独立噪声下常近似成加权图的最短链/匹配。

Ĉ=arg max[C]:∂C=s Pr([C]|s)

6 · 容错时空

检测事件是检查值随时间的变化。数据故障、门故障和测量故障成为三维图中的边；逻辑失败是跨越时空边界的非平凡链。

dᵢ(t)=mᵢ(t)⊕mᵢ(t−1)

专家速查词典

data qubit · 数据位
承载编码状态的物理量子比特，不在每轮直接测量。
ancilla / measure qubit
与邻近数据位耦合后被测量和重置，用来抽取检查结果。
stabilizer · 稳定子
把码空间固定为 +1 本征空间的 Pauli 乘积。
syndrome · 综合征
一组检查结果；在循环 QEC 中通常更关心其轮间变化。
detector · 检测器
在无故障时结果确定的测量结果组合；触发值叫 detection event。
code distance d · 码距
最小非平凡逻辑 Pauli 的权重；电路级距离还要考虑故障传播与时间。
rough / smooth boundary
允许某一类链端点凝聚的两类边界；不同绘图约定会交换名称，判断应看哪类检查被截断。
homology · 同调
把“相差局部稳定子变形”的链归为同类，并区分是否跨越全局边界。
decoder · 解码器
从检测事件与噪声模型推断修正等价类的经典算法。
Pauli frame
经典记录中尚未物理施加的逻辑/物理 Pauli 修正。
lattice surgery · 晶格手术
通过合并/拆分边界稳定子执行逻辑联合测量。
threshold · 阈值
