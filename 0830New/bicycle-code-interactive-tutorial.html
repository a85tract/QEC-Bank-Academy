量子纠错不能偷看被保护的未知状态。它改问一组更克制的问题：某些位置上的翻转总数是奇数还是偶数？

物理量子比特

真正会受噪声影响的硬件单位。教程中的 L0…L6 与 R0…R6 共 14 个。

两类基本翻转

X 像把 0/1 对调；Z 改变相位。Y 同时含 X 与 Z 分量。CSS 码把两类线索分开处理。

测量什么

测的是稳定子校验的 ±1（这里显示成 0/1 综合征），不是逻辑量子比特本身的未知振幅。

让一行规则绕成一圈

Bicycle 的机关不是一辆自行车，而是“循环移位”。写一行种子，向右挪一格又是一条校验；到边缘就从另一侧回来。

7 个位置里，第 0、1、2、4 位取 1。拖动行号，看它如何循环平移。

x 只是“平移一格”的记号；x⁷ = 1 表示走七步回到原位。

为什么叫 Bicycle

原论文把这种 [C, Cᵀ] 的双循环块称为 construction B / bicycle。这里的“双轮”是忠实的代数图像，不是额外的物理假设。

同综合征 ≠ 同错误

若 E 与 E′ 的差是稳定子，它们对编码态作用相同；这种“简并”不是漏洞，而是量子码的特征。

成功条件

E + Ê ∈ row(H)

真实错误 E 和修复猜测 Ê 相加后只是稳定子，逻辑信息没有改变。

逻辑失败

E + Ê ∈ ker(H) \ row(H)

报警全灭，却残留一个非平凡逻辑算符——这正是最危险的失败。

检查点：两个错误给出相同综合征，能直接断言它们等价吗？

对象对照表

S：向右循环移一格的 7×7 矩阵。

C = I+S+S²+S⁴：左轮连接规则。

Cᵀ：反向移位，右轮连接规则。

H=[C│Cᵀ]：7×14 校验矩阵，秩为 6（有一条冗余行）。

Hₓ=H𝓏=H：分别生成 X、Z 型稳定子。

CSS 定义与综合征

Hₓ H𝓏ᵀ = 0
s𝓏 = H𝓏 eₓᵀ,   sₓ = Hₓ e𝓏ᵀ

这里 eₓ,e𝓏 是错误的二进制位置向量。X 错误与 Z 稳定子反对易，所以出现在 s𝓏；反之亦然。

k = n − rank(Hₓ) − rank(H𝓏)
= 14 − 6 − 6 = 2

逻辑算符与距离

一个 X 型逻辑算符是 ker(H𝓏) 中却不在 row(Hₓ) 的向量。穷举全部 2¹⁴ 个二进制向量，最轻的非平凡代表重量为 3，因此 d=3。

X̄₁ = X(L0)X(L2)X(L3)
Z̄₁ = Z(L0)Z(L2)Z(L3)

二者重叠 3 次，故反对易；它们与所有稳定子对易。

解码目标

Ê = arg min |e′|   subject to   H e′ᵀ = s

我们的浏览器解码器对 14 位玩具码做完整穷举，所以“最小重量”是精确的。大码不能这样做，实践中常用 BP、OSD 等近似算法。

距离 3 的含义：能保证纠正任意 1 个未知 Pauli 错误；并不保证纠正任意 2 个。

展开：完整 7×14 的 H
展开：为什么 Y 需要两份综合征

忽略整体相位时 Y = XZ。它既有 X 分量又有 Z 分量，所以既会触发 Z 型校验，也会触发 X 型校验。CSS 的分开解码很清楚，但若噪声中 X/Z 相关，完全分开也可能损失信息；原始 Bicycle 论文已讨论利用这种相关性改进译码。

06 / 07

它的“拓扑”到底在哪里

原始 Bicycle 首先是代数上的准循环 CSS 码，不应不加限定地叫作二维局域拓扑码。它的周期边界来自循环索引；双变量扩展才把两个平移方向组织成环面布局。

家族关系

原始 Bicycle
C → H=[C│Cᵀ]
Generalized Bicycle
A,B → Hₓ=[A│B], H𝓏=[Bᵀ│Aᵀ]
Bivariate Bicycle (BB)
x=Sℓ⊗Iₘ, y=Iℓ⊗Sₘ
A=A(x,y), B=B(x,y)

只要 A 与 B 可交换，就有 HₓH𝓏ᵀ=AB+BA=0（模 2）。2024 BB 构造常取 A、B 各含 3 个移位项，因此校验重量为 6。

关键限定：BB 的节点可排在带周期边界的二维网格上，校验由平移生成；但其校验通常包含长程边，所以不像表面码那样几何局域。其 Tanner 图可拆成两层平面、每层度数 3，不等于“单层二维最近邻”。
