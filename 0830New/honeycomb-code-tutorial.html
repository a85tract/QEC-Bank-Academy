会呼吸的量子记忆

大多数纠错码像一座固定的城墙。Honeycomb code 更像一支按 0 → 1 → 2 节拍巡逻的队伍：每次只检查一对邻居，却从跨时间的记录里拼出六体约束，并在不断变化的瞬时码空间里守住两个逻辑量子比特。

00 · 先看任务，不背术语

我们真正要保护的，不是某一个格点。

一个物理量子比特很脆弱；编码把信息分散到整张网格。测量只询问“两个邻居在某个 Pauli 方向上的奇偶关系”，不直接读取被保护的逻辑信息。错误留下的不是身份证，而是一组可见的detector events；译码器猜最可能的错误链。

顶点

每个蜂窝顶点放 1 个物理量子比特。

边

每条边测一个两体检查：XX、YY 或 ZZ。

面

六条边的记录合成一个 weight-6 plaquette stabilizer。

隐藏

逻辑量子态与具体错误链都不会被检查直接读出；只看到兼容它们的症状。

30 秒量子生存包

Q

量子比特不是藏着 0 或 1 的小盒子。它可以对不同问题给出统计结果；测量会改变它，不能把所有问题的答案同时抄下来。

P

X、Y、Z 是三类 Pauli 问题。它们不是空间里的普通箭头。对同一量子比特，某些问题不兼容；代数里用“反对易”记录这种冲突。

⊗

PP 是联合问题。例如 ZZ 只返回两个量子比特的 Z-parity 为 +1 或 −1，不必分别泄露每个量子比特的 Z 结果。

02 · 六个随机数如何说真话

单次结果可以随机；它们的乘积却受约束。

一个 type-a 六边形周围只有另外两种轮次标签。连续测完这两类边，就能把 6 个两体结果相乘，推断该面的 plaquette stabilizer。与上一次推断值比较，变化才叫 detector event。

03 · 症状不是错误的照片

同样的两个端点，可能藏着不同的路径。

译码器得到的是错误链的边界，而不是错误链本身。恢复链只需连接相同端点；真正决定成败的是“真实错误链 ⊕ 恢复链”是否形成不可收缩的绕圈。

04 · 把你已经看见的现象写成数学

术语现在不是门槛，而是压缩包。

下面的每个符号都对应前面可操作的对象。默认几何是周期边界的环面；平面边界需要修改测量时序与译码图，不在这个局部演示里偷偷混用。

1. 两体检查与三步日程

顶点集合 V 放量子比特。边 e=(u,v) 有方向标签 α(e)∈{x,y,z} 与轮次标签 c(e)∈{0,1,2}。

Cₑ = σᵅ(e)ᵤ σᵅ(e)ᵥ
Mᵣ = { Cₑ : c(e)=r mod 3 }

相邻且共享一个顶点的不同 Pauli 检查反对易，因此不能把所有边同时当成固定 stabilizer 测量。

2. 面算符与 detector

对六边形 p，沿边界相乘得到 weight-6 面算符（整体相位选成 Hermitian）：

Wₚ ∝ ∏ₑ∈∂p Cₑ
[Wₚ, Cₑ] = 0
dₚ(t) = [1 − sₚ(t)sₚ(t−3)] / 2

这里 sₚ∈{±1}；dₚ=1 表示相隔一个三步周期的推断发生变化。

3. 瞬时 stabilizer 群为什么留下两个逻辑量子比特

时刻ISG 生成元（忽略符号）发生了什么
初始{I}尚未建立码空间
轮 0 后type-0 checks每对活跃边成为一个约束
轮 1 后type-1 checks + type-2 plaquettes首次推断一类面
轮 2 后type-2 checks + type-2、0 plaquettes第二类面进入 ISG
r ≥ 3当轮 checks + 全部 plaquettes稳态，ISG 以 3 轮为周期

环面有 nₚ 个面、2nₚ 个物理量子比特。稳态 ISG 秩为 2nₚ−2，所以码空间维数 2²=4，即保护 2 个逻辑量子比特。若忽略测量顺序把所有 checks 当成 subsystem gauge group，则反而没有逻辑量子比特——时间顺序就是编码的一部分。

4. 逻辑算符会演化

内逻辑算符是沿环面不可收缩回路的 checks 乘积，与所有 checks 对易，代表可保持不变的长环。外逻辑算符的代表随轮次改变。

measurement period = 3
outer-logical period = 6
e ↔ m each subround

每三轮，外逻辑代表会乘上一个平行的内逻辑算符（忽略符号）；再过三轮才返回。随机测量符号必须保留在 classical Pauli frame 中。

5. 距离与译码目标

环面上的码距随系统线性尺寸增长。译码图在 2+1 维时空中分成两个同构于剪切简单立方晶格的连通分量；MWPM 寻找最可能的 1-chain。

given ∂E = detector events
find R with ∂R = ∂E
success ⇔ [E ⊕ R] = 0 in homology

“最短”只在独立同分布近似下等价于“最可能”；相关错误需要加权或相关译码。

实验 4 · Pauli 对易计算器

输入等长的 I/X/Y/Z 字符串。每个位置若两者都是非 I 且不同，就贡献一次反对易；贡献次数为奇数时整体反对易。

默认例子在第 2 个量子比特上 X 对 Y，只有 1 次局部反对易，所以整体 反对易。
05 · 阈值不是一个属于代码的常数

先问噪声模型，再谈“性能好不好”。

阈值会随门集、测量实现、相关性、边界、译码器与报告口径变化。下面数字来自 Gidney 等人的 Monte Carlo 研究；它们是模型内估计区间，不是任何 honeycomb 硬件的保证书。

实现边界
本页精确演示的是周期环面 bulk 机制。实验硬件通常需要平面补丁；平面 honeycomb code 会加入边界、修改测量顺序，并出现可在边界终止的新错误路径。2022 年平面基准研究给出 SD6 / SI1000 / EM3 约 7000 / 50000 / 900 个物理量子比特的 teraquop 投影（p=10⁻³），但这依赖外推、目标口径和具体电路，不能当作已实现的硬件数字。
