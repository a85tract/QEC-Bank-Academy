00 / 先补三块地基

我们不直接“看”量子信息。

直接测量一个未知量子态会扰动它。纠错的办法是问一些更克制的问题：某一组量子比特的翻转次数是偶数还是奇数？答案只有 +1 或 −1，却足以暴露局部错误。

0 / 1

普通比特

像一张正反面卡片。翻一次，0 变 1；再翻一次，又回到 0。这里只需要会数奇数和偶数。

α|0⟩+β|1⟩

量子比特

它可处于 0 与 1 的组合。α、β 是组合方式；本教程不会要求你计算它们。关键是：保护它们，而不是读出它们。

±1

检查（stabilizer）

检查只返回“符合规则”(+1) 或“违反规则”(−1)。这些答案合在一起叫综合征（syndrome）。

三个误差字母： X 是“0/1 翻转”分量，Z 是“相位翻转”分量，Y 同时含有 X 与 Z 分量。暂时把它们当作三种不同墨迹即可。
01 / 地图先于术语

点存数据，面负责盘问。

七个量子比特放在顶点。红 R、绿 G、蓝 B 三张面各触碰四个点；纹理与字母让颜色不是唯一线索。每张面都问两次：一次用 X 检查捕捉 Z 分量，一次用 Z 检查捕捉 X 分量。

R 面 · 斜纹 · {1,2,3,4} G 面 · 点纹 · {2,3,5,6} B 面 · 横纹 · {3,4,6,7}

为什么三色？

在更大的 2D color code 晶格中，每个内部顶点有三条边相遇，面可以用三种颜色着色，且共享一条边的相邻面不同色。

什么被编码？

六个独立的“+1 规则”从七个量子比特的巨大状态空间中圈出一个二维子空间；这个子空间恰好容纳一个逻辑量子比特。

什么仍然隐藏？

检查告诉我们哪里违反了规则，却不告诉 α、β，也通常不唯一指出真实误差。纠错依赖的是误差类别，而不是完整侦探报告。

02 / 核心工作台

制造错误，然后只看它留下的影子。

选择 X、Z 或 Y 墨迹，再点击任意编号点。面变粗表示至少一个对应检查为 −1；真正要读的是下方六盏检查灯。

A · ERROR → SYNDROME

先试 Z₅，再试 X₂，最后试 Y₃

Z₅ 只触碰 G 面，所以只有 G 的 X 检查翻成 −1。X₂ 触碰 R、G 两面，所以两张面的 Z 检查翻转。Y₃ 位于三面交会处，又同时含 X 与 Z，于是六盏灯全灭。

B · EQUIVALENCE

不同墨迹，也能有同一影子

点“等价对：Z₅ ↔ Z₂Z₃Z₆”。两者相差整个 G 面的 Z 稳定子，因此综合征相同，对逻辑信息的作用也相同。这叫退化（degeneracy）。

为什么乘一个面不改变答案？

每对面重叠 0、2 或 4 个点，都是偶数。模 2 世界里，偶数次反对易抵消，所以所有稳定子彼此对易。

C · DECODING

解码器猜“最轻”的解释

在当前理想模型里，每个非零 3 位综合征都对应一个单点。点“运行最小权重解码器”，它会独立处理 X 与 Z 分量。注意：它猜得合理，不代表猜中了真实历史。

D · LOGICAL FAILURE

让检查全部通过，却把信息改掉

装入“双错误陷阱 Z₁Z₂”，再运行解码器。综合征 010 看起来像 Z₅，于是校正后留下 Z₁Z₂Z₅：灯全亮，但它是一个逻辑 Z。距离 3 的代码能保证纠正任意 1 个错误，不保证纠正 2 个。

03 / 把时间加回来

一次坏读数，不等于一次数据错误。

真实机器要重复测量检查。解码器常看相邻轮次是否变化：dₜ = mₜ ⊕ mₜ₋₁。持续的数据错误通常制造一次变化；单轮测量毛刺通常制造前后两次变化。这里忽略最终边界读出，只展示中间因果。

模型升级：现象学噪声

现在数据与测量都可能错，但还没有展开具体门电路。检查读数被当作一个抽象的、可独立出错的过程。

05 / 现在再给它名字

你已经操作过这些公式里的每个对象。

下面的 1 表示“这张面触碰这个量子比特”。所有加法都按奇偶计算：1+1=0。H 同时描述 X 面与 Z 面，这是 color code 的 X/Z 对称性。

Parity-check matrix

HX = HZ = H

1111000 0110110 0011011

三行依次是 R、G、B 面。每行重量 4；任意两行重叠 2 个位置。

HX HZT = H HT = 0 (mod 2)

这正是 X 稳定子与 Z 稳定子对易的二进制条件。

Syndrome equations

灯是矩阵乘法的结果

把误差拆成 X 分量 eX 与 Z 分量 eZ。Y 在两边都记 1：

sX = HZ eXT
sZ = HX eZT

这里 sX 是“X 误差分量的综合征”，由 Z 检查读出；sZ 反之。文献的下标习惯可能按误差或按检查命名，阅读时务必看定义。

Code parameters

为什么是 [[7,1,3]]？

n = 7
七个物理量子比特。
k = 1
rank(H)=3，所以 k=7−3−3=1。
d = 3
最轻的非平凡逻辑算符重 3，例如 X₅X₆X₇ 或 Z₅Z₆Z₇。
t = 1
保证可纠正 ⌊(d−1)/2⌋=1 个任意位置的 Pauli 错误。

Logical operators & decoding

零综合征不等于“什么也没发生”

XL=X₁X₂X₃X₄X₅X₆X₇，ZL=Z₁…Z₇。乘 R 面稳定子后，它们分别等价于边界上的 X₅X₆X₇、Z₅Z₆Z₇，因此距离是 3。

正确的解码目标：在给定综合征和噪声模型下，选择概率最大的稳定子陪集（equivalence class），而不只是寻找某个看起来最像的具体误差。本工作台的“单点最小权重”只是小代码、理想模型下的特例。

理想数据误差

只有数据点会错，检查完美。核心工作台和精确曲线使用此模型。

现象学测量噪声

数据和抽象读数都可错，需要时间维度与 detector events。时间实验使用此层。

电路级 / 硬件噪声

把制备、双比特门、测量、空闲、泄漏、串扰和相关性展开。真正的硬件阈值与资源估计必须在这一层审计。

END / 你现在该会什么

Color code 是一张会回答奇偶问题的拓扑地图。

颜色组织局部检查；综合征暴露错误与稳定子的对易关系；解码选择等价类；逻辑失败则是“所有局部问题都答对了，全球信息却已改变”。这条因果链比记住任何单个阈值更重要。
