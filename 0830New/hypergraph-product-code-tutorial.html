一个检查不问每个 bit 是多少；它只问：我照看的 1 有几个，是偶数还是奇数？

量子世界只多了哪一步？

经典 bit 在读取时给出 0 或 1。bit-flip 把 0↔1。

量子比特 还保存“相对相位”。因此需要分开追踪两种基本误差：

X 误差：像 bit-flip；
Z 误差：改变相位；
Y 误差：同时含 X 与 Z。

本例把 1 个逻辑量子比特 α|0̄⟩+β|1̄⟩ 分散编码进 13 个物理量子比特；α、β 不属于棋盘上任何单独一点。这里模拟 Pauli 误差的二进制支持，不模拟任意量子态振幅。

关键限制：检查只返回 ±1（页面写成 0/1）这种奇偶信息，不返回被编码的逻辑振幅。我们得到“错误脚印”，却没有偷看逻辑量子态。

02

让两条路径相乘

每条路径都是刚才那个 3-bit 重复码的 Tanner 图：v₀—c₀—v₁—c₁—v₂。把一条横放、一条竖放，交点的类型决定那里放什么。

实验 2 · 分层搭建乘积棋盘

轴数据检查完整网络

完整网络：相邻节点连接，显示两条 Tanner 路径的笛卡尔积。

V₁×V₂9 个圆形数据量子比特
C₁×C₂4 个菱形数据量子比特
C₁×V₂6 个 X 检查
V₁×C₂6 个 Z 检查

为什么是 13 个数据位？

N = n₁n₂ + m₁m₂
= 3×3 + 2×2 = 13

n 是变量节点数，m 是检查节点数。数据落在“同类交点”：V×V 与 C×C。

“拓扑”在哪里？

不是说这张图必须铺在二维芯片上。真正的结构是一个 2 维链复形：V₁×C₂（Z 检查 / 面）→ V₁×V₂ ⊕ C₁×C₂（量子比特 / 边）→ C₁×V₂（X 检查 / 点）；边界的边界为零。

HGP 通常含长程连接。棋盘表达代数邻接，不承诺几何局域性。

持续对象：这块棋盘

右侧的 5×5 棋盘正是两个长度 5 的 Tanner 路径之积。13 个圆/菱形是物理量子比特；其余 12 个方块是稳定子检查。接下来所有误差、syndrome 与矩阵行都落在同一组对象上。

03

误差不会说话，检查会

选择右侧的 X 或 Z 笔，再点数据量子比特。被触发的检查会显示“!”；这就是 syndrome。

实验 3 · 预测一枚误差的脚印

先按“单个 X 误差”，在脑中数一数它邻接几个 Z 检查，再看棋盘。因为 X 与 Z 反对易，X 误差只触发 Z 类型检查；Z 误差反过来。

sZ = HZ eXᵀ　·　sX = HX eZᵀ　（mod 2）

看得见

哪些检查翻转，即 syndrome；也可以重复测量，比较随时间的变化。

仍隐藏

逻辑量子态的振幅、准确错误代表元、以及“这串零 syndrome 是否其实是逻辑算符”。

为什么两枚误差可能抵消警铃？

同一个检查若同时碰到两枚相关误差，会得到 1+1=0（mod 2）。所以 syndrome 不是错误照片，只是错误经过 H 后的投影。不同错误可以留下完全相同的脚印。

本页默认 syndrome 测量完美。若测量本身会错，单轮的 “!” 也可能是仪器错误；那时必须引入时间维度与 detector event。

04

相同脚印，不同结局

量子解码不要求猜中原始误差；只要“真实误差 + 修正”是稳定子，就算成功。难点是：零 syndrome 也可能藏着逻辑算符。

实验 4 · 加一个稳定子，脚印不变

先放一个 X 误差，再加任意一行 X 稳定子。物理误差图案改变了，但 Z-check syndrome 不变，因为每个 X 稳定子与每个 Z 检查都有偶数个重叠。

等待实验。

E ∼ E ⊕ S　⇔　二者只差一个稳定子。解码目标是等价类，不是唯一的 E。

实验 5 · 让最小重量解码器踩进逻辑陷阱

这个小码的最短逻辑 X 有 3 枚。我们只放其中 2 枚；它们与“缺掉的那 1 枚”拥有相同 syndrome。最小重量解码器会合理地选 1 枚修正，但三枚合起来正好形成逻辑 X。

05

现在，把棋盘压成矩阵

你已经操作过每种对象。下面只是在为刚才发生的事取标准名字。

一般构造

HX = [ H₁⊗In₂ │ Im₁⊗H₂ᵀ ]
HZ = [ In₁⊗H₂ │ H₁ᵀ⊗Im₂ ]

这里 Hᵢ 是 mᵢ×nᵢ 的二进制经典校验矩阵；⊗ 是 Kronecker 积。左块对应 V×V 量子比特，右块对应 C×C 量子比特。

toy code 的完整矩阵

红色分隔线左边是 9 个 V×V 量子比特，右边是 4 个 C×C 量子比特。每行的 1 与棋盘上一只检查照看的数据位完全一致。

换一对检查，亲眼看它们为什么对易

它们重叠 2 个量子比特；2=0（mod 2），所以对易。

HXHZᵀ = (H₁⊗H₂ᵀ) ⊕ (H₁⊗H₂ᵀ) = 0

编码多少？

K = k₁k₂ + k₁ᵀk₂ᵀ

本例 H 满秩：k₁=k₂=1，转置码维数为 0，所以 K=1。

距离多大？

dQ ≥ min(d₁,d₂,d₁ᵀ,d₂ᵀ)

本例转置码平凡（距离记 ∞），经典重复码 d=3，且可找到重量 3 的逻辑 X/Z，所以 dQ=3。

06

别让一个 threshold 脱离模型

“阈值是多少？”必须连同码族、解码器、噪声、syndrome 提取方式与有限尺寸证据一起回答。

四层噪声模型审计

层级什么会错需要的数据本教程
code capacity数据量子比特可带 X/Z；检查完美单轮 syndrome交互支持，不采样
phenomenological数据与测量结果都可错多轮 syndrome / detector events只解释边界
circuit level门、制备、测量、idle 都可故障并传播具体提取电路与时序未模拟
hardware还含连通性、串扰、泄漏、延迟与校准漂移设备特定实验未声称

怎样正确阅读 “约 7.5% / 约 3%”

Grospellier 等人在特定的 (3,4)-双正则 HGP 码族、特定混合 BP+SSF 解码器和独立 bit/phase flip 模型下，报告数值证据：理想 syndrome 提取约 7.5%，含 syndrome 噪声时接近 3%。这不是“所有 HGP 码的阈值”，也不是电路级硬件承诺。

审计句式：“对哪个码族，用哪个解码器，在什么噪声与测量模型下，由什么尺寸的数据得到？”五项缺一，就先别比较数字。

可推广的结构

两任意经典校验矩阵都可进入 HGP 构造；稀疏种子会保留稀疏检查。合适的经典 LDPC 族可得到常数编码率与 Θ(√N) 距离。

不可从 toy 推断

13-qubit 穷举解码器的速度、有限尺寸表现、二维布线代价、 syndrome 电路深度与硬件阈值都不能外推。

机制边界 · 本页究竟做了什么

所有 syndrome、稳定子等价、逻辑类和最小重量修正都由页面内的二进制矩阵实时计算。解码器枚举 2¹³ 个 Pauli 支持，适合教学小码；它不是 small-set-flip、BP、OSD 或工程解码器。页面不模拟量子振幅、测量回路或噪声采样。
