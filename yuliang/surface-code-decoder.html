不读出秘密，怎样发现错误Detect damage without reading the secret

把“有没有损坏”变成可测问题，先要说明什么信息必须继续隐藏。To ask whether information was damaged, first identify what a check must leave hidden.

把一个比特重复三次，可以通过比较副本来发现翻转。但量子计算要保存的对象还有相对符号：用两个分量写成 α|0⟩+β|1⟩，α、β 是振幅，模平方给出测量概率，总和为 1。竖线和尖括号只是标记状态。直接测量通常只得到 0 或 1，不能把原来的两个振幅都读出后再放回去。纠错必须问一个更窄的问题：状态是否仍满足编码时设下的共同约束？Repeating a classical bit three times lets us detect flips by comparing copies. A quantum state also carries relative signs: write its two components as α|0⟩+β|1⟩. The amplitudes α and β have squared magnitudes that give measurement probabilities and sum to one. The vertical line and angle bracket simply label a state. A direct measurement usually returns only 0 or 1; it does not reveal both amplitudes so that we can put them back. Error correction must ask a narrower question: does the state still obey the shared constraints imposed by the encoding?

先看两个物理量子比特。测量 Z₁Z₂ 只区分“00 或 11”与“01 或 10”，分别返回 +1 与 −1。在理想测量下，α|00⟩+β|11⟩ 总是返回 +1，却不透露 α、β。这里只演示一个约束，不是完整的纠错码：相对符号发生变化时，这个约束还看不出来。Consider two physical qubits. Measuring Z₁Z₂ distinguishes “00 or 11” from “01 or 10,” returning +1 or −1 respectively. An ideal measurement always returns +1 on α|00⟩+β|11⟩ without revealing α or β. This is one illustrative constraint, not a complete error-correcting code: a change of relative sign can still escape it.

为了描述这种遗漏，给两种操作起名字。泡利 X 交换 |0⟩ 与 |1⟩；泡利 Z 保留 |0⟩、给 |1⟩ 乘 −1。前者是比特翻转，后者是相位翻转。对两个分量先交换再改符号，与先改符号再交换，结果相差一个负号：XZ=−ZX。这叫反对易。Y 同时含有 X、Z 两部分，忽略整体相位即可分开记录。整体相位不改变任何测量概率，但错误与校验反对易时，会改变校验的可测符号。To describe that missing change, name two operations. Pauli X exchanges |0⟩ and |1⟩. Pauli Z preserves |0⟩ and multiplies |1⟩ by −1. These are a bit flip and a phase flip. Exchanging the two components and then changing the sign differs by a minus sign from doing those operations in the opposite order: XZ=−ZX. This is anticommutation. Y contains both an X and a Z component, which we can record separately when ignoring an overall phase. An overall phase changes no measurement probabilities, but anticommutation between an error and a check changes the check's measurable sign.

编码让每个校验 S 对合法状态 |ψ⟩ 都返回 +1，即 S|ψ⟩=|ψ⟩。如果错误 E 与 S 反对易，S(E|ψ⟩)=−E(S|ψ⟩)=−E|ψ⟩，这个校验就变为 −1。同一校验碰到两个这样的错误，两个负号又抵消。因此我们可以只记录“哪几个约束变号”，不读取逻辑振幅。这份 ±1 清单写成 0/1 后，叫综合征 syndrome。解码器 decoder 是处理这份经典清单的算法；它看不到真实错误。Encoding makes every check S return +1 on every allowed state |ψ⟩: S|ψ⟩=|ψ⟩. If an error E anticommutes with S, then S(E|ψ⟩)=−E(S|ψ⟩)=−E|ψ⟩, and this check returns −1. Two such errors on the same check cancel the two minus signs. We can therefore record which constraints changed sign without reading the logical amplitudes. This list of signs, written as bits, is the syndrome. A decoder is a classical algorithm that processes that list; it cannot see the actual error.

画出错误，却只留下端点Draw an error; observe only its endpoints

上一章的奇偶变号规则，现在变成一张可逐边操作的平面码图。The odd-overlap sign rule now becomes a planar code you can manipulate edge by edge.

图上的每一条边承载一个数据量子比特，圆点表示 X 校验的位置，不是额外的数据。圆点询问相邻各边上 X 操作的乘积。现在在一条内部边放一个 Z 错误：这条边接触两个 X 校验，每个都遭遇一次反对易，所以出现两个警报。再延长错误链，中间校验碰到两条错误边，负号抵消；警报只留在端点。Each edge in the diagram carries one data qubit. A circle marks an X check, not another data qubit. The check measures the product of X operators on its incident edges. Put a Z error on an interior edge: it touches two X checks, each encounters one anticommutation, and two alarms appear. Extend the chain and an intermediate check meets two error edges, so its minus signs cancel. Only the endpoints remain visible.

为什么所有约束能一起成立？任意 X 校验与 Z 面校验重叠 0 条或 2 条边，反对易的负号出现偶数次，两个完整校验因而对易。把同类支持写成二进制矩阵 HX、HZ：每行对应一个校验，每列对应一条边，有接触填 1。错误向量 e 的第 j 项等于 1 表示第 j 条边发生 Z 错误。于是 s=HXe mod 2，而 HXHZᵀ=0 mod 2 表达两组校验兼容。模 2 的意思是只保留奇偶。Why can the constraints all hold together? Any X check and Z face check share either zero or two edges. The anticommutation signs occur an even number of times, so the complete checks commute. Record their supports in binary matrices HX and HZ: rows are checks, columns are edges, and an incidence is 1. Entry j of the error vector e is 1 when edge j has a Z error. Then s=HXe mod 2, while HXHZᵀ=0 mod 2 expresses compatibility. Modulo 2 means keeping only parity.

s = HXe (mod 2)
HXHZT = 0 (mod 2)

矩阵乘法在这里就是逐行数一数：该校验碰到了奇数条还是偶数条错误边。T 表示转置，交换行与列。Here matrix multiplication counts, row by row, whether a check touches an odd or even number of error edges. T denotes transpose, exchanging rows and columns.

这块未旋转平面码有 n=d²+(d−1)² 个数据量子比特，两类各有 d(d−1) 个独立校验。n 个量子比特共有 2ⁿ 个计算基态方向；每个独立、兼容的二值校验把允许空间的维数减半。因此剩余空间维数为 2ᵏ，其中 k=n−2d(d−1)=1，也就是一个逻辑量子比特。d=3 时是 13 个数据、6 个 X 校验、6 个 Z 校验；测量用的辅助量子比特未画入数据计数。这里的边是解码图中的错误位置，不是芯片布线图。This unrotated planar code has n=d²+(d−1)² data qubits and d(d−1) independent checks of each type. The n qubits have 2ⁿ computational basis directions. Each independent, compatible binary check halves the dimension of the allowed space. The remaining dimension is 2ᵏ with k=n−2d(d−1)=1: one logical qubit. At d=3, that means 13 data qubits, 6 X checks, and 6 Z checks. Measurement ancillas are not included in this data-qubit count. Edges here locate errors in a decoding graph; this is not a chip wiring diagram.

在任意错误上叠加一个 Z 面校验，每个相邻 X 校验仍被触碰偶数次，综合征不会改变。编码态又是这个面校验的 +1 态，所以这种局部变形不改变所存的信息。我们已经碰到解码的根本困难：综合征给出端点，无法唯一确定路径。Add a Z face check to any error pattern. Every adjacent X check is still touched an even number of extra times, so the syndrome stays unchanged. An encoded state is also a +1 eigenstate of that face check, so the local deformation preserves the stored information. We have reached the basic decoding ambiguity: the syndrome gives endpoints, without identifying a unique path.

模型范围：这是未旋转平面码的 Z 错误解码图。完整量子码的两类校验都定义了，但交互没有模拟振幅、测量电路或 X/Y 噪声。现代实验常用旋转布局，数据量子比特计数不同。Model boundary: this is the Z-error decoding graph of an unrotated planar code. Both check families are defined, but the interaction does not simulate amplitudes, measurement circuits, or X/Y noise. Experiments often use rotated layouts with different data-qubit counts.

给可能的修复定价Put a price on a plausible repair

端点已知，路径未知；噪声模型给不完整的证据补上一条选择规则。Endpoints are known, paths are hidden; a noise model supplies the missing rule for choosing.

解码器收到 s，必须选择另一组 Z 操作 c，使 HXc=s。同样的操作做两遍会抵消，因此错误和修复叠加后，所有校验都可以恢复。候选路径很多；如果每条边独立地以小概率 p 出错，短路径通常比长路径更可信。这是选择规则所需的额外信息：噪声模型。Given s, the decoder must choose Z operations c satisfying HXc=s. Applying the same operation twice cancels it, so composing error and repair can restore every check. Many paths qualify. If edges fail independently with a small probability p, a short path is usually more plausible than a long one. This extra information is essential to the choice: it is the noise model.

不同边的出错概率可以不同。某条候选错误使用边 j 的概率因子是 p_j，不使用则是 1−p_j。把所有边的因子相乘，再取负对数，候选间共同的部分可以去掉，留下每条选中边的代价 w_j=ln((1−p_j)/p_j)。这里 ln 是自然对数。本页限制 0<p_j<1/2，所以所有代价为正；越容易出错的边，代价越低。相同概率时，最小代价等价于最少边数。Different edges can have different error probabilities. A candidate error contributes p_j if it uses edge j and 1−p_j if it does not. Multiply those factors, take a negative logarithm, and remove the part shared by all candidates. Each selected edge then costs w_j=ln((1−p_j)/p_j), where ln is the natural logarithm. We restrict 0<p_j<1/2, making every cost positive. A more error-prone edge costs less. When probabilities are equal, minimum cost is the same as minimum edge count.

为什么动态规划比较的是全局修复？Why does the dynamic program optimize a complete repair?

把尚未分配的警报集合记作 U，选其中第一个警报 a。它要么连到边界，要么与 U 中另一个警报 b 配对；这两类涵盖所有合法分配。把最短连接的成本与剩余集合的最优成本相加，比较所有可能。空集合成本为 0；缓存重复子问题。正权重让不必要的闭环可以删除，所以路径匹配给出最小权重的奇度约束解。Let U be the unassigned alarms and choose its first alarm a. It must connect either to a boundary or to another alarm b in U; these options cover all valid assignments. Add each shortest-connection cost to the optimum for the remaining set, then compare. The empty set costs zero; repeated subproblems are cached. Positive weights allow unnecessary cycles to be removed, so path matching solves the minimum-weight odd-degree constraint problem.

The objective is exact; runtime is not a PyMatching benchmark. The corridor is an assumed independent-edge noise model, not measured chip calibration.

MWPM：把路径换成匹配问题MWPM: turn paths into matching

加权目标已经明确；现在推导为何匹配能精确求这个目标，以及 Blossom 怎样允许旧配对被改写。The weighted objective is defined. Now derive why matching solves it and how Blossom lets old pairings be revised.

§3 已经给出目标：找一组修复边 c，让 HXc=s，同时让各边对数几率权重的总和最小。困难在于，候选是整张格子上的边子集，数量随数据边数指数增长。我们先问一个结构问题：任何满足这个奇偶条件的子图，能拆成什么？Chapter 3 gave the objective: choose correction edges c satisfying HXc=s while minimizing the sum of their log-odds weights. The candidates are subsets of all lattice edges, so their number grows exponentially with the data-edge count. Start with a structural question: what can any subgraph satisfying this parity condition be decomposed into?

在修复子图里，没有警报的内部顶点度数是偶数，有警报的顶点度数是奇数。这里“度数”就是连接到该顶点的已选边数。从一个奇度顶点出发沿边走，在偶度中间点总能把进入与离开配起来，直到遇到另一个奇度顶点或允许吸收端点的边界。重复这个过程，剩下的只会是闭环与边界到边界的路径。对于非负边权，这些不影响观测端点的多余部分可以删掉而不增加成本。于是最优候选可以用“一组警报之间或警报到边界的连接”表示。In a correction subgraph, an internal vertex without an alarm has even degree, and an alarm vertex has odd degree. Degree here means the number of selected incident edges. Starting at an odd-degree vertex, follow edges; an even-degree intermediate vertex can pair an arrival with a departure, until the walk reaches another odd-degree vertex or an absorbing boundary. Repeat. What remains consists of cycles and boundary-to-boundary paths. With nonnegative weights, these extra pieces can be deleted without changing the observed endpoints or increasing cost. An optimal candidate can therefore be represented as connections between alarms or from alarms to a boundary.

现在把整段路径压缩成一条辅助边：辅助图的真实顶点只保留警报 a、b 等，连接 a 与 b 的权重 d(a,b) 等于原图里两者的最短路径权重。d(a,∂) 表示 a 到任一可吸收边界的最小代价；这里 ∂ 读作“边界”，不是新校验。最短路不能借边界作为免费中转站：到达边界就结束。每个警报只需在这些辅助边中被选中一次，这就是匹配的约束。Compress a whole path into one auxiliary edge. Write d(a,∂) for the minimum cost from a to any absorbing boundary; ∂ reads “boundary” here, not a new check. A shortest path must stop when it reaches a boundary; it cannot use that boundary as a free transit hub. Each alarm needs to be used exactly once among these auxiliary connections: this is the matching constraint.

但一个普通匹配顶点只能被用一次，粗糙边界却可以吸收任意多个警报。因此，不能把整条边界直接画成一个容量为一的普通顶点。设有 m 个警报，为每个警报 a 添加一个专属虚拟副本 a′，以权重 d(a,∂) 连接 a 与 a′。再把所有虚拟副本两两用零权边连接。若 a 去边界，就选 a—a′；若 a 与另一个真实警报配对，闲下来的两个虚拟副本可以免费互配。实际去边界的警报数与 m 同奇偶，所以闲下来的副本总能两两配完。这一步把问题变成 2m 个顶点的完美匹配：每个顶点恰好参与一条选中边。An ordinary matching vertex can be used only once, but a rough boundary can absorb several alarms. We must not model an entire boundary as one capacity-one vertex. For m alarms, give every alarm a a private virtual copy a′ and an edge of weight d(a,∂) between them. Connect every pair of virtual copies by a zero-weight edge. An alarm sent to the boundary uses a—a′; when two real alarms pair, their unused copies can pair for free. The number of boundary assignments has the same parity as m, so the unused copies can always be paired. The result is a perfect matching on 2m vertices: every vertex meets exactly one selected edge.

The Union-Find decoder starts with a more local question: if repairs are allowed only inside a connected region C, when is that region large enough to explain all its alarms? 先假定 C 不接触吸收边界，也不允许修复离开 C。把 C 内所有顶点的度数相加，每条内部边都被两个端点各数一次，所以总和必为偶数。它的奇度顶点，也就是待解释的警报，数量必须为偶数。这个必要条件也足够：在 C 中保留一棵连接所有顶点、没有闭环的生成树，就可以从叶子开始逐个满足奇偶约束。剥离的具体过程稍后会把这个“足够”做给你看。First suppose C touches no absorbing boundary and no repair can leave C. This necessary condition is also sufficient: keep a spanning tree that connects all vertices without a cycle, then satisfy the parity constraints starting at its leaves. The peeling procedure will shortly turn this sufficiency claim into a construction.

紧凑词汇表Compact glossary

稳定子 · stabilizer　对所有合法编码态都作用为 +1 的泡利约束。面校验的乘积仍是稳定子。stabilizer — A Pauli constraint acting as +1 on every code state. Products of face checks remain stabilizers.

综合征 · syndrome　校验的变号清单。它给错误留下的约束破坏，不读取逻辑振幅。syndrome — The list of flipped checks. It exposes broken constraints without reading logical amplitudes.

简并 · degeneracy　多个不同物理错误只差稳定子，因而对编码信息产生相同作用。degeneracy — Different physical errors differ by a stabilizer and have the same encoded action.

逻辑失败 · logical failure　修复后仍有非平凡逻辑作用；零综合征也可能失败。logical failure — A nontrivial logical action remains after repair; the syndrome can be zero.

检测事件 · detection event　测量记录相对已知预期关系发生的改变；本实验是相邻轮异或。detection event — A change relative to an expected relation among measurements; here, XOR between adjacent rounds.

泡利框架 · Pauli frame　用经典记录追踪泡利修复，并据此解释后续测量。Pauli frame — A classical record of Pauli corrections used to interpret later measurements.

Blossom / 奇环收缩　在匹配搜索中把奇数长度的交替环暂时视作一个顶点；必要时展开以恢复内部配对。Blossom　Temporarily contracts an odd alternating cycle during matching search, then expands it to recover internal pairings.

Union-Find / 并查集解码　维护簇的归属与奇偶，让不可修复簇增长至可修复，再从物理生成树中剥离修复。Union-Find decoding　Tracks cluster membership and parity, grows invalid clusters until repairable, then peels a repair from a physical spanning forest.
